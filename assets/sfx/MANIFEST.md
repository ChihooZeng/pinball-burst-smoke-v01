# 音效素材清单（S1 阶段）

> 本阶段只做**素材筛选与试听**：不改游戏逻辑、不接入音频系统、不部署。
> 交付日期 2026-11-05 · 分支 `experiment/audio-sfx-v1-20261105`

## 1. 筛选方法

三个包共 255 个 `.ogg` 全部解码分析，不靠文件名猜。每个文件先转 22050Hz 单声道，
再计算四项客观指标，用数据缩小范围，最后靠人耳定夺：

| 指标 | 含义 | 在本项目里的用途 |
|---|---|---|
| 时长 | 解码时长 | 机枪必须 < 0.3s；清屏/失败可 0.8–1.2s |
| 峰值 / RMS (dBFS) | 响度上限与平均能量 | 判断是否要压增益；机枪必须够轻 |
| 过零率 / 谱重心 | 明亮度 | 击碎要中高频，爆炸要低频 |
| 低/中/高频能量占比 | 频段分布 | 避免与现有 BGM 抢频段 |

**这张表不能替代试听。** 文件名能说明"这是金属撞击"，但说明不了"好不好听、像不像砖块碎"。
所以 12 个候选全部标为**待人工确认**。

## 4. 已知缺口（不粉饰）

1. **没有真正的"升级旋律"**。三个包里全是点击/开关/撞击/引擎，没有正向 jingle。
   `switch28` 只是 0.20 秒确认音，做升级音偏弱。
2. **没有理想的"开花爆开"**。`laserSmall_002` 是能量感占位，不是"啵"地爆开。
3. **清屏音不确定**。`forceField_004` 是低频能量音，听感可能偏"护盾"而非"胜利"。
4. **失败音与爆炸低频共用**同一个文件，语义可能冲突。
5. **三个包都没有"砖块"材质**。Impact 包是玻璃/金属/木板/石板，砖块只能借用石板或矿岩。
6. **全部 12 个候选未经人耳确认**。本次筛选只做到"数据上合理"，没有"听感上确定"。

前 4 条如果要补齐，合理路径是用 **jsfxr** 生成短音（8-bit 风格，可精确控制包络），
而不是继续在 CC0 包里凑。这属于下一阶段，本轮不做。

## 5. 怎么试听

```sh
cd .worktrees/audio-sfx-v1-20261105/assets/sfx
python3 -m http.server 4190
# 打开 http://127.0.0.1:4190/audition.html
```

直接双击 `audition.html` 也能用（脚本用 `<script src>` 加载，不受 file:// 的 fetch 限制）。

页面能力：

- 每个候选独立播放 / 循环 / 停止；
- 同页对照 M2.5 现状合成音（同参数复刻，含 -18dB 阈值 5:1 压缩器）；
- **响度对齐 -18 dBFS 默认开启**——Kenney 素材峰值接近 0dB，现状合成音只有 -8～-20dB，
  不统一响度就会得出"新的更好听"的假结论；
- 机枪候选有「连发 2 秒」，按 12.5 发/秒真实射速测试叠加是否刺耳；
- 「依次试听 12 个」用于快速通听。
