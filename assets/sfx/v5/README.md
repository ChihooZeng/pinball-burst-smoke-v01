# 《弹珠超载》独立音效选型 V5（7类 × 30候选）

- 入口：`assets/sfx/v5/index.html`
- 目标：**回到独立试听、人工选型**，不运行游戏，不修改游戏代码。在上一轮约定的7种核心音效范围内为每种提供30段独立可播放候选。
- 分类：机枪射击、普通命中、砖块击碎、爆雷引爆、清屏过关、触线失败、升级/解锁。
- 不再作为独立类别：装甲砖命中（暂用普通命中调整音调）、砖块开花（暂用击碎）、植雷（暂时无独立提示）；**此前已选音频继续保存在 `assets/sfx/selected-v4/`，没有删除**。
- 总候选：7 × 30 = 210；每类前10来自原 `assets/sfx/v4/catalog.js`；第11–20来自 `compare/audio-in-game-lab-v1/extra-catalog.js`；第21–30来自 `assets/sfx/v5/more-catalog.js`。
- **注意：210条属于候选文件数，并不代表210种听感完全不同的正式成品。部分来自同一个Kenney系列的不同录音，仍需玩家实际听过才能判断质量。**
- 新扩展的70条逐一匹配公开索引中的真实文件，按事件类型过滤物理撞击、碎裂、提示和Jingle，不以强电子合成作为默认方向。
- 试听：每条旁边有独立“单次”和“连续3秒”按钮。连发采用AudioContext绝对时间排程，约0.08s/发机枪；含RMS归一、峰值上限、动态压缩器和主动停止。若跨域解码失败，尝试普通媒体播放并提示响度不再严格一致。
- 操作：选一个首选；可收藏多个备选（☆→★）、记录单类备注、记录已试听条目；支持“全部30 / 原选10 / 扩展20 / 仅看保留”过滤。
- 数据：V5使用单独LocalStorage键 `pinball-overload-audio-selector-v5`，不会覆盖V4与游戏内实验室的选择记录；支持JSON、Markdown导出及V4/V5 JSON导入。
- 默认继承2026-11-06人工V4选择：`mg-01`（同时收藏`mg-01`、`mg-02`、`mg-03`）、`hit-02`、`boom-03`、`clear-10`、`upgrade-03`。砖块击碎与失败未选定、不能被自动填充。
- V4清屏过关与升级使用了同一个`Rise03.wav`，保留为各自现有首选；V5备注提示可能需要区分。
- 已归档7类中的用户首选/备选，从本项目 `assets/sfx/selected-v4/` 读取；其他候选按需从 `Mcamento8/open-game-sfx-index` 的raw GitHub镜像试听。网络或CORS受限可能导致部分音频不可用。
- 发行前必须**单独下载、归档全部最终选中音频**，重新核实Kenney与OpenGameArt各源素材的许可证、真机兼容、混音音量与高并发性能。素材索引注明CC0 1.0，但本实验室不替代独立法律授权核验。
- **本阶段不做游戏内接线、音效混音，也不替代真实战场最终音效验收。** 在独立工具中选好以后，再对7类做R1游戏内A/B综合试听。

## 预期验收

1. 分组共7个，每组有30个不同的来源URL；只显示当前类别的30行，不一次堆叠210行。
2. V4首选与3个机枪收藏默认存在，砖块击碎/失败默认待定；收藏与首选各自独立。
3. 单次、连续3秒试听按浏览器真实播放；连续不因setTimeout链式漂移影响间隔。
4. 选择、收藏、备注、已听记录刷新后仍保留；导出文件可恢复数据。
5. 页面可在电脑浏览器顺畅浏览和试听，正式Demo、原V6与游戏内音效实验室文件均不修改。
