# 《弹珠超载》音效选型 V4：10组 × 每组10个备选

- 目的：对应2026-11-06用户V3试听反馈，扩充**每个游戏事件10个新候选**；本轮没有选定新的正式音效，也没有修改游戏代码。
- 入口：`assets/sfx/v4/selector.html`
- 数据：`assets/sfx/v4/catalog.js`（10组，合计100条真实素材链接）
- 选型：本地自动保存；支持试听、单选、备注、JSON与Markdown导出。
- **保留 V3 决策**：7组原有已选项保持选中（但对应新WAV仅在本地V3工作区，GitHub Pages当前未发布，故在本页只保留记录、不能试听）；砖块击碎、装甲命中、爆雷这3组保持“需重做”状态。
- 音频：全部100个备选由第三方公开CC0声音索引的原始文件链接提供（未将100个源文件并入本项目），仅供试听和选型。当前页面使用浏览器 Web Audio 对每个样本做有限RMS增益调整并限峰；浏览器若禁止跨域解码，则退回普通媒体元素播放，此时响度不能严格对齐。
- 正式发行前：**必须下载选定声音到本仓库，自托管，不可直接依赖第三方GitHub raw热链**；记录每条原始文件名、素材包、许可证，并在手机真机上测试。所有音效的音色质量均须人工试听，文件名不代表已验收。

## 来源与许可证

- OpenGameArt：Level up / power up / Coin get 13 Sounds（wobbleboxx，CC0）：<https://opengameart.org/content/level-up-power-up-coin-get-13-sounds>；其他OpenGameArt来源请核对索引库 `SOURCES.md` 和 `ATTRIBUTION.md`。
- 这是一份用于试听的素材目录，不是用户已验收的商用最终音频清单。

## 已知限制

1. 100个新增备选音频从 GitHub raw 域名按需加载，因此网络访问条件会影响试听；页面提供失败提示。
2. V3已经选定的7个WAV目前不在GitHub `main`，不会假装可以在线听到。本页通过文字、状态和导出值保留已有结果；若要同页试听V3原音，须单独发布原始V3 WAV。
3. “爆雷”候选为天然冲击/裂开/金属爆点的单个素材，部分不一定单独听起来就像完整爆炸；最终可能仍需专业分层，不应因数量变多就宣称完成。
4. 多个Kenney/OgA素材属于同一个系列的不同录音，10个候选**不是**10位不同音效师或10套正式混音成品。
5. 不允许据此修改Demo、R1或V1–V3；后续由玩家评审后决定最终接入和混音。
