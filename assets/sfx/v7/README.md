# 《弹珠超载》V7 极短音效重选

## 背景与用户最新意见

V6人工反馈导出：2026-11-06T07:50:27.853Z，详见 `v6-feedback.json`。

**清屏过关**：用户反馈“过关音乐不需要太长，我认为上面的音乐都偏长，因为我们是过关式的，很快节奏就开始下一关，不宜太长”。

**触线失败**：用户反馈“一样，都太长，而且都和我们的风格不符”，暂时保留的参照为“简单收尾提示”，但没有最终选择。

结论：V6的长音乐路线失败。**无需扩大长音乐候选库，应改成短促游戏状态反馈**。

## V7定义

- 独立试听页：`assets/sfx/v7/index.html`。
- 清屏成功：10组全新微型提示音，设计时长 **0.52–0.70秒**。目标是明亮、向上、具有结算感但不打断下一波。
- 触线失败：10组全新微型提示音，设计时长 **0.33–0.55秒**。目标是短暂收尾、明确、无刺耳电子声。
- 使用**16条真实CC0短音素材**作为发声源，通过浏览器Web Audio混合3–4个短撞击/弹拨，改变播放音高和触发节奏，生成20种新的微型声效配方。不是20个不同作者完整配乐成品。
- 每项可一次试听、**连续约3秒快节奏试听**（约0.8秒间隔连续4次）、收藏备用、单选为首选、记录备注；选择和备注本地自动保存；导出JSON/Markdown，支持导出当前选中配方为浏览器离线合成的PCM WAV（生成时按当前页面音量渲染）。
- 采用Kenney CC0短音素材，通过 `catalog.js` 记录每一个真实原文件名、实际来源URL、混音音量、速率、时间；已存档的木质声音优先本仓库自托管，其余按需外部加载，CORS及网络可用性需要实际验证。
- **不再默认采用**V5过关`Rise03.wav`、V6长音乐或Game Over结尾曲。V7两组均未预选。
- **V5其他五组（机枪、普通命中、击碎、爆雷、升级）继续保留原有候选选择，不做修改。**

## 限制与发布

- Web Audio中用素材重组并不保证天然优美；是否听起来“成功的喜悦”必须由用户试听评定。仅保证配方时长与来源明确。
- 素材若无法解码，页面会提示而不是假装已经播放；源音频请重新验证CC0及国内网络环境。
- 实际接入游戏前，把最终选中WAV归档、验收响度、处理多次过关快速连播，避免与升级音混淆。
- **本工作仅新增V7目录和评审文档**。V1–V6、正式Demo、原R1、V4存档不改。
