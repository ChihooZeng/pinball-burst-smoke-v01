# 《弹珠超载》独立音效选型 V8（中等时长）

## 本轮决定

2026-11-06 用户反馈：「两组的声音都过短，重新给我筛选」，随后明确要求「不如你给我网页，我自己选择」。

因此提供一个**独立的网页试听选择工具**，而不是继续讨论是否需要音效、也不修改游戏：

- 清屏过关：10组 **0.98–1.31秒** 中等时长音效，明亮、上扬，保留完成感；
- 触线失败：10组 **0.76–1.08秒** 中等时长音效，简短明确，避免长Game Over音乐；
- 两类都**默认待选**，不继承已经否决的V6长音乐或V7极短音效；
- 页面可单次试听、连续约3秒、选择首选、收藏备用、填写备注、浏览器本地保存、导出JSON/Markdown，也可将最终选中配方离线渲染为PCM WAV（按页面当前音量渲染）。
- 已确认的另外5类沿用V5记录：机枪、普通命中、砖块击碎、爆雷、升级；不改原素材、选择或代码。

## 实现

- 页面：`assets/sfx/v8/index.html`
- 目录：`assets/sfx/v8/catalog.js`
- 播放器：`assets/sfx/v8/selector.js`
- 复用16种真实Kenney CC0物理短采样；与V7相比，**重新编排触发时间和结尾段落**形成不同的节奏/层次，不是简单在旧配方后补静音，也不是把长音乐加速。
- 20组为**10种成功 / 10种失败的组合配方**，而不是20个不同作者新采样；音色实际是否符合用户偏好需真人试听。
- 保持浏览器本地选择键独立 `pinball-overload-sfx-v8-midlength-microstingers`，V5/V6/V7选择完全不动。
- 已存档Kenney音频优先使用 `../selected-v4/`，其余从Kenney CC0音源索引镜像获取，网络或CORS可能影响播放；正式使用必须归档最终选中的渲染文件和原始授权信息。
- 切换候选会停止之前的播放，避免造成对比误差。连续试听按每个候选实际长度加0.14s间隔排程，避免两段长音频提前叠加。
- 这次只新增 `assets/sfx/v8/` 文件，正式Demo、R1玩法、原音效实验室、V1–V7均不改。

## 仍需检查

- GitHub Pages完整加载和播放至少成功/失败各两条；
- 音频是否真正具有成功感/结束感，必须由用户试听选择；
- 若这轮仍不满意，应从用户收藏的具体候选反推音色及节奏，不继续盲目增长候选数量。
