## 已实现切片

3种开局能力、各Rank1–3、6条互斥分支、4项通用底盘、3项辅助；其他核心可作为弱辅助。开局不锁职业，分支选择才确认主核心。三选一由数据定义驱动，过滤前置、已满、互斥，提供方向/稳定/探索；有资格时提供两条分支供玩家决定，并轮转多条已培养路线。不足三卡时提供三种不同的下一波实际强化。

保留单炮台、真实反弹、固定120Hz、整波下降、真清屏、每波一次升级、波间清球、Boss每4波及有限召唤。第8波清屏升级后显示原型完成，不自动进入下一阶段。每次生产重开生成新随机种子；自动测试固定seed。

未实施：史诗/传说、融合、终极、神器、额外Boss奖励、特殊砖15/30秒Buff、50波内容。未来Buff跨波及停表规则保留在规格中，未误作永久资源。
