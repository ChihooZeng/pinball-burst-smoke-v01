# 六分支手感专项第二轮：脆击重做（2026-11-03）

## 反馈问题
用户在“强化击中”版仍感觉打击感不足。问题不只是特效强度低，而是**耐久砖每次受击缺乏清晰的接触-形变-回弹**，且原先 Elite 与 Boss 绘制路径跳过了砖块受击位移动画；增加亮度、粒子不能解决这个根因。

## 本轮修改
- 新增 `snap` “脆击重做”模式（六分支独立实验默认）。旧 `punchy`“上一版强化击中”、`bold` B轻快、`balanced` 更轻、`off` 关闭均保留。
- 对砖块耐久降低采用**0.12秒两阶段受击反馈**：约前0.029秒压缩和位移，后约0.091秒回弹。不改变真实碰撞盒、物理位置或弹球计算。
- 同一块目标表面绘制**白色瞬间受击面、命中边缘线、接触亮点**，替代仅依靠砖块外扩环暗示命中。
- 对 Elite、Boss 先调用同一受击位移动画，再绘制自身图形及受击高光；修复这两种砖之前完全绕开砖块视觉位移的问题。
- 击碎时保留较亮但更短的碎裂残影，以强化“碎掉的一瞬”而不是增加大批粒子。
- 命中声音增加复用的22ms短噪声瞬态，并混入短促中低音；每种击中声音仍遵守原先限频与压缩器。
- **不改变**数值、伤害、掉血时机、Boss血量、巨型球释放方式、六分支行为、发射节奏、球上限；旧特效可立即切回对照。

## 验证
- 读取真实 JS 后在 V8 模拟DOM/Canvas：确认 `snap` 默认、旧模式可切换；
- 注入 HP70 的受击砖：伤害受击标记建立；执行模拟帧后，确实调用压缩/回弹变换及接触白光绘制；碎裂事件触发独立残影计数；
- 六分支×密集第6波/Boss第10波共12个模拟入口成功，正常射击且巨型球可释放；
- 正常流程首关仍提供裂变/电弧/机枪三选一。
- 更新仓库 Node 回归脚本 `demo/v1/quick-build-lab-smoke.cjs`，但没有通过真实 Node CLI 运行，**不应声称 Node 执行通过**。
- **未验证**：iPhone Safari 的画面/声音质感、人工“爽感”、60/120fps；新默认是否足够重，需要用户试玩决定。
