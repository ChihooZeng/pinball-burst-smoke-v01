# 砖块色彩专项审计与重设计（2026-11-19）

> 基线 `b93e8db`（V4）。本轮只改配色表，渲染管线保持 V1，未改 HP/数值/特殊砖/Boss。
> 截图目录：`demo/v1/review-brick-color-audit/`（54 张，全部真实关卡生成）

## 1. V1 与 V4 的代码差异审计

V4 只动了三处渲染参数，**没有动任何颜色**：

| 项 | V1 | V4 |
|---|---|---|
| 辉光 | 给整块填充加 `shadowBlur 8` | 独立半透明描边 `blur 8 / α .50 / lw 2.2 / inset .8` |
| 亮边 | 1.3px | 1.5px |
| 顶部高光 | α .13 / 5.5px | α .11 / 5px |

实测（固定砖阵，360×640@2x）：砖面亮度 88.29 → 88.68（+0.4%），砖缝亮度 28.06 → 26.05（−7.2%）。

**结论**：V4 是"边缘清晰度"优化，颜色一个都没换。用户感受到的"颜色辨识度没改善"是必然的——**它本来就没解决颜色问题**。本轮因此把 V4 的渲染改动整体撤回，只保留 V1 管线作为唯一变量。

> 修正上一轮的错误：第 1 关**不是**"全部 HP1"。`createWavePlan(1)` 里有 `hp = row<2 && col%3===0 ? 2 : 1`，实际是 31 块 HP1 + 4 块 HP2。

**结构性发现（本轮最重要的一条）**：

```js
const tier = Math.min(10, 1 + Math.floor((n-1)/2));
```

`n=1→1, 2→1, 3→2, 4→2`——**关卡两两共用同一个 HP 档位**。所以：

- 第 1、2 关用同一档（profile 1），第 2 关只是多了 HP3/4；
- 第 3、4 关用**完全相同**的档位（profile 2），两关的色阶分布 42/29/21/8 与 42/26/23/9 几乎一样。

这解释了"第 1、2 关颜色接近"：**主因是 HP 分布，不是颜色映射**。仅靠换色，第 2 关仍会有 81% 的砖是 Lv1；第 3、4 关也会永远长得一样。

## 3. 七色系统的实际问题（CIEDE2000）

| 相邻 | 面 ΔE2000 | 边 ΔE2000 | 判定 |
|---|---|---|---|
| Lv1→Lv2 | 13.2 | 13.0 | 太近 |
| **Lv2→Lv3** | **6.6** | **13.4** | **几乎同色** |
| Lv3→Lv4 | 17.5 | 22.7 | 勉强 |
| Lv4→Lv5 | 11.0 | 14.4 | 太近 |
| Lv5→Lv6 | 10.9 | 12.9 | 太近 |
| Lv6→Lv7 | 11.6 | 13.4 | 太近 |

白字对比度全部达标（5.72–10.82:1），所以问题不在可读性，在**区分度**。

与特殊砖的撞色（边 vs 边）：

| 普通砖 | 能量 `#4BEB9B` | 精英 `#C39BFF` | 召唤 `#4FC6FF` |
|---|---|---|---|
| 最小 ΔE | **7（Lv1）** | **5（Lv6）** | **9（Lv3）** |

三个特殊砖各自与某一级普通砖几乎同色。这不是"轻微撞色"，是**同色**。

**四个问题的答案**：

1. **第 1、2 关为什么接近**：第 2 关 81% 是 Lv1，且 Lv1↔Lv2 只有 ΔE 13。
2. **HP 还是映射**：两者都有，**HP 分布是主因**。换色只能让第 2 关里 19% 的 Lv2 跳出来，整关基调仍是 Lv1 的颜色。
3. **哪些等级难区分**：Lv2↔Lv3（6.6）最差，其次 Lv4↔Lv5（11.0）、Lv5↔Lv6（10.9）、Lv6↔Lv7（11.6）、Lv1↔Lv2（13.2）。
4. **是否有单色关**：**第 1 关 100% Lv1，是纯单色关**；第 3、4 关因共用 HP 档位，两关在颜色上无法区分。

## 4. 两个候选配色

约束：HP 映射（2/4/8/16/32/64）不变、颜色仍只表达耐久、白字 ≥4.5:1、不改特殊砖。

### 候选 A「薄荷收边」

只改 Lv1：色相保持 162°（薄荷），提亮砖面 + 描边略微压深。

| | main | ft | fb | edge |
|---|---|---|---|---|
| Lv1 | `#0BD57E` | `#07804C` | `#044D2D` | `#04BE6D` |

- Lv1↔Lv2 边 ΔE **22.3**（V1 13.0）
- Lv1 vs 能量砖 **11.4**（V1 7）
- 白字 6.24:1

### 候选 B「绿起步」

Lv1 移到绿色 128°，Lv2 及以后全部保持 V1。

| | main | ft | fb | edge |
|---|---|---|---|---|
| Lv1 | `#0CDF28` | `#078618` | `#04500E` | `#04C81E` |

- Lv1↔Lv2 边 ΔE **30.3**（V1 13.0）
- Lv1 vs 能量砖 **14.8**（V1 7）
- 白字 5.96:1

两套的 Lv2–Lv7 与 V1 完全一致，因此 Lv2↔Lv3（6.6）等中后段问题**本轮不修**——按"Lv3–Lv7 以现状为基准"的要求保留。

## 5. 为什么只动 Lv1

对 7 级色带做过穷举搜索（40 万组色相 + 描边明度组合）：

- **不存在**"7 级相邻都 ≥18、同时与三个特殊砖都 ≥15"的解（0/37 万通过筛选）；
- 上限约：相邻最小值 ~13、与特殊砖最小值 ~10。

原因是三块特殊砖（150°/199°/264°）正好占住了 7 级色带必须经过的三段。所以只能按"同波共现"排优先级：第 1–4 关只出现 Lv1–Lv4，其中 Lv1↔Lv2 是最关键的一对。

## 6. 实机 A/B 结论

| 场景 | 结果 |
|---|---|
| 第 1 关 | A 与 B 都保住了亮边霓虹；B 的纯绿与能量砖（薄荷+闪电）区分最明显 |
| 第 2 关 | V1 里 Lv2 几乎看不见；A 能看出偏青；**B 能一眼挑出 Lv2** |
| 第 3 关 | V1 是"绿-青-蓝"一团；B 变成 绿/青/天蓝/蓝 四段，层次最清楚 |
| 第 4 关 | 与第 3 关同档位，换色也无法再拉开（结构问题） |
| 高耐久（16 关） | 三套几乎一样（只动 Lv1，高关以 Lv4–Lv7 为主） |
| 精英 / Boss10 | 精英砖、Boss 砖、召唤砖均未变；B 的普通砖与召唤砖（青）更容易区分 |
| 受击 / 击碎 | 闪白与粒子未受影响 |

**推荐：候选 B「绿起步」。** 理由：Lv1↔Lv2 从 ΔE 13 → 30，是唯一能让第 2 关"看得出两种砖"的方案；同时把 Lv1 与能量砖的撞色从 7 提到 14.8；亮边霓虹、白字对比度、性能全部保持。

**保留意见**：B 把最弱一级从"薄荷"改成"绿色"，是可感知的身份变化。如果更看重连续性，选 A（只压明度结构，色相不动）。
