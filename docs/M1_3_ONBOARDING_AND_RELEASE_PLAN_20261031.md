# 《弹珠超载》M1.3 新手引导、单手技能与公开测试计划（2026-10-31）

## 真实已实现 / 未验收
- 基线：M1.2，物理普通球伤害1，球速330，三核心延伸、不重叠Boss、手机可用视口全屏等不改。
- 首波：**直接普通炮台开打，无技能选择**；35块易碎教学砖（5行×7列，少量HP2），屏幕下方不弹技能按钮；若首波仍太长须再调教学波而非增加普通球基础伤害。
- 真正清屏第1波 → 出现三选一裂变/电弧/机枪 → 获得第一项永久技能与第1波升级记录；其后每波一次三选一，无额外奖励。
- 主动技能在第一次升级后解锁，能量满且首次未施放时提示一次；成功施放后本机LocalStorage保存，不在后续游戏重复。手机换机/无痕/清理存储需重新显示。
- 手机一手控制：原本自动发射、拖动瞄准松开后保留角度；按钮下方拇指区放大到至少96×64px，设置可选择左/右角；能量满时**自动释放**为可选开关，默认关闭。任何主动不能在第1波提前触发，按钮点击不应改变已选瞄准角。
- 代码补充无流派的shotsByBuild.base，避免首波统计缺失/NaN。开发分支：codex/v1-m1-3-onboarding，目录：compare/hybrid-v1-m1-3/。
- 已有24项V8/数据模型定向检查通过，**未执行完整物理10波、历史回归、iPhone/Android真机**。

## 一、下一阶段只建轻量「参数调试台」，不要重做引擎
建议采用 [Tweakpane](https://github.com/cocopon/tweakpane) 或 [lil-gui](https://github.com/georgealways/lil-gui)（已存在的轻量成熟开源UI）；仅调试页加载，正式/公开游戏不加载调参UI。

### 单一参数来源
- `game-config`（数据、默认值、单位、范围、变更生效条件、公开/实验标记）
- `SkillDef`（技能触发与效果、升级卡文案的增量由同一参数计算）
- `Wave/BossProfile`（波次阵型、HP、Boss阶段及下落，独立于技能）
- 通过 `Tuning.get("cannon.normalInterval")` 等读取、校验和应用；尽量渐进地抽出已有CFG和游戏硬编码常量，不改写底层物理。
- 决定生效层级：射速/球速通常可下一帧或下一次发射生效；世界尺寸、危险线、关卡布局和Boss类型需“重开本波/下一波生效”避免碰撞错位。
- UI：射速、球速、伤害、下降、HP倍率、Boss、技能概率、同屏球预算；立即显示当前配置与参考基线差异；随机种子锁定、回放前后对比、保存预设、JSON导入/导出、恢复默认。
- 调整后的真实参数必须进入本局导出记录，不能让A/B测试中展示值与真实效果不一致。预设提交Git；玩家正式版不含调试面板。

## 二、公开试玩（不等于50波正式版）
平台路线：GitHub Pages先建立可分享独立体验入口；随后可按外部渠道规则在TapTap的H5网页游戏流程和itch.io HTML5试玩投放。不要同时引入原生应用、微信小游戏、广告、内购。

### 公测前最小Gate（没有达标不得对外大规模引流）
1. 1→10波可完整开始、清屏、选卡、暂停/恢复、失败/结算/重来；无明显死锁、技能失效、重叠实体、隐藏增伤。
2. 第一波能看懂操作，第一次三选一与主动技能引导成功；同手指瞄准与技能操作可用、不卡死。
3. 三核心至少一条正常构筑和有意较弱的构筑可完整跑通或有可解释的生存补救；已知弱电弧第5波失败不能直接忽略。
4. 同步验证iPhone Safari与Android Chrome至少两种真实机型，报告异常帧/严重发热/音频初次解锁。
5. 明确写**“10波公开测试Demo，正式目标50波”**；提供反馈入口、可选本局记录导出，不在未经批准时静默收集个人数据。
6. 对外上架/替换默认入口/商业化仍须用户手动批准；本阶段GitHub Pages独立候选不代表已经进入外部渠道发行。

### 建议可执行市场验证
- 第一批10名不熟悉规则的测试者，观察5分钟内能否开始、完成首波并第一次升级、知道主动技能。记录阻塞并修复。
- 第二批约30–50名测试者，用可分享链接测试：首波完成率、首次升级成功率、主动技能首次释放率、达到第3/5/10波比例、二次启动意愿及最常见中途退出原因。
- 不把“30–50人”当作足以严谨估算市场大小的样本；用它发现最严重的首玩问题。出现玩家主动复玩、分享、询问后续版本，再投资50波内容。
- 达到公开验证的第一轮Gate后就投入招募测试者，避免全部开发资源持续投入功能却没有真实获客反馈。

## 三、阶段决策
- **现在：** M1.3第一波教学与单手技能独立候选 → 用户真人Gate
- **下一步：** 简单调参台+一轮10波全路径稳定性/弱Build与音频验证
- **之后：** 10波公开测试发布与第一批真实玩家数据
- **若玩家留存与主动分享有信号：** 完整50波作为正式版主线推进，逐章扩张Boss/技能/长期Build、暂停续玩；商业化在实际需求得到验证后设计

以上数值（35砖、96x64px、10/30–50测试者）是实验建议，未经真人验证不视为产品最终规则。
