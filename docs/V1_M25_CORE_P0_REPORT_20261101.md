## 实际代码
- 分支`codex/v1-m2-5-boss-finisher-sequential-arc`，目录`compare/hybrid-v1-m2-5/`。所有旧试玩保留不覆盖。
- `defeatBoss()`：Boss血量0后`bossVictory`状态立即锁胜，取消后续召唤、发射、待发闪电和现有危险线结算；残余真实实体在约1.7秒内按离Boss中心距离顺序引爆，屏幕出现扩展的发光波纹及击中反馈；**FX爆炸不调用`hitBrick`且不增加`score`/经验**。结束后接回原普通`wave_clear`奖励流程；第20关走`finishPrototype()`。原硬HP阶段仍生效，玩家仍须实际杀死888HP核心。
- `triggerLightning()`负责锁定有限队列，不再立刻调用`hitBrick`；`updateLightningChains()`从首发25ms后每82ms按排序目标逐跳执行实际伤害并生成一条可见电弧，击杀后可增加未访问过的目标。单链最多6，队列最多7，单帧最多两步，以免掉帧跳过演出。雷霆聚能仍聚焦单体。
- 新用户`autoSkill=true`；`localStorage`中显式`no`保留手动；蓄力100%且可释放时现有循环自动调用`activateEquippedSkill()`。射击循环未重构。按钮文案/设置说明同步。
- 其他继承M2.4：基础普通球直击1伤害、速度330、20关/50关目标、三流派升级池、Boss10动态增援与渐进下降、Boss20三阶段。
