# 《弹珠超载》V1.0 RC 验收报告

## 浏览器与范围

2026-11-19，本机 macOS，Chrome 157.0.8103.79。通过 CDP 启动真实 Chromium，使用 360×640、390×844 和 1440×920 的 CSS 视口。移动尺寸使用触控和 DPR 2 模拟。砖块实尺寸截图用 DPR 1 便于按原尺寸查看。设备模拟、运行时故障注入、全程鼠标输入回归分开记录。

## 已验收项

- 两档手机尺寸和桌面正常打开，无横向溢出。英文自动识别、中文保存、实触摸瞄准、三选一、构筑面板和终局核心名称通过。日常入口隐藏 QA。
- 普通 1HP Canvas 数值不绘制，2HP 仍有数字。全 20 波逐 HP 生成分布复核。色差和对比度见 [砖块审计](BRICK_COLOR_AUDIT_20261119.md)。
- 巨型球把 Boss10 打到 0 后继续跑完连环爆炸、进入升级并继续第 11 波。切后台模拟停表，恢复后推进。地址栏高度变化模拟保持战斗状态。一次受控 Canvas 异常显示回到首页，恢复后成功开始新局。
- 390×844 浏览器实际触摸解锁，BGM 媒体时间推进。受击保留 V5，击碎、机枪、超载、中枢击破、清屏均有音频计数，真实混音从 Web Audio 总线录制。设置静音使音效停发，BGM 元素静音，并记住选择。

## 真机与真人

当前环境无 Android 实机和可用 iOS 模拟器。iPhone Safari、Android Chrome 与实际玩家体验仍需验证。每台设备按以下路径验收并记录机型、系统、浏览器版本及网络：

1. 竖屏冷打开，中英文分别进入。检查首页、触控拖动、单手切边、自动与手动超载。
2. 保持战斗时进出控制中心、切后台和锁屏。返回后继续，观察音效、BGM、游戏时钟及方向，检查系统静音和蓝牙切换。
3. 让地址栏展开和收起，横转后还原。检查 UI 安全区、按钮、字号和 Boss 顶部增援。
4. 从第 1 波运行至少一局，记录首次成功选择、每波节奏、触线原因、Boss 阶段、结算及是否愿意尝试另一流派。
5. 高粒子、满球和 Boss 结算时观察帧率并保留录屏。测连续重开，打开和撤回统计同意。
