## 3. Codex报告的自动化证据（不是本人手机实机复测）
- 25个旧版 Node 测试脚本 PASS；v26 Chrome模拟手机三尺寸基线 PASS。
- v27数据模型、战斗机制、互斥分支、跨帧逻辑与30/60/120Hz确定性回放 PASS；Chrome模拟 390×844、375×667、320×568、1440×900布局及操控 PASS。
- 固定 seed=2701、真实物理自动瞄准8波、不过度使用测试作弊：裂变星海风暴148.43秒；电弧雷网蔓延256.92秒；机枪直线压制152.19秒；三路线均击败2次Boss完成8波。
- 机枪主核初始射击间隔0.35/0.27/0.20秒，直线0.17秒、扇扫0.18秒；主核机枪最大射速卡下限0.12秒；同屏32真实球预算。
- 孤立52HP Boss且禁主动的特定构筑：裂变5.54秒、电弧17.94秒、机枪4.17秒。
- 弱势选择路线：裂变第4波失败（133.63秒）、电弧第3波失败（104.87秒）、机枪第7波失败（253.17秒）。
- 高密度压力夹具60秒、峰值32球，连射499发、回收499球、抑制0；该测试关闭下降并人工填满球池，不代表手机持续帧率。
- Chrome/Mac短采样显示60FPS，**不代表iOS Safari/Android真机长时间、发热和帧率已通过**。
- 对比实验为了使8波可通关，v27采用 **v26的80%下降速度** 且电弧伤害随Rank为1/2/3；这两项都是待人工认可的临时平衡参数，**绝不能悄悄当正式策划结论**。

## 4. 未解决的产品风险（新窗口优先讨论）
**P1 — 电弧明显慢**：自动8波256.92秒，裂变148.43秒、机枪152.19秒。电弧孤立Boss17.94秒，需区分传播效率、孤立目标补偿、实际命中与视听反馈，先试玩定位再调参，不要粗暴进一步增伤。
**P1 — 玩家前期投资可能失效**：当前选择主核心分支后，非主核心rank有效值上限为1。若前几波给某能力投入Rank2后选了另一核心，可能出现“升级投入白费”。设计上可考虑升级返还、转化为辅助成长、分支前限制非种子深度或更清晰预告；先确定用户偏好再让Codex修改。
**P1 — 机枪球数预算的手感**：满32球时，为继续发射会回收最老子球，其次回收最老普通球；需真机观察突然消失、低效弹球占位、对比裂变压制性，确认是否应调整。
**P1 — 平衡数据不可直接外推**：当前只测8波，下降速度80%与电弧伤害特调；50波仍是远期挑战，10–20波完整Build体验未实测。
**P2 — 用户操作与反馈**：第1波三流派差异是否清楚；分支菜单是否易懂、是否愿意重开；音效、手势、手机机型兼容、隐藏页停表、长时发热。
**P2 — 极罕见技能期待**：用户要求传说非常稀有且有明显改变玩法的惊喜，但应先把v0.27a普通Build好玩且可成型验证好，再按v0.27b开发真实效果。

## 5. 已确认的设计方向 vs 待定参数
确定：
- 《弹珠超载》强调弹球撞击、数字下降、密集连破与构筑自己的破坏机器；
- 10–20波应具有完整成长体验，50波是高阶挑战目标；
- 每波固定获得成长；关键Boss/里程碑可给予进化/特殊奖励（奖励次数的额外增加仍需验收）；
- 三个实验Build：**裂变（场内增殖）/电弧（伤害传播）/机枪（炮台高频，直线或扇扫）**；
- 不锁死起始职业，前中期引导构筑，成熟Build通过有限高阶进化和稀有突破保持差异；
- 史诗/传说稀缺，但普通完整Build不依赖必抽到传说；
- **特殊砖只触发即时和15/30秒限时战斗强化，不掉落永久升级/碎片**；Buff使用有效战斗时间，升级/过场/暂停时不计时，剩余可**跨波延续**；清屏只清物理球/巨型球，不清未到期Buff。
待确认：
- v27的80%砖阵下降是否保留；
- 电弧等三个Build的攻击/存活数值；核心分支触达波次与保底；
- 第2波额外一次基础强化、Boss额外奖励、神器/传说实际装备槽位；
- 传说稀有率、触发强度、性能上限、20–50波进化深度。
