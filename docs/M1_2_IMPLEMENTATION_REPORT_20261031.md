- 不改伤害1/球速330/普通炮台基础间隔与机枪基础间隔；实际选取火力强化仍可直接伤害+1。
- 原`BUFFS.power`15秒直接伤害+1改为15秒炮台射速+10%；按实际Buff修改发射间隔。原30秒球速Buff保留；特殊砖依然不给永久成长。
- 孤立Boss在每6秒的末2秒弱点窗口由直接伤害+1改为每次命中额外积累4点主动能量。Boss真实血量不会被暗中削减。
- 直接撞击新增事件`direct_hit`记录独立伤害来源与HP前后。已选择机枪破甲、钻头、侧墙蓄势、火力和后续电弧效果可合法增加伤害；两球物理先后命中不等于一球打2。

- 三选一把多段参数叠加说明改为“本次变化”为主，分支强调替换与二选一；完整效果仍可在暂停Build查询。
