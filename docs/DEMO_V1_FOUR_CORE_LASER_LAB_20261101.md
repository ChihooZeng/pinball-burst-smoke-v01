## 已确认产品顺序

1. 新增第四个核心流派 **激光**，先有最低可用机制。
2. 对四个核心流派的技能设计、两个专精分支、跨流派混搭进行专门讨论与定稿。
3. 之后才设计炮台主动/被动技能、超载和巨型球等独立系统。
4. 再按成熟构筑平衡关卡难度，继续准备11月5日 Demo。
5. 本轮不处理第二轮打击特效、美术与页面美化。

## 原型实现（非最终平衡）

- 波1清屏后选择 **裂变 / 电弧 / 机枪 / 激光** 四选一；之后每波仍三选一。最多能拥有两种核心能力。
- 激光作为辅助持续火力和普通弹球同时运作；沿瞄准方向击中真实砖块，穿射数量随激光等级从1增至3。
- 激光在侧墙自动发生**至多一次**镜面反射；基础伤害周期约0.34秒，后续等级约0.27秒、0.22秒，射速训练可以小幅提升该频率。
- 激光伤害走既有砖块伤害、连击、清屏和危险线流程，不能绕开Boss HP获胜；为便于与其他流派融合暂时共享普通命中计量规则。
- 采用解析式射线命中测试，光束用少量画线呈现；不增加物理弹球、粒子风暴或新的独立计时器。
- QA 导航可选激光用于 Boss10/20跳关。

## 重要未定稿项目

- 激光**两个专精分支尚未实施**。候选方向：折射/覆盖型 与 聚焦/灼烧型，均只是讨论提案。
- 激光与其他三流派的联动、融合、抽卡权重、专精锁定时点未最终定稿。
- 光束是否最终替代普通弹球，还是作为额外攻击，需要和其他流派成长/火力预算一起比较。
- 当前激光数值不能认定与裂变、电弧、机枪平衡；也不能声称 Boss10/20 自然通关、移动端60FPS均达标。

## 下一步讨论的四个重点

- 每一流派的**行为身份**，不能重复。
- 4个核心×各2个专精分支的**技能质变机制**，不只是数字提升。
- 不同流派的二次融合是否满足明确前置条件与成本，防止所有Build最后趋同。
- 每关三选一如何兼顾专精承诺、随机性与普通辅助技能数量。
