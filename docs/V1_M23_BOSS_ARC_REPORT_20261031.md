# 《弹珠超载》M2.3 Boss大波次与电弧路线救援（2026-10-31）

## 起因
用户在M2.2真人游玩中确认：Boss10生成砖主要在顶部、数量仍不够、下降偏慢；电弧路线无法通过第10关。已认可20关高压版为总压力基准，正式目标仍50关不断Build。解决实际分布与伤害，不仅换UI或把标记改成召唤。

## M2.3代码变更
- Boss10：原每4.6秒最多4块、总≤23块、同时活≤16 → **每3.8秒最多14块、总≤70块、同时活≤48块**。使用真实`isSlotFree`碰撞与待生成砖预留，优先在全场上/中/下分区轮转，底部Boss中央3列保留弹射入口；每块7–21HP，部分两翼锚点22–38HP，提前BOSS_WARNING（约1秒）虚线标示。普通关仍无中途补砖；无无限Boss再生。真实数量受空间、危险线和Boss存活影响，不能保证每轮满14块、总70块。
- 第10关Boss下降倍率1.04→1.20；第20关888HP三阶段Boss保留，下降倍率阶段1/2/3从.29/.38/.47→.34/.45/.56。没有降低普通关基础HP，也没改变50关成型节奏。
- 电弧三级目标2/3/4、每目标实际电弧伤害由1/2/3→2/4/6；额外+2/+3/+4导电伤害仅对Boss、护甲、精英和Boss增援砖生效。起始电弧释放门槛3次普通命中→2次；冷却.45→.34s；跳电距离提高至145/165/180。击碎后仍能继续有限传导，最多6个不重复实体；没有递归触发。直接命中Boss/高HP护甲产生电弧时必须将该实体放在被电击目标里。
- 技能卡和暂停Build的展示同步真实增量，包括导电+2/3/4；无升伤害选项普通物理弹球直击仍1，速度330，视觉大小/碰撞半径分离保留。
