# 弹珠超载：移除激光流的验收记录（2026-11-03）

## 结论
删除激光作为第四个主流派的实验性实现；不并入 Demo 正式主线。原始激光实验保留在独立历史测试文件夹以供版本比较，但不代表已接受的产品设计。

## 审查依据
- 实验版 `laser` 是额外持续光束；原物理弹球仍按普通炮台逻辑发射。
- 光束升级主要缩短命中间隔、增加穿射数量；墙面反射为预设效果，并没有形成专属分支成长。
- 激光与原射击瞄准控制高度重合；不存在值得作为独立流派的独有抉择、风险回报或流派转折。
- 原先声称的光网与聚焦分支均未真正实现，不能以未来假设当作当前玩法价值。

## 删除范围
`demo/v1/builds.js` 中的激光定义、升级卡、成长、优先级、属性和混搭；`demo/v1/game.js` 中的持续射线、反射判定、伤害周期、绘制、计数、调试预设；`demo/v1/index.html` 中的第四流派与激光升级按钮；`demo/v1/style.css` 中的激光高亮。删除过期 laser-only 冒烟测试，三流派速测测试已更新。

## 保留
三大核心裂变/电弧/机枪、各自两条已有分支；相同第6波砖阵的直达按钮；暂停返回菜单；正常闯关；Boss10/20调试；B版打击感；危险线追踪。巨型球在速测模式仍不参与，但正常模式不受影响。
