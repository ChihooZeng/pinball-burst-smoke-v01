# 弹珠超载 · 六专精分支机制验证（2026-11-03）

## 范围

从三大核心/第6波一键速测版本 `codex/demo-v1-quickbuild-lab-20261101` 独立创建 `codex/demo-v1-six-branch-feel-lab-20261103`，未覆盖正式主线与原三核心速测对照。

目标是让每个专精分支改变战斗轨迹或目标选择，而非仅增加数值；激光已被移除，继续维持三核心。

## 六种互斥分支

| 分支 | 机制 | 对应可见/计量事件 |
|---|---|---|
| split-a 回旋星雨 | 裂变子球首次接触砖块后，回旋指向同一水平范围的另一个目标；不再因此额外生成球 | `storm_sweep` / `stormSweeps` |
| split-b 猎星裂变 | 裂变子球生成后主动对护甲目标进行有限次校准，墙面反弹后还可继续校准 | `childLocks` / `homingTurns` |
| arc-a 分叉雷网 | 击碎目标后在剩余跳转预算内分叉，顺序传导，单链最多6跳 | `relayForks` / `arc_hop` |
| arc-b 蓄能雷击 | 累积三次真实普通球命中后，在360范围内优先选择Boss、高HP护甲砖，集中单点放电，无群体链式传播 | `focusBursts` / `focus_discharge` |
| gun-a 穿阵机枪 | 每6发穿阵弹，最多穿过2块真实物理砖；等级2每5发；之后正常碰撞 | `needleShots` / `needlePasses` |
| gun-b 扇面齐射 | 三路扇角交替扫射，每6发在相反侧额外发1颗真弹；等级2每5发 | `fanExtraShots` / `fan_volley` |

三个核心、两分支互斥、升级总次数和现有球上限仍保留。并非六个彼此叠加的独立职业；这轮只对六种专精行为做验证。

## 人工试玩入口

在首页选择模式：
- 第6波密集砖阵：预配5次真实合法升级，测试范围伤害与清场；
- 第10波Boss+护甲：预配9次真实合法升级，测试单体压力与Boss；
- 选择六个分支中的任意一个即可立刻进入同一模式的相同砖阵。
- 速测禁用巨型球；暂停、结束界面可返回速测菜单；正常从第1波闯20波入口仍可用。

**两个模式之间的等级和技能数量不同；只能在同模式内比较。** 直达试玩不等于真实闯关胜利。

## 初步模拟验证

使用工具内 JS V8 Mock DOM/Canvas 及120Hz固定物理帧：
- 6×2=12组直达分支/场景均成功、同场景起始砖阵/HP一致；三大核心正常三选一仍能进入第2波。
- 在第6波运行360帧：回旋8次、主动追猎12次、电弧分叉13次、蓄能爆发2次、贯穿弹6发、侧翼齐射6次，六种特征行为均有实际计数。以上每种数值均为各自独立路线一次模拟，不能比较为平衡结论。
- Boss模式同样能进入第10波的128HP Boss，无巨大球技能混入。
- Node脚本已更新于 `demo/v1/quick-build-lab-smoke.cjs`，但**尚未在Node进程里运行**，不能声称该脚本执行成功；相同关键逻辑已在工具模拟中通过。

## 尚需验证

- Safari/Android 真机触控、声音、性能与60/120FPS。
- 六条路线在不同瞄准水平、不同目标布局下的优劣。
- 真实人类的主观爽感：同一人比较分支A与B，看得到行为差异吗？
- 分支等级2的演出、成长树与混搭融合尚未最终定稿。
- 炮台和巨型球独立技能**本轮不处理**。

## 产品建议

先让每条分支至少拥有一个真正改变弹道/命中机制的技能，再补中期升级，之后才统一做20关难度调参和Boss平衡；切忌因单次自动瞄准模拟的清场结果就宣称路线强弱或不公平。
