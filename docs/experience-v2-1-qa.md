## 手机战斗坐标

V2 的外框跟随外壳布局，Canvas 尺寸从窗口宽高另算。390×844 时，外框宽 370 CSS px，Canvas 实际宽 298.17 CSS px。玩家可以看到 Canvas 之外的装饰框，球却在 Canvas 侧壁反弹。

V2.1 先测量 HUD 和技能栏之间的容器，开局由此建立宽 360 的逻辑战场。运行中旋转或浏览器工具栏改变高度时重新适配同一战场。Canvas、霓虹边和触摸共享这一个 CSS 矩形，正式区域顶边对准原碰撞平面 y=4。左墙 x=0、右墙 x=360，球心按半径在墙内反弹。底边是画面边缘，球仍按原规则离场。设备 DPR 上限为 2，后备像素按实测尺寸四舍五入，再用实际后备像素和逻辑尺寸求变换。瞄准从同一个 Canvas 矩形映射，继续使用 A1-1 炮管原发射点。

## 紫色砖块

在相同布局和视口中捕获第 1、8 波，比较原紫色 `#C68AFF`、薰衣草紫 `#D6A8FF`、兰花紫 `#D99CFC`、浅丁香紫 `#CDAAFA`。采用 `#D6A8FF`，比原色更亮，同时和邻近蓝紫、粉色有清楚分界。砖面和辉光共用砖块色值。另四档继续为 `#6EE7FF`、`#7CC8FF`、`#A1A8FF`、`#FF8AEF`。原 UI/Boss 紫色独立保留。砖块浏览器回归覆盖 22 张截图、40 个生成样本、白字、普通 1HP 省略数字和特殊砖识别。

### 自动化通关与挂机

基线和候选均用真实 Chromium 运行原有物理更新，测试固定帧时钟和随机种子 `20261118`、`2701`、`781`。主动策略瞄准目前危险的列，每波按预先固定的优先序选卡。锁角策略在第 1 波仅为取得初始流派而主动瞄准，从第 2 波起锁定 `-0.53`、`0.43` 或 `0.71` 弧度，全程不手动使用主动技能。两版保留产品默认自动超载。另跑三场从开局即固定瞄准的严格挂机。

| 流派 | V2 固定角度 | V2.1 固定角度 | V2.1 主动 | V2.1 固定角度失败波次范围 |
| --- | ---: | ---: | ---: | --- |
| 裂变 | 3/9 | 1/9 | 3/3 | 4–17 |
| 电弧 | 4/9 | 1/9 | 3/3 | 4–19 |
| 机枪 | 1/9 | 0/9 | 3/3 | 3–13 |
| 合计 | 8/27 | 2/27 | 9/9 | 3–19 |

三场开局锁定均止于第 1 波。通过的两场固定角度分别是裂变种子 `20261118`、电弧种子 `781`，均为 `-0.53` 弧度。没有流派与固定角度组合通过三个种子。V2.1 固定角度终止局剩余 1–17 块砖，以最接近的砖从警戒线外进入 32 单位内计一次，共 44 次接近。主动场中 Boss 10 耗时 5.58–13.20 秒，终局 Boss 20 耗时 9.40–21.95 秒，每场均经历终局三个阶段。逐局记录见 `balance-results.tsv`，逐波清理时间、剩余砖块、接近警戒线次数和击败 Boss 耗时见原始 JSON。自动化通过证明同一机制下存在可行的主动打法，正式试玩反馈用于评估一般玩家的难度体验。

核心升至第 3 级后，通第 9 波可选 4 级，通第 14 波可选 5 级。仍由三个互异的有效升级卡选择，两条分支专精保留。下表采用同一 A 分支二阶专精并固定通用强化，用以比较 V2 原上限和 V2.1 上限。

| 裂变 | 5 子球，场内寿命 4.10 秒，残局追击 2 次 | 7 子球，4.70 秒，残局追击 4 次 |

## 技术回归

- Node 单元测试 10/10 和原始 smoke 测试通过。源码快照比对覆盖砖块构造、20 波生成、普通弹球碰撞、特殊球碰撞、Boss 阶段和击败函数。归一化仅包含顶墙常量名称和本次明确调整的残局引导阈值。原音频素材、A1-1 素材、中英文切换逻辑、隐私与统计服务通过内容对照。
- Chromium 在四个指定视口、两种语言检查界面，以及触摸、选卡、暂停、恢复、重开、失败提示和双语持久化。独立本地统计验证首次未同意不落库、主动同意、撤回和后台隔离。
- 真实 Chromium 渲染在四个密集场景与 Boss 场景采样约 59.7–60.0 FPS，帧间隔 P95 16.7–16.8 ms，采样内 50ms 以上帧 0。十次重开并主动 GC 后堆从 1,814,584 到 1,901,572 字节。性能结果来自本机 Chromium，移动尺寸通过仿真触摸输入验证。实体 iOS Safari 和实体 Android Chrome 本轮不可用。
- 按真实时间运行完整 20 波，测试程序仅发送 Chromium 原生触摸或鼠标输入，开局前移除可变 QA 钩子。三场移动模拟分别为裂变 360×640（223.9 秒）、电弧 390×844（286.5 秒）、机枪 412×915（338.2 秒），另有桌面 1440×900 鼠标电弧（278.5 秒）。四场均达本流派 5 级、完成 20 波、击败两个 Boss、经历终局 1/2/3 阶段，浏览器错误均为 0。逐局 JSON 和 5 / 20 波、终局、结算原始 PNG 同附。

## 回滚

1. 对外试玩立即切回原 [V2 已验收 HTTPS 入口](https://chihoozeng.github.io/pinball-neon-v2-preview/demo/v1/)。正式站无需操作。
2. 源码如需并排复核，在现有仓库执行 `git worktree add --detach /tmp/pinball-v2-rollback 9856139c72925ef9bfc51c051736780c141ae91e`。这会创建新目录，现有开发改动与工作树可继续保留。
3. 在新工作树用 `python3 scripts/package-release.py /tmp/pinball-v2-rollback.zip` 打包，解包后运行 `shasum -a 256 -c SHA256SUMS`，再用 Node 启动并从浏览器验证主页、开始游戏和静态资源。
