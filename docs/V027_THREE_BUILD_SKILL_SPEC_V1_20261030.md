> 首批三条实验路线：**裂变 / 电弧 / 机枪**。这三种是“构筑方向”，**不是初始职业**，持续保留同一炮台和物理反弹核心。

## 0. V1 的决策边界
**已确认的方向**：
- 一局到底、真清屏、整波下降、波末三选一；10–20波有完整成长体验，50波为高阶目标；每波仍成长，关键节点进化。
- 先验证三种不同的爽感：裂变＝场内球数量自增；电弧＝伤害在目标间传播；机枪＝从炮台高频射出弹球，具有直线和扇形扫射分支。
- 史诗/传说有稀有度与惊喜，但基本完整构筑不依赖抽中传说。
- 特殊砖**只提供战斗中的即时或临时强化**（建议15/30秒），按有效实战时间计时，**暂停/升级/过场时停表，可跨波保留**，**不提供永久升级或进化碎片**。清屏时移除物理弹球，但不清除尚有剩余时间的Buff。
- 所有技能以真实弹球反弹为中心；已认可的 v0.25/v0.26 核心玩法和霓虹视觉不可随意重构。

**尚待实测批准**：所有数值、概率、技能名称、主核心占用、Boss额外奖励的具体形式、神器槽位、0.27分包顺序。Codex应把它们放在配置表，便于单独调参；不要视为最终平衡定稿。

## 1. 已核对的 v0.26 代码事实
来源：compare/hybrid-v26-wave-level/game.js（GitHub main，2026-10-30审阅）
- 现有限制：MAX_BALLS=32；普通基础发射间隔1.14s，射速训练每级缩短0.075s，代码下限0.69s；BALL_TTL=8.4s；普通子弹为真实反弹球。
- 技能注册：rate/speed/life/power/volley/split/arc/drill/shock/hunter/ricochet 11种；现有 cap 分别为5/4/4/3/2/2/2/2/2/2/2。
- splitAt：普通球首次撞砖后分裂一次，一级2颗子球、二级4颗；小球默认不可再次裂变。
- triggerLightning：有效撞击按 contacts 门槛触发、附近目标传播；闪电间接伤害不应递归重复触发。
- skillStage 和 eligibleSkills 按LV阶段逐渐开放技能；offerChoice 用排序构建三张卡；chooseUpgrade 更新各自级数；不支持核心、分支、稀有度、进化条件。
- 完整清屏时清空 balls/giant，level+1、choiceQueue+1；击砖不升等级；Boss第4、8、12…波生成，但目前不单独赠送奖励。
- 现有 special 砖：击破时更快提升主动技能能量，未实现15/30秒Buff；且“仅直接击破才获得额外充能”的实现与未来“特殊砖无论伤害来源击破均生效”规则不同。
- MAX_WAVES=10 目前只用于诊断显示；代码不等于已完成50波规则和平衡。正常实际波次数值与难度另外验证。

**关键技术决策**：机枪必须新增发射间隔/弹球寿命管理，不能依靠把旧 rateLevel 提高来实现；升级系统应升级为数据驱动定义，而不是再增加一组散落的全局变量和 if 分支。

## 2. 统一技能数据与状态模型
每个技能配置：id、name、family、role（core / base / auxiliary / branch / rare_mod / epic_mod / legendary_mod）、rarity（common/rare/epic/legendary）、maxRank、prerequisites、minClearedWave、excludedWith、triggerEvent、triggerCondition、effectParams、cooldown、perWaveLimit、ballBudget、bossFallback、upgradeCost、testCounters。
独立追踪三种概念：
1. **强化等级** rank：普通能力强化了几次。
2. **进化阶段** evolution：基础能力 → 分支 → 终极机制。属于**可预期构筑**，不能靠极低概率才能触发。
3. **卡牌品质** rarity：卡片出现稀缺性和特殊规则强度。传说是意外惊喜，不能作为通常进化的必备前置。

建议状态字段：seedAbility、coreFocus（nullable，前期尚未选择）、coreRank、coreBranch、coreUltimate、auxiliarySkills、selectedActive、equippedArtifacts、rareModules、temporaryBuffs、choiceHistory、pendingRewards、eventCounters、buildTags。
允许拥有辅助效果，但**仅一条核心路线能完成本轮的终极进化**；辅助之间的数量与神器槽位仍属原型候选。首次验证建议“主核心1、主要辅助2、主动1、神器2（装备上限）”，并允许通用炮台基础强化独立累积。

## 3. 三种核心能力：可实现规格（参数是起始测试值）

| ID | 核心 | 初始技能（开局三选一；不是职业） | 两次机制强化 | 明确差异 |
|---|---|---|---|---|
| CORE-SPL | 碎星裂变 | 一颗非子代的普通球累计**2次有效撞砖**后，生成1颗真实小球；同一父球最多触发1次 | Rank2：触发时2颗小球；Rank3：改为首次撞砖后2颗小球 | **弹球在场内增殖**；子球默认不能继续产生子球 |
| CORE-ARC | 电弧印记 | 由普通球直接撞砖累计3次触发一次向附近1块存活砖的电弧，距离≤110px | Rank2：每2次有效直接碰撞触发，最多2目标；Rank3：最多3目标，距离≤140px | **间接伤害传播**，少球也能打多块砖 |
| CORE-GUN | 高速供弹 | 炮台基础自动发射间隔设为0.35s；每次仍发射一颗真实物理弹球，单颗TTL暂定2.4s | Rank2：0.27s；Rank3：0.20s；所有数值可调 | **从炮台持续快速发射**；不靠撞击生成额外弹球 |

**关键限制**：
- 三条核心开局必须拥有可见破坏行为。第一波不要等至波末才让玩家感到不同。
- 分裂触发只计 ball direct hit，不计电弧/震荡造成的间接损伤；防止无限回调。
- 电弧积蓄可以由直接命中供能，不以每颗机枪子弹独立抛骰来倍增：同一能力的实际电弧释放有**全局最短间隔0.45s**作为首轮测试值。Boss没有其他可传播目标时，积攒电荷并转化为有限直接单体放电，不允许完全空转。
- 机枪弹球仍然撞砖/撞墙反弹，并非一撞就消失的射击子弹；短TTL是控制场内数量与强化炮台持续输出的辨识度。平均留场球量约为 TTL÷发射间隔，仅作估算，不替代真实测试。
- 炮台瞄准由原触控方式控制。机枪不新增必须按住射击的操作，保持手机单指可玩。

|---|---|---|---|---|

| BR-SPL-HUNT | 分支：猎星裂变 | 同上；与STORM互斥 | 每次触发2颗子球，子球墙面反弹后可有限次轻量追猎 | 单体、残局更稳定，群体数量较少 |
| ULT-SPL-STORM | 正常终极：星潮回灌 | STORM + CORE-SPL Rank3；建议清屏≥12 | 每累计6次子球**真实命中**，生成1颗普通强化球，≥2s全局冷却；每波次数可控 | 少目标时根据实际命中累计，不能无目标自动爆球 |
| ULT-SPL-HUNT | 正常终极：星核围猎 | HUNT + Rank3；同窗口 | 子球连续命中同一存活高HP目标后叠加“锁定”，下次真实撞击额外伤害，单目标≥1.5s冷却 | 专门改进Boss/残砖，保留物理命中要求 |

分支和正常终极**不属于需要抽到传说才能完成**的成长；达到条件后提高相关卡可见性并有阶段保底。

### 3.2 电弧：两条互斥分支与正常终极形态

| ID | 阶段 | 前置 / 获取 | 机制 | Boss / 尾砖 |
|---|---|---|---|---|
| BR-ARC-NET | 分支：雷网蔓延 | CORE-ARC Rank≥2；清屏≥4 | 电弧优先寻找不同目标并跨距跳转，最多3跳，传播到不同砖块 | 目标少时退化为有限单体电荷，不“凭空多跳” |
| BR-ARC-FOCUS | 分支：雷霆聚能 | 同上；与NET互斥 | 电荷优先集中于被命中的目标，达到阈值造成一次额外单体放电 | Boss / 高HP更有效；群体影响范围较小 |
| ULT-ARC-NET | 正常终极：雷暴共振 | NET + CORE-ARC Rank3；清屏≥12 | 一次传播命中≥3个不同砖块时，为这些砖留下可见短电荷；随后真实命中引爆局部范围，最多2个次级目标 | 无足够邻居时只保留对自身的回响伤害 |
| ULT-ARC-FOCUS | 正常终极：雷暴聚核 | FOCUS + Rank3；同窗口 | 对同一存活目标积满4次有效电荷后触发集束爆发，短冷却 | 针对高HP和Boss的持续压制型机制 |

电弧衍生伤害只可扣HP；**不可再产生新的电弧、震荡、裂变及主动充能递归**。

### 3.3 机枪：两条互斥分支与正常终极形态

| ID | 阶段 | 前置 / 获取 | 机制 | Boss / 尾砖 |
|---|---|---|---|---|
| BR-GUN-LINE | 分支：直线压制 | CORE-GUN Rank≥2；清屏≥4 | 按原瞄准方向集中扫射；发射间隔测试0.17s，角度微小抖动 | 对单体持续命中、强调精准瞄准 |
| BR-GUN-FAN | 分支：扇形扫射 | 同上；与LINE互斥 | **连续单颗发射**，枪口方向在±0.28rad范围内往复扫描；间隔测试0.18s | 大范围清场，单体效率低于直线；不是一次射出5球 |
| ULT-GUN-LINE | 正常终极：穿针火力 | LINE + CORE-GUN Rank3；清屏≥12 | 每累计30次发射获得2s“超载扫射”窗口，射击间隔测试0.12s；≥10s冷却 | 单体压制；遇同一目标连击时强化命中特效 |
| ULT-GUN-FAN | 正常终极：极限横扫 | FAN + Rank3；同窗口 | 每累计30次发射获得2s高频扇面往复；发射间隔测试0.12s，覆盖角随周期渐变 | 多目标扫射；不会无代价同时获得直线分支 |

**机枪平衡强约束**：
- 旧 rate 加成对机枪采用独立缩放与最短间隔，不可与分支简单线性相减到0秒；物理碰撞时间步长也不得与超短射击间隔互相混淆。
- 机枪平均弹球寿命设计短于普通流（初始2.4s，随续航提升），但始终是真实反弹；极限射击时优先保证机枪基础发射，再按预算生成额外裂变球。
- 现有“散射进化”同时发射多球与新扇扫概念冲突：**v0.27首测先从三条核心池中排除旧 volley 作为机枪的叠乘升级**；可保留在原v0.26对照版。
- 拥有辅助裂变的机枪不能自然获得完整裂变流的最高阶增殖树；避免三条流派最终趋同。

## 8. 升级次数、候选池与稀缺性的V1预算
**已经确认**：每完成一波至少一次普通三选一（v0.26规则）；第4、8、12…波为Boss挑战；特殊砖不提供永久升级。
**待验证候选**：开局从3种 seed 中选1；清第2波后多一次基础强化；第4/8/12…波在普通升级之外多一次**Boss特殊选择**。则累计选择次数：
- 第8波：1开局+8普通+1早期+2Boss=12次；
- 第12波：1+12+1+3=17次；
- 第20波：1+20+1+5=27次；
- 第50波：1+50+1+12=64次。
这些数字只是成长选择预算，不是独立技能数量，**Boss奖励额外发放尚待验证，不能在未签核前假定已实现**。

### 8.1 三选一候选算法（首测提案）
每次波末生成3个**互不重复、当前可用**的选项；先过滤未解锁、已满级、前置不满足、互斥路线、已装备且不可叠加项。
- 槽位A“方向”：如果已有明确偏好/主核心，优先提供该路线的有效强化或可进化候选；若无主核心则展示可能选择的基础方向。**保底的是相关选择出现，而不是保底传说出现**。
- 槽位B“稳定”：炮台/辅助短板的通用有效强化，不要出现已满级或毫无效果的废卡。
- 槽位C“探索”：跨流派辅助、融合、稀有/史诗候选或随机新能力；可通过稀有度池调整。
- 允许灵活打破固定槽类别以避免每局套路相同，但A的成长保底不应失效。
- 如果当前候选不足3个：从未满级的通用强化/临时“选一个当前能力强化”中兜底，**禁止重复同一张卡充当多个选项，也禁止悄悄吞掉升级机会**。

### 8.2 核心进化保底
- 初始能力在第1波就有效；第3–4波争取已有一项有意义的联动。
- 核心 Rank≥2 且清屏≥4 时开放分支；如条件已满足，**第5–8波的候选池至少一次保证出现对应分支选项**（若两分支都合格，可在一次菜单同时出现；由玩家决定）。
- 已选分支且 Rank3、清屏≥12 时，**第13–20波至少一次出现正常终极进化候选**，不受传说抽取率影响。
- 未选择某张进化卡不等于永久错过，后续仍可再次出现；但每次选择都消耗一次升级机会。

### 8.3 品质概率（仅为每次完整三选一界面的实验起始值）
| 已清屏波数 | 史诗候选（概率） | 至少一张传说候选（概率） |
|---|---|---|
| 1–4 | 暂不投放 | 0% |
| 5–8 | 约2–4% | 约0.5% |
| 9–20 | 约5–8% | 约1% |
| 21–50 | 约8–12% | 约1.5% |

概率表示：**在具备符合资格的卡牌前提下**，该界面“至少出现一张相应品质卡”的概率；不是每个卡槽的独立概率。实际候选池无符合资格的卡，不能通过降低前置条件强行塞一张；本轮只制作概率工具与可配置权重，**不把这些数字视为最终发行值**。
- 不使用“强迫连续失败才能开出传说”的隐藏机制；保底只保障基本 Build 进化。
- 通常最多一个传说模块参与实战（首测候选；获得第二张时可替换/拒绝，避免无上限传说累加）；史诗与传说都消耗成长预算。
- 普通升级三选一和Boss特殊奖励使用分离的池；Boss不能每4波固定赠送传说。
- 调试接口允许固定seed、强制稀有候选、强制分支/融合，用于可重复测试，**不得把测试入口暴露给普通用户界面**。

## 9. Boss、特殊砖、主动技能和神器：首测的最小接口
- Boss继续每4波一次；**波次结束才结算额外奖励**。第4/8波可以测试“神器/主动替换/特定进化资格三选一”，三选一是一次奖励，不是同时获得全部。
- 主动技能先保留巨型球（giant），后续为替换active预留接口；v0.27**不必同时开发多个主动技能**。
- 神器建议最多同时装备2件，首测仅需一件规则型样例（如少目标时定向伤害补偿），替换与无效奖励回退要定义；后续版本扩展。
- 特殊砖（独立能力系统，不参与永久成长）：击碎后触发15s或30s战斗强化；以实际战斗时间倒计时，升级/过场/暂停冻结；跨波Buff保留、旧球照常移除；相同buff刷新而非无限叠加，不同Buff可有限共存；任何合法击破来源触发一次，同一砖不能重复激活。
- 对特殊砖的现有“能量加速”实现，需在开发相应子版本时明确是否保留为瞬时奖励的一种，**不可被当作永久构筑资源**。
- 清屏后计时Buff保留但**不自动携带场上弹球**。Buff显示剩余秒数与类别，避免玩家误以为奖励被吞。

## 10. 单体与残局适应：不能靠无限刷砖
- 每个正常核心路线必须在仅1个Boss/仅1–3个残砖情况下仍有有效击破方式；对网状裂变、电弧特别检查。
- Boss单独留场时可使用有限弱点窗口或可破坏的附属物，但不允许无限召唤支持砖强行延时。
- v0.26已有尾砖HP软化策略；不能把“尾砖击破体验”作为罕见神器的唯一解药。
- 所有额外伤害必须区分 direct_hit 与 secondary_damage；主动充能、裂变、电荷、震荡回调处理需要明确来源标签与递归保护。

## 11. 性能预算与可重放的验证标准
暂时沿用 MAX_BALLS=32 作为**旧版性能参照**，不直接宣称可以把上限翻倍。通过弹球TTL、发射预算与出生优先级共同控制；当处于上限时不得静默丢失大量“机枪”火力而导致手感失效，需要输出可见的临界反馈并记录被抑制次数，必要时再测碰撞优化与更高预算。

建议埋点：shotsFiredByBuild、directHitCount、secondaryDamageCount、spawnedMiniBalls、suppressedProjectiles、livingBallsPeak、legendaryOffers、selectedRareCards、evolutionOffers、coreBranchSelectedWave、ultimateSelectedWave、damageBySource、bossSoloDuration、waveDuration、fpsP50/P10、cpu/frameStepCost、buffRemainingAcrossWave。
**至少保证：**
1. v0.25与v0.26入口不变；v0.27新建独立 compare/hybrid-v27-buildlab，不覆盖基线；基础碰撞、清屏、Boss、移动端单屏不回退。
2. 开局三种 seed 都在第1波生效；机枪真实射速明显快于普通、扇形连续逐发扫描而非同帧多球；机枪命中反馈可读。
3. 第1–8波升级和进化条件可以自动回放；保证三选一不重复、不空白、不提供失效技能。
4. 同一随机种子下，裂变、电弧、机枪的主要伤害来源和视觉表现显著不同；不只比较总DPS。
5. 独立测“纯流派、弱势选择、跨流派辅助、人工固定传说卡、仅剩Boss、仅剩尾砖”的路径，测试两分支与融合互斥。
6. 30/60/120Hz模拟一致（游戏逻辑固定120Hz），真实手机至少覆盖390x844、375x667、320x568单屏；性能过低自动降特效但保持物理伤害一致。
7. v0.27中不允许出现直接伤害、闪电、裂变、震荡无限互相触发、无限弹球出生或因发射上限导致机枪彻底失去核心玩法。
8. 特殊砖Buff 15/30s、跨波保留和暂停停表必须单测；不要先让该系统承担永久技能成长。
