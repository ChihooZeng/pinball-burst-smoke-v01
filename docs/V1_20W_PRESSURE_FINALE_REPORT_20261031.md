# 《弹珠超载》20关高压终局开发记录（2026-10-31）

用户真人试玩发现旧20关的11–20关HP过小、阵型同质化、缺少下降压力和挑战；要求有压力的爽快，最终第20关大额Boss和多波次砖。正式完整目标50波持续Build，本次仅20波独立实验。

## 实现
- 11–19关：双翼、漏斗、斜通道、压力门、双走廊五种阵型轮换；高低HP砖相邻且数字逐波增加，普通砖大部分至少2HP。11关69砖，总1154HP、最高43；15关71砖，总1635HP、最高69；19关75砖，总2480HP、最高92。特殊临时Buff砖仍可能1HP。11–19额外下降倍率从1.028逐波升至1.252。
- 20关：大型116×74、**888HP** Boss，外围大额砖、下方中央真实弹射通道。第1阶段起始；Boss剩HP≤70%或战斗24秒触发第2波；剩HP≤35%或战斗46秒触发第3波。每批最多15砖，1.35秒虚线预告，不与Boss/旧砖重叠、不无限补充。Boss死亡后新增砖仍需真实打碎；正常波仍仅清屏后进下关。
- 开始页保留直达Boss10，新增直达Boss20，并允许裂变/电弧/机枪选择，给9或19次合法升级Build用于实验；跳关不当正常通关。基础伤害1、球速330、手机全屏等原本已确认内容不变。

## 已做检查
1. 新JS语法解析通过。
2. 实际地图生成器在三种手机顶部偏移下全部1–20关HP合法、无砖砖重叠，最终Boss碰撞体与砖无重叠、下方弹射入口开放。
3. 三核心完整19次合法升级的跳关Build测试通过。
4. 阶段排队逻辑独立模拟在HP615、298时可各排15块、含阶段事件，不重复生成。
5. 所有实验代码在独立目录，不覆盖旧20关或默认入口。

## 未通过

## 首次线上机枪验收发现并修复的缺陷
首次Chrome线上试玩直达20关，确认888HP Boss可实际被击碎，但旧实验值下机枪26秒触线失败、Boss在第二阶段已被打死，第三批砖可能不出现。这不能算终局合格。已修复：终局Boss显示阶段护盾，阶段1最低621HP，阶段2最低310HP，第三批砖预警时最低1HP，预警生成后才能击杀；最终护甲上层改43–66HP、两翼32–51HP；两批增援砖改更轻的反弹构筑（最高约58HP）；终局下落阶段倍率0.24/0.32/0.40。同时修复长屏召唤砖下边界未随DANGER_Y更新。更新后仍需再次浏览器验收、真人与全20波回放，不得沿用旧机枪26秒失败当作新结果。

## 2026-10-31 最新独立线上浏览器回归（w20f3）
页面可打开；选择机枪Build直达20关时Boss初始888/888，第1阶段正常，进而确认到第2/3阶段，再进入第3/3阶段；砖数约从29增长到44、56，说明有限的分批增援砖确实进入战场。阶段护盾防止Boss在第2阶段就死亡，页面没有明显重叠或卡死。**但无主动瞄准的浏览器自动游玩仍于55秒因触线失败，仅打碎约3块普通砖**。这代表工程机制运行，而**不是20关终局可通关/手感达标**。下一轮需要真人用三流派瞄准体验，核对第20关能否在危险线前清屏；若失败过多，优先微调终局砖阵体积、后期清扫奖励、下降速度，不要恢复隐式基础伤害2。测试报告仅代表自动浏览器一次试验，不能推断真实玩家必败。
