# 六分支速测反馈修复 · 击中重量与巨型球（2026-11-03）

## 玩家反馈
- 当前六分支试玩版打击感偏轻。
- 巨型球技能在速测里消失。

## 代码原因
`quickLabActive` 在上一版被用于隔离流派对比，却连带隐藏巨型球按钮、禁止 `fireGiant`、屏蔽自动释放。并非巨型球资产或玩法已删除。

## 已修复
1. 六个分支×两种测试场景开始后，巨型球按钮持续可见且立即 100% 能量。
2. 速测中巨型球改为**手动点击释放**：不会开局自动抢先出手；释放后正常扣除能量，真实物理撞击、时间条、穿透等原逻辑不变，杀砖后可再充能。
3. 正常20波入口依旧遵守用户的“充满后自动释放”设置；无需改变正式主线体验。
4. 默认特效切换到“强化击中”（punchy）：高HP砖局部位移稍明显、碰撞短闪更亮、短环略粗、碎片微增、击中声新增短促低频身体感。
5. 旧“B版·轻快（对照）”、更轻、关闭选项仍可在暂停设置里切换，防止以前的“厚重感”卷土重来。
6. 主要增强**局部砖块接触反馈**，未给每一次耐久下降加全画面震动、长音或强制停顿；战斗数值、掉落、Boss血量和六种分支机制保持不变。

## 验证
用 V8 模拟 DOM、Canvas 和固定120Hz物理帧测试：12组（六分支×密集场景/Boss场景）起始巨型球能量100%，手动可释放，确实生成巨型球并命中实际砖块，释放扣能量，返回菜单正常；首波普通三选一未受影响。“强化击中”与两个B版预设的模式切换验证通过。

**未验证**：人类主观打击感、手机Safari触控/听感与性能；不能认定本轮参数就是最终版本。
