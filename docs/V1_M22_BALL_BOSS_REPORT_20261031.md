# 《弹珠超载》M2.2 真实穿缝碰撞与Boss压迫修正（2026-10-31）

> 源自已上线M2.1用户的第二轮体验反馈；在独立`codex/v1-m2-2-compact-ball-boss`、`compare/hybrid-v1-m2-2/`中执行。完整产品仍50关连续成长，首版Demo目标20关；原M2.1和20关高压基准保持不变。

## 变更
- **视觉/物理半径解耦**：普通球显示半径3.45，实际碰撞半径2.7；绘制球与拖影取`visualR`，砖与墙碰撞取`r`。直径分别6.9/5.4。裂变子球两个半径同按0.83缩小，钻头球两个半径同按1.35放大，原巨大主动技能球不变。导出本局诊断包含`shotRadius`与`shotCollisionRadius`。物理判定小于视觉意味着贴砖时可能有少量视觉接触；要由真人确认没有明显穿模。
- **间距**：普通砖高22、行距33→31，净上下缝11→9，仍容得下碰撞直径5.4，画面直径6.9也低于9。左右间距38.5保持，净水平缝9.5。纵向补偿参数读取新行距，不另改普通关卡下落数值。
- **第10关Boss**：25护甲环＋10引导砖沿用；原7秒一次、上限12块（可能只是招募既有砖）改为**4.6秒一批，每批最多4块真实新砖，总≤23，场上活辅助≤16**，优先顶层与侧翼安全槽，保留Boss下方中央三列入口；新砖真实HP8–20、1秒预告、须通过实体不重叠与总预算。Boss死亡后的辅助处理依照M2.1旧版规则。第10关Boss下落系数0.9→1.04（相对专用系数，约+15.6%），但纵缝变小使首波起点略高，应以真实危线时间衡量。
- **第20关Boss**：888HP/3阶段/可见阶段HP护盾和最终真清屏仍保留。阶段2/3砖阵计划数量各≤18（从15提高），备用上方位点上限16；Boss专属下降阶段倍率0.24/0.32/0.40→0.29/0.38/0.47。仍需1.35秒预警、禁止堵中央射入通道、无无限召唤；不会新增技能奖励。
- **不变**：普通球未选伤害加成时直接命中1HP、球速330、三流派、电弧R1/2/3多目标与有限击碎续传、20关Demo/50关长期目标、11–19密度、完整的手机视口和右上设置。

## 已实际验证
1. JS源码语法解析通过。
2. 从原M2.1生产生成器将纵向行距31应用于实际1–20关，在三种手机上边界84/105/121检查没有砖块两两重叠或Boss实体重叠；第10关仍25高HP护甲＋10引导砖。
3. 第10关真实召唤函数通过6组场地组合（3顶部×2高度），分八次尝试按4砖生成，约22块真实砖入场，最多16块辅助存活（模拟过程中清除6块），实体重叠检查无异常；实际20秒内是否完整触发由浏览器验证。
4. 第20关阶段计划函数在不同画面高度模拟第二、第三批分别能排最多18块，不代表实际战斗每次都能生成18（受现场已有砖占位）。
5. 普通球可见直径6.9/碰撞直径5.4，纵向净缝9，理论上真正可穿；本项只证明几何可行性，不等于真人看到持续穿缝弹反。
6. 基础伤害1、球速330、无增发永久升级和50关连续成长目标不变。
