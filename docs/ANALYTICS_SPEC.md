# 《弹珠超载》V1.0 玩法统计

静态包、默认 Node 服务及新浏览器的玩法统计均默认关闭。启用 Node 统计配置后，玩家可以在首页或设置中自行选择。撤回会同步更新开关，清空页面未发送队列，删除本地统计访客 ID，后续新开局继续可玩，刷新后仍关闭。已经送达的记录按服务的留存周期处理。

## 上报和存储

- `POST /api/events` 与试玩同源。客户端用随机访客、页面访问、局及事件 ID 关联数据。每批最多 24 条，SQLite 按事件 ID 去重。
- 游戏事件包括访问、开局、教程完成、波次开场和清场、选卡、流派、Boss 开场和击败、暂停和恢复、触线失败、通关、重开、退出及局内心跳。QA 跳关练习局跳过上报。
- 服务校验事件名、语言、波次、时长、流派、卡片及原因。粗粒度市场分类由受信任代理配置提供，缺省为 `unknown`。事件表不存原始 IP、用户代理或玩家输入。
- 传输失败时在页面内保留有界队列，重试去重。SQLite 设为 WAL，服务清理超过 90 天的事件。数据库路径应放在版本目录之外。

## 统计查看和验证

- `/analytics/` 提供查看页，`GET /api/dashboard` 要求 Bearer Token，支持 1、7、30、90 天窗口。
- 源码工作树运行 `node --test tests/release/services.test.mjs` 检查数据过滤、去重、留存和广告禁用。使用独立 QA 数据库运行 `node tests/release/analytics.mjs <QA Token文件> <新JSON路径> <本机服务origin>`，验证浏览器撤回同意、后台聚合和 SQLite 落库。QA 记录不应进入生产库。
