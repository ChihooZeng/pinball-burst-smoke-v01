## 0. 产品灵魂与设计判断

《弹珠超载》不是靠技能数量取胜的“技能收藏游戏”，而是 **玩家亲自把一台破坏机器构筑成越来越独特、越来越强大的弹球连锁系统**。主要乐趣是：真实物理反弹、大量弹球在密集砖阵中反复撞击、砖块数字快速降低、连锁破碎、整波真正清屏。保持目前深蓝霓虹 + 清晰彩色数字砖 + 手机单屏为视觉基线。

已认可的整体方向：**以「A：构筑越来越夸张的破坏机器」为核心，以「B：适度挑战与策略应对」提供起伏和重玩。** “70% 破坏爽感 / 30% 构筑与挑战”是**定性设计准绳**，不是游戏统计参数或必须严格执行的数值。

不是要让全程始终最大特效：玩家体验必须有 **初始爽感 → 成长与挑战 → 组合质变 → 集中爆发 → 新压力 → 新突破** 的节奏。任何技能、特殊砖、阵型或 Boss，都必须说明服务于哪一段节奏、为什么增加爽感、会否造成等待与中断。

## 1. 三层游戏闭环（方向确认）

1. **即时破坏循环（秒级）**：发射 → 连续碰撞 → 降 HP → 砖块粉碎 → 连锁触发/更多弹球 → 再次碰撞。保证视觉可读性和反馈节奏。
2. **单局成长循环（波级）**：遭遇新阵型/障碍 → 获取成长资源或升级机会 → 玩家选择技能 → Build 改变破坏方式 → 新一波验证 → 展示强力效果。
3. **重开循环（整局）**：尝试不同起始能力和升级顺序 → 发现联动或失败短板 → 解锁或认识新的组合/挑战 → 希望用不同 Build 再玩一次。可考虑轻量局外解锁，但**不优先做永久数值碾压**。

核心闭环应为：**开局就有特别的破坏能力 → 击碎特殊砖获得当前波次的短期爆发 → 清屏获得永久成长 → 形成个人 Build → 阵型与 Boss 检验并展示能力 → 进化/神器制造新高潮 → 冲更高波次 → 失败后尝试另一种组合。**

## 2. 保留的当前已实现规则：v0.26（不要把设想写成实现）

- 一局到底，单炮台，真实弹球；整波生成密集砖阵并缓慢下降；**普通波次中途不持续补砖**；全场所有实体砖（含 Boss）真正清理完才进入下一波。
- 完成一波 → **LV +1，进行一次三选一升级**，而不是击砖获得经验后当场升级；结束时清除上一波所有在场弹球（含巨型球）；选完技能后庆祝/虚线预告，再开始下一波。局内 Build 跨波次持续。
- 现有主动技能是巨型球；现有强化包含射速、火力、球速、续航、散射、裂变、电弧、震荡、钻头、追猎、蓄能等。这些是临时能力池，未构成系统化流派。
- 大致每第4波 Boss（4/8/12…），Boss 可有限召唤辅助砖，且必须清完本波剩余砖。现有数值（下降速度、78砖、HP、Boss HP）是可调测试参数，而非锁死规则。
- **现状问题**：前1–2波基础输出单调、巨型球承担过多清场职责；第4波前成长不足；Boss 核心单独剩下时容易拖沓；后期阵型/技能互动单一；尾砖难命中。

## 3. 单局时长与情绪节奏：工作假设，待真人验证

- **工作目标**：以约 **10–15 分钟**形成一局的完整成长体验；不是强制终止时间，也不是现有 v0.26 已达到的时长。高手可以继续冲波；新手在较早失败前也要体验到一次组合破坏高潮。
- **第1–2波 / 开局就好玩**：进第一波前就有**弱但明显的特殊破坏能力**，可观测到额外破坏；第一波不应是沉闷的升级前置。每波清屏的固定升级规则保留。
- **第3–4波 / 第一组联动**：两项能力出现可辨认的联动；第一次 Boss 检验初步 Build，而不是逼玩家只能开巨型球。
- **第5–8波 / Build 成型**：形成明显的独特破坏方式；足够密集的阵列让其展示威力，第二次 Boss 检验成长。
- **第9–12波 / 爆发高潮**：弹球能力、主动技能、神器等可形成质变与融合；游戏通过关卡表现玩家确实变强。
- **第13波以后 / 高阶挑战**：新阵型、规则变化、Boss 机制、进化目标与冲榜/挑战，不依赖无限提高砖块 HP。
- 这些波次是**体验里程碑**，必须通过真人试玩的波次耗时、失败原因、技能成型时点调整，不能直接当作版本排期或关卡定稿。

## 4. 未来系统分工：方向认可，具体规则未定

| 系统 | 应承担的职责 | 避免的偏差 |
|---|---|---|
| 炮台基础能力 | 射速、火力、发射数量、基础控制和持续输出的稳定增长 | 把所有成长压成不可见的小幅百分比 |
| 弹球能力 / 流派 | 裂变、连锁、穿透、追猎等**撞击后的不同物理与连锁结果** | 看起来换皮、实际上只改伤害数值 |
| 主动技能槽 | 玩家充能后主动触发爆发或救场；巨型球只是候选之一，未来可考虑波末更换 | 所有构筑都被迫依赖巨型球；战斗中频繁切换产生复杂操作或充能漏洞 |
| 神器 / 被动规则 | 用少数稀有规则改变 Build 性质，例如尾砖收尾、对单体 Boss 的补偿 | 仅仅改名为神器的 +10% 伤害 |
| 特殊砖 | **只提供即时效果或15/30秒短时能力增幅（可跨波保留）**（如临时裂变、射速、连锁、超载），击碎立即触发，不弹窗 | 把必破坏的特殊砖变成永久技能/进化资源/额外升级来源；让战斗频繁暂停 |
| 砖块阵型 | 用反弹通道、密集程度、局部薄弱点和特殊摆放，改变不同 Build 的表现 | 每波仅增加 HP 但玩法无变化 |
| Boss | 让 Build 充分发挥并产生针对性挑战、阶段变化、可破坏部位或特殊窗口 | 只剩一个大血条反复单点，清场爽感中断 |

初步倾向（**尚未批准为实施方案**）：开局只做一次**基础弹球能力三选一**；巨型球暂作默认主动技能，后续通过特殊奖励获得其他主动技，在**波次结算**而非战斗最激烈时更换；神器与主动技能不同，神器偏持续生效。**特殊砖只负责局内短期爆发，不提供永久升级、进化碎片或额外技能资格。** 其战术意义来自玩家击破的时机、当时弹球密度和阵型位置，而不是能否在清屏过程中获得掉落。临时增幅按有效战斗时间计时，过场暂停计时，未到期Buff可跨波保留；清屏时仅强制移除弹球。永久成长由波末升级、Boss 奖励及未来另行设计的成长节点承担。

## 5. 波次体验不是只加 HP

下一阶段可以比较：**爽感展示波**（密集低中 HP 让新能力明显发挥）→ **压力挑战波**（阵型、特殊状态考验 Build）→ **Boss 检验波**（有阶段与互动，同时保留破坏快感）→ **新的成长突破**。

上述是节奏设计模式而非固定每3波轮换的规则。不能每次都给玩家最克制/最适配他 Build 的阵型；保留不确定性和路线差异。**Boss 是 Build 的展示舞台，不是长时间拖延的孤立血条。**

## 6. 已明确的设计原则 / 验收问题

- **开局就好玩**：第1波应能制造肉眼可辨的特殊破坏，不必等几波才获得真正能力。
- **升级可感知**：玩家选择新能力后，下一波能明确感到差异，而非单纯数值加一点。
- **Build 可成型**：玩家不能因核心技能完全抽不到而在能力成型前失败；也不能永远固定最优解。
- **保留瞬时连击**：特殊砖击碎后立即触发短期爆发，战斗中不弹出升级选择；波末才进行永久成长结算。
- **挑战产生新爽感**：阵型/Boss改变破坏过程，不通过无聊耗血延长时长。
- **重开有动力**：每局留下组合发现、挑战记录、新能力解锁等成果；不要先用永久数值加成填充重玩理由。
- **尾砖问题是基础节奏问题**：神器“最后1–2块降至1HP”可作为强化候选，但不能用稀有神器掩盖常态尾砖难命中的基本体验问题。

## 7. 下一步讨论：成长选择的自主权与随机性

**本轮尚未锁定**职业数量、流派条数、神器数量、起始技能、升级概率、技能槽上限、进化配方、波末多重奖励等，不要擅自开发。

优先讨论以下系统级取舍，然后再设计技能清单：

1. 玩家能否预期并实现想玩的 Build：**自由选择 / 完全随机 / 有引导的随机** 如何组合？至少能否在中前期锁定一个破坏方向？
2. 三选一候选如何分配：稳定底盘、已有路线的进阶、跨流派的新可能分别扮演什么角色？允许多少次重抽或定向选择，代价是什么？
3. **特殊砖定位已锁定**：只提供短时增幅或即时战斗特效（按有效战斗时间计时，可跨波保留），不再承担进化资源和额外升级。若每波升级一次仍不足，必须另行评估波末、Boss 奖励或其他独立成长节点，而不是重新塞进特殊砖。
4. 玩家选择的**机会成本**：先选基础炮台、弹球效果、主动技能或神器，是否都会抢占同一升级预算？同一局的成长上限在哪里？
5. 怎样避免奖励只奖励强者（强 Build 轻松打掉特殊砖，弱 Build 更缺成长），让落后构筑有修正机会而不是死得更快？

**下一次对话从讨论这些规则入手，先形成两三种可比较的完整成长闭环，再决定具体技能、进化和 UI。暂不写代码。**

## 9. 2026-10-30 用户确认：特殊砖的职责纠正（优先于早期讨论）

**确定规则**：在“清空本波所有砖块才能过关”的既定玩法下，只要一波成功清屏，出现的特殊砖必然被击碎；用特殊砖掉落永久升级/进化碎片缺乏实质抉择并引入多余经济。特殊砖应当只提供**击碎后立即生效的战斗内短期增幅、特殊撞击/连锁、瞬时爆发**，不提供长期 Build 成长资源。适用约束：无中途升级弹窗，临时效果可跨波、升级/过场停表；清屏时回收弹球，保留未到期Buff。可用“何时击破”形成战术时机差异，而非“是否击破”形成奖励差异。

此前讨论中涉及“特殊砖额外永久升级、进化资源、定向重抽”等提案，**在当前设计中已被明确否定，不得当作已确认规则执行**。稳定永久成长由波末三选一、Boss 奖励及将来另行确定的独立成长机制解决。
