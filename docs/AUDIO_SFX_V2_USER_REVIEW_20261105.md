## 3. V3 目标与建议（待下一轮真人试听决定）

**不是重新搜索一大批音效，而是针对未通过的9组补出彼此有明确听觉差异的2–4个可试听方案。**
- 机枪：简短、干净的物理打点或机械节奏；拒绝持续嗡嗡、激光感过强，需12.5发/秒连发试听。
- 普通命中：保留已选 `impactGeneric_light_001.ogg`，允许补充一层极轻、极短的“咚/咚”质感作为试听对照，不能直接改变已选结果。
- 砖块击碎：保留 Mining+Glass 双层方案，增加不同短碎裂候选；用户原话“再来击中”可能为笔误，不擅自改写选择。
- 装甲命中：有质感但不似橡胶弹跳的短促厚实碰撞。
- 开花：明确**不要电子音**，优先“啵、啪、轻盈破裂/迸发”之类有物理质感的声音。
- 植雷：短而轻的贴附/落点确认，不抢击碎音。
- 爆雷：原版候选“太炸”；减弱低频冲击和尾音，试清脆、克制的爆破和分段接力。
- 清屏过关：现有音效太短，增加**有胜利/完成感**的正向结束句式，可尝试约1–2秒，不能听起来像护盾或警告。
- 失败：与爆雷区分，做短暂下行/落幕，不要共用爆雷音。
- 升级：与首次浏览器解锁严格分离；制作正向奖励短句，首次解锁应静默或中性极短音，禁止误播升级音。

## 4. 实施和验收

1. 仅在独立音效工作分支、新试听页/新素材目录操作；不覆盖现有V2候选和本人的选择，不修改正式Demo或R1战场。
2. 候选可组合/分层、剪辑和变调，但必须附真实可试听文件；任何非原创素材记录可靠来源、原始文件名、许可证和处理变更。谨慎避免跨材质不真实。
3. 试听页V3必须支持**各事件的试听、单选、备注、自动保存、从V2导出的JSON/Markdown恢复选择、最终导出JSON/Markdown**；不应依赖只有某台电脑的本地缓存。
4. 高频命中、机枪、爆雷必须有连发压力试听，且试听响度统一；不能以音量大来伪装“爽”。
5. 只有用户实际试听并选定后，再进入音频接线与 `?audio=a|b` 游戏内对照。V2的M2.5回退必须保留。
6. 本文件属于设计决策存档，**不代表V3已开发、已试听或已发布**。
