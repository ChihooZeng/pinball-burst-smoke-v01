## A. 任务目标
在不破坏 v0.26 基础玩法与现有 URLs 的前提下，开发**可试玩、可回归测试**的三大 Build 首轮原型：
1. 初始三选一：裂变/电弧/机枪，第一波立刻产生不同战斗反馈。
2. 每波真正清屏后一次三选一升级，旧球和巨型球清零、波末暂停升级、选完预告下一波；沿用 v0.26。
3. 每条核心有Rank1–3及两条互斥进化分支，共6条分支，分支条件可在第5–8波触达；不强制玩家开局锁定固定职业。
4. 通用底盘强化（rate/power/speed/life）与3项辅助（hunter/drill/shock），允许混搭，防止三流派到后期自动同质。
5. 引入数据驱动升级定义、前置资格、阶段与互斥、有效三选一、构筑偏好保底和可复现的随机种子。
6. 手机优先验证机枪高频连续发射、直线/扇扫不同手感及CPU/碰撞性能。

## E. 构筑路线 & 三选一
**开局**：三种 seed 能力三选一，`seedAbility`记录起点，`coreFocus`初始可以为空；开局选了能力并**不等于锁死职业**。第1–4波可在候选池获得其他基础机制作为弱辅助；第5–8波根据已培养的能力进行**明确的主核心分支选择**，分支只可选其一。需要记录两条路线权重，不直接替玩家确定。
**候选生成**：数据驱动 `eligible` + 前置过滤 + 满级过滤 + 互斥过滤。3卡**不能重复、不能失效**。如池不足，提供真实可执行的通用强化兜底；不能将随机数伪造为进化资格。
**保底**：在已满足Rank≥2 + 清屏≥4的情形下，第5–8波必须至少一次提供合资格分支选项；未选过的进化后面仍可再出现。保底只针对正常进化，不保底传说。
**成长预算**：每清一波固定一次普通升级已确认；第2波额外一次强化、每4波额外Boss奖励**是下一阶段待测候选**，v0.27a默认不偷偷启用，做feature flag方便后来测。
**进度**：普通技能Rank升至3时不再提供重复无效卡；分支拿到后仍可通过通用技能和辅助继续升级，直到第8波。
**显示**：卡片要能清楚区别当前核心、辅助、原有Rank、即将获得的效果、互斥分支标记；适配 390/375/320宽，长文本在手机上仍然可读。

## F. 测试矩阵与验收
| Case | 验证 |
|---|---|
| 基线回归 | v0.26原本自动测试与移动端QA仍通过；v0.25不改动 |
| 三种开局 | 每种seed第1波即产生明显差异，不依赖巨型球 |
| 裂变 | 第一次/第二次有效碰撞按rank触发预期小球；不二次无界裂变 |
| 电弧 | 按直接命中计数触发；附近目标、单体Boss均可发挥，间接伤害不递归 |
| 机枪 | 实际平均发射间隔与配置匹配；真实反弹；LINE稳定、FAN连续逐发角度往复 |
| 升级 | 真正清屏一次只得一次普通升级；Boss击败本身不额外升级；三个选项不重复、不无效 |
| 分支 | 合资格第5–8波出现至少一次；选择A则同核心B消失；其他core仍可作为辅助 |
| 性能 | 实测同屏球峰值、被抑制发射次数、碰撞开销，保持手机可操作；60/120Hz物理一致 |
| 尾砖/Boss | 非传说正常Build能清理尾砖；Boss单体不陷入漫长空场乏味 |
| 移动端 | 390x844/375x667/320x568，无网页纵向滚动，三选一和射击区域无遮挡 |
| 可调试 | 固定seed、强制能力与分支、重放固定序列、导出测试数据；测试口令不暴露在生产界面 |

**结束标准**：3个seed至少各一条可自动化复现的前8波有效升级路径 + 视频/截图/结构化事件日志；候选算法与性能测试PASS；至少一轮移动实机手感人工Gate。只跑自动测试不等于用户手感验收。
