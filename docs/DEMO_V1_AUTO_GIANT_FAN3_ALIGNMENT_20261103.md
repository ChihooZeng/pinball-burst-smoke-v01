# 《弹珠超载》自动技能 / 机枪三球扇形 / 独立反弹对齐（2026-11-03）

## 追溯前期决定
- 2026-10-27/10-31：炮台连续自动发射，玩家只控制瞄准方向；巨型球蓄满100%自动释放。
- 2026-10-29：扇形散射一次发出三颗真实弹球，且三个球各自独立与墙和砖碰撞、反弹。这与“快速摆动方向、逐发射击”不是同一种武器模式。
- 用户指出之前的六分支测试版技能仍需点击、机枪射速慢、扇形不是同时三球，且反弹体验不足。

## 本轮修复
1. 取消巨型球手动点击事件以及手动模式设置；技能按钮仅作为能量和倒计时的视觉状态展示，满能自动触发。
2. 即便历史浏览器缓存记住“关闭自动技能”，当前独立测试版也不读取旧设置。正常玩法/六分支速测同一规则。
3. 速测初始满能量，下一次物理帧自动产生实体巨型球，之后仍按实际破坏回收能量。
4. 机枪单核间隔 rank1/2/3 从 .35/.27/.20s 改为 .30/.22/.16s；机枪A专精间隔 .17s→.125s（加射速卡后可更快）；无隐藏伤害倍数。
5. 机枪B从“逐发角度摆动+每6次补发一颗”调整为每发射周期同时放出三颗真人物理弹球，分别位于方向 -0.32 / 0 / +0.32 弧度。每颗具有独立位置、速度、生命期及碰撞状态，沿用普通球的砖块/侧墙反弹规则；同时三颗与球数上限48共用预算，不是特效虚弹。
6. 机枪B单轮间隔设 .24s，单轮3颗；考虑到一轮三球，单轮发射频率低于机枪A的直线扫射，避免无上限持续增加子弹。
7. 它属于独立对照测试；六分支技能和上一轮“脆击重做”保留，不覆盖正式Demo和旧B版。

## 验证范围
- 模拟12种（六分支×两场景）速测：满能后第一物理帧自动释放巨型球，巨型球产生实际撞击，普通球仍持续自动射击，手动技能点击监听器不存在。
- 机枪B一次真实发射生成3个正常大小、非mini、速度左右对称的球，留场时间约4.1s。
- 第6波三球扇射的固定物理模拟：瞄准中路产生7次真实扇形球侧墙反弹、45次真实砖块反弹；瞄向右侧产生60次侧墙反弹、49次砖块反弹（这些数字是模拟结果，只证明功能，不用于平衡结论）。
- 最大在场球不超过48，正常首轮三核心升级选择保持可用。
- Node回归脚本已更新：`demo/v1/quick-build-lab-smoke.cjs`。在此轮仅在 V8 mock 浏览器环境复现检查，未独立运行真实 Node CLI。
- 未验证真机Safari/安卓性能和手感，尤其三球同时反弹对FPS的压力。
