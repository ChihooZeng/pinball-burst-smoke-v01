# 《弹珠超载》V1.0 真机与真人试玩检查单

试玩入口为独立的 [Marble Overload 预览站](https://chihoozeng.github.io/pinball-burst-v1-preview/)。建议首轮使用 iPhone Safari、Android Chrome 和手机微信内置浏览器各试一次。记录手机型号、系统及浏览器版本、网络、语言和复现时间。

## 5 分钟快速检查

- [ ] 从微信聊天或浏览器粘贴打开页面。确认竖屏首页完整、无横向滚动，语言切换后刷新仍记得选择。
- [ ] 查看操作说明，再点击开始。左右拖动，确认炮台瞄准、自动发射和击碎砖块；观察前四波的多色砖、1HP 无数字、特殊砖图标。
- [ ] 打完第一波，确认三张卡的名称和说明完整。选一张，确认进入第二波。另一轮换一种流派。
- [ ] 在战斗中暂停，改语言和音量，再继续。切至后台或锁屏后回来，观察时间、音效与音乐状态，测试系统静音或蓝牙设备。
- [ ] 让砖碰到警戒线，读完失败提示后重新开局。确认新局从第 1 波开始。测试手动超载时先关闭自动超载。
- [ ] 打开隐私页，核对语言和返回按钮。公开预览关闭统计和广告，开局无需提供信息。

## 有时间时

- [ ] 继续挑战第 10 波中枢和第 20 波终局核心，记录阶段提示是否容易理解，重特效时是否卡顿。
- [ ] 通关后检查流派、时长、得分与再次挑战按钮。记录停下的波数、原因和最希望改善的一点。

反馈可写成一行，例如「iPhone 15 / Safari / English / Wi‑Fi / 第 4 波 / 切后台后音乐未恢复」。附截图及复现步骤即可，避免包含个人信息。
