# 《弹珠超载》20关 Build Lab — 第5关精英、第10关Boss护甲环（2026-10-31）

> 独立实验候选。完整50关目标不变；本首版对外Demo拟20关连续成长，不重置Build。仍待真实物理及真人Gate。

## 成长与内容
- 第1关沿用M1.3普通炮台+首次清屏才选核心；首关一体化新手教程留待下一轮。
- 第5关大型32HP精英砖（非Boss，正常清屏/奖励规则）；6–9关继续构筑。
- 第10关128HP Boss；中心周围16块22–39HP高HP护甲小砖、14块3–7HP低耐久引导砖；底部中央从第4行以下始终保留3列空位，真实弹球能从底部进入，在护甲与Boss之间连续反弹。Boss保留有限辅助召唤，不能封闭入口。
- 11–15关主流派成熟：第11关清屏后允许已选择的专精分支升级第二级，裂变+1子球/追猎+1，电弧额外+1目标/聚能+3，机枪直/扇射速提升；不得赠送额外卡。
- 16–20关为Build展示：大多数普通低砖HP 2–6，高数字保留适度比例且与低数字相邻，让打碎低砖后弹球持续命中高HP；低数字并非HP0的伪砖。第20关真正清屏即结算。
- 全20关仅清1–19波的19次正常升级，Boss/精英没有新增永久奖励。无10/15/20波重置。

## 直接进入Boss
开始页选择裂变/电弧/机枪Build，点击「直达第10关Boss」。系统合法构造前9次普通升级，进入Boss并提供满额超载能量；只用于测试，不作为真实通关数据。当前第4/8关Boss被移除，第10关是唯一的Boss关。

## 验证
- V8 JS源码解析，模型测试：3核心×70种固定seed×3种选卡策略=**630条19轮三选一**，没有空卡池/异常卡文案。
- 从实际生成代码运行阵型函数：WAVE_START_Y=84、103、121三场景，精英与普通砖、Boss与护甲砖没有矩形重叠；第10关中央下方没有实体阻挡；11–20普通砖均HP>=2。
- 抽样第16/20关分别拥有49/43块2–6HP砖及12/14块19HP以上砖（另有少数特殊砖）；这些只是静态数量，不证明爽感。
