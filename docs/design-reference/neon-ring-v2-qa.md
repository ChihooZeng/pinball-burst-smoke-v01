## 功能回归

- `tests/visual/protection.mjs` 归一化逐项列明的渲染与界面改动后，剩余游戏脚本与 V1 完全相等，比较 SHA-256 为 `c56245be32d3ecf082ba9427a679519a8ecfa13bd44b18b05e8c4f6974e85e41`。逐一核对 43 个文件，包括 27 个音频资源、Build、语言、音效引擎、振动相关引擎、隐私、统计和服务器。
- 100 份同种子波次计划与 V1 相等。两个手机尺寸各覆盖 DPR 1/2，加一个桌面场景。实测每种配置的砖矩形与 HP、弹球位置与速度、伤害计数、砖缝通过和命中反弹相等。画布输出像素按实际尺寸和 DPR 独立校验。
- 40 份额外砖面样本覆盖各个波次。开局的非特殊 1HP 砖呈现全部五种已确认色值，且无数字。2HP 仍显示数字，特殊砖图标与识别规则仍在。
- 触摸拖选通过 360×640、390×844、1440×900 和额外的 844×390 横屏验证。左右手技能、真实升级选择、机枪两个分支、Boss 召唤和阶段、最终 Boss 三道门、击败演出、再开一局、返回首页、失焦暂停恢复、异常恢复、语言切换均通过。
- 14 个现有音效事件均逐项调度并核对实际播放计数。实战首触发声、BGM 时间推进、暂停恢复、音量、静音、持久化与混音采样通过。振动在 Chromium 通过记录浏览器 API 调用确认，关闭设置后同一命中未发送振动请求。
- 发行单测 5/5，原入口 smoke、统计同意与撤回、隐私、静态包开局和真实触控通过。屏幕采集过程未记录 JS 异常或资源失败。
- 同一 Mac 的 V1/V2 Chromium 四种重载场景约 60 FPS，P95 帧间隔均约 16.7–16.8 ms。两者均未出现超过 50 ms 的帧。V2 十次重开前后的 JS 堆为 1,810,652 与 1,861,852 字节。样本包含 48 球预算压力，未发现明显帧率或内存退化。
