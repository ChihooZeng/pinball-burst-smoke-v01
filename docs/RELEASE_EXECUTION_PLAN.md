## 基线发现

- 七档原色集中在青蓝紫。第一波 31 块 1HP 和 4 块 2HP 原本共用一个颜色。第二波多数砖共用第一档。优先重设固定阈值及色相，先保留关卡 HP。
- 历史同条件脚本裂变通关，电弧止于 11–12，机枪在第 15 波因时间截断。复跑无跳关测试，检查连锁的实际命中路径、目标预算和升级池。
- `record()` 已记录战斗事件，当前只有本地导出。页面、Canvas 和构筑文案须统一双语。需补采集、暂停与异常恢复、正式入口和发行配置。
- 音频已包含 V5 木板受击及已审计素材。补齐事件并在游戏内复验。历史音频回归基线 65/66，旧断言要求原 resize 写法，和后续 HUD/生命周期修复冲突。根目录旧 smoke 通过。
