# 中英文实现与验收

`demo/v1/i18n.js` 集中保存简体中文和英文词条。标题、功能按钮、操作说明、无障碍名称使用 HTML 的 `data-i18n` / `data-i18n-label`。游戏状态、Canvas 标签、Boss 阶段、结算和构筑由 `t(key, values)` 渲染。升级记录保留结构化属性变更，切换语言后会从原值重新生成说明。

首次进入时优先读取本机选择，再读取浏览器语言，中文系列使用简体中文，其余使用 English。玩家可从首页或设置更改语言，当前波次和构筑在原地更新。浏览器拒绝存储时此页内仍可切换。语言变化与地区统计维护独立。

统一名称使用「弹珠超载 / Marble Overload」「碎星裂变 / Star Split」「电弧印记 / Arc Mark」「高速供弹 / Rapid Fire」「中枢 / Nexus」「终局核心 / Final Core」。事件 ID 和存档 key 保持稳定。QA 区域在普通玩家入口隐藏。

Chromium 测试覆盖 360×640、390×844、1440×920，英文自动选择、触控瞄准、三选一卡片、战斗后中文切换、设置和构筑记录刷新、重载记忆、Boss20 标题。用 300 条带种子的双语升级序列抽检 16,200 个卡面及可选性。浏览器脚本 `node tests/release/ui.mjs <证据目录> <游戏 URL>`。
