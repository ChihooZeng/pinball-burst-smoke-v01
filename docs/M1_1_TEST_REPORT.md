## 实验方法
before.json为原调弱版；experiment-a.json仅改战斗，保留旧布局/砖位置；final.json包含全部最终机制和HUD预留位置，对照下降.80/.84/.86。最终选.84（+5%）作为保守微增实验，不是用户已确认的精确平衡值。

所有完整回放自动瞄准实际砖、从真实三卡选卡、满能量可放巨球，未跳波/注伤/减HP；noActive禁用主动。Node参考世界360×560，另验证390×844对应360×779。场景夹具：单砖52HP且为Boss，三砖15/19/30，五砖15/19/30/15/19；R1无火力，R3另有火力R1，两版相同，不使用巨球。旧版较快尾砖可能来自隐藏削血，不能等同真实伤害更高。

final.json保存每波清屏、最长无击碎、尾≤5时间、孤Boss时间、实际伤害、接触射击比例、预算与卡历史。接触比例=至少撞击一次的非子球/发射数，不是碰撞次数/发射数。
