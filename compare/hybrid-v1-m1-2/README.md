## 修复内容
- 单颗未强化普通球直接撞击固定伤害1，基础球速330、常规发射间隔不变。明确选取的`火力强化`仍让普通球每次撞击+1。
- 原特殊砖15秒`强击`（直接伤害+1）改为15秒`急速`（炮台射速+10%）。原30秒弹球速度+15%保留。Boss弱点窗口命中不再自动+1直接伤害，改为额外+4点超载能量。
- 单次直接命中写入`direct_hit`事件，包含HP前后、球原伤害、已选机枪破甲、钻头、撞墙蓄势、Boss弱点能量，可供本局JSON追查。
- Boss的x138,y108,w84,h53真实碰撞矩形及额外5px空间从砖阵规划中避开（不再按固定行、列粗略空缺）；后续扩大Boss形式时要改为数据化共享矩形。
- 手机长屏根据砖阵到危险线的初始距离，对下落速度进行平滑补偿（超出参考560高场地的距离按70%补偿，倍率封顶3.2）；`fallScale`基础系数仍为0.84。这会增加长屏紧迫感，需要真人确定是否合适。
- 三选一卡片以一句本次增量或新能力简介为主；暂停菜单保留详细Build。手机布局、右上设置和滑动瞄准保持M1.1已认可方案。

## 重要待验收
- 已完成JS解析、核心数据模型、临时Buff、技能卡字符串和Boss几何/长屏倍率的定向检查。**没有在此次修改后执行27项旧浏览器脚本和完整10波六路线回放，不要将其标记PASS。**
- M1.1已知弱电弧第5波和弱裂变第7波失败；长屏下降压力增大可能恶化，Boss弱点由伤害改充能也可能影响孤Boss耗时。请优先进行弱Build与真实手机的Gate，不要直接进入M2。
- 已选技能可能产生单次额外伤害（火力、机枪破甲、钻头、蓄势），或电弧作为独立技能追加伤害；不同弹球近乎同时撞击也能累积扣血。这些不能误称为未选卡情况下普通球基础伤害>1。
