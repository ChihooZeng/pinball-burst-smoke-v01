# 弹珠超载 v0.21 — 成长曲线、持续爆破与 Boss 召唤动画

**2026-10-29，独立对照试玩版。** 以 v0.20 为基础，仅修改 `compare/hybrid-v21-burstcurve/`。不改变 v0.17、v0.19、v0.20 的原始实现。主线仍是一个炮台连续生存、砖块下降、击碎获取经验、三选一升级、清屏奖励、召唤型 Boss。

## 玩家问题与修改

### 1. 性能增长太快：强力技能延后

升级三阶段（同时满足时间和等级门槛）：

| 阶段 | 条件 | 可抽技能 |
|---|---|---|
| 基础训练 | 生存 <34s **或** LV≤3 | 射速训练、弹速训练、弹跳续航 |
| 中级成长 | 已过基础训练；生存 <85s **或** LV≤5 | 上述三项 + 火力强化、追猎弯弹、蓄能弹跳、钻头穿阵 |
| 爆发解锁 | 生存≥85s 且 LV≥6 | 再加入散射进化、碎星裂变、震荡核心、电弧印记 |

基础射速训练 -0.075s/次，基础弹速训练 +18，弹跳续航 +0.9s。第一轮升级界面只展示基础三项；并没有开局就获得三连射或裂变。
基础发射 1.14s，球速 280；初始伤害仍为 1。优先保证 0–60 秒保有主动瞄准价值，而非开局就自动清场。

### 2. 砖阵下落、耐久和火力曲线

- 开局仍为 **6行×9列=54块**，底部两行偏易打，避免玩家在尚未升级前必死。
- 初始下落速度 **11.2 px/s**，随时间逐渐上升，最高约 **19.8 px/s**。v0.20 是 8.8→16.4。
- 正常补砖约 **每3.5秒**（v0.20 为4.1秒），砖潮仍会更密集。
- 耐久梯度每约 **46秒**进入下一阶段，较 v0.20 的70秒明显加速；不再停留在 30 多 HP 的顶点，后期按档位增长，保留 HP=1 砖制造碎裂连锁。
- 砖块数量有随生存时间提高的密度软上限（初始约65块，每55秒提高7块，最高不超过168块），防止初始低性能直接被新砖堵死；越往后可以出现更多数字砖块。
- 清屏后保留约0.55秒视觉间隔，**在屏幕内**直接补充4行×9列；仅剩 ≤4 块且持续2.3秒未清时，追加3行可立即打到的砖阵，避免盯着空场等待顶部砖块慢慢落下。

注意：不断增加耐久是为了让数字持续下降，同时保留低耐久块触发连锁；不是无脑给全部砖加血。

### 3. 固定循环色盘

普通数字砖使用固定8色循环；HP1/2–3/4–7/8–15 各有明确色阶，随后每12点 HP 进入下一色，64+ 再从第一色开始，不会“高于某个值全是橙色”。击中造成 HP 下降时颜色也随当前数值变化。HP=1 仍默认隐藏数字；Boss 核心和特殊砖单独表现。

固定色盘：
`#257DA9` / `#218FA7` / `#428BBD` / `#7972C5` / `#BB77AD` / `#CC817B` / `#B9985E` / `#4C9E90`。

### 4. Boss 数字砖从凭空出现改成“预警→凝聚→实体”

- 每次召唤时先在目标位置显示 **约0.52秒青蓝色闪烁虚线预警轮廓**，此阶段不会参与碰撞。
- 接着砖块经过约0.38秒 **半尺寸放大+渐显**，外层有约0.7秒向外扩散的脉冲光框。
- 密集砖阵里允许把已经存在的普通数字砖“转化”为 Boss 辅助砖，避免两个实体重叠。
- 实体未完成成形前的最初约0.2秒不参与球体碰撞；Boss 死亡会取消所有未完成的召唤。
- 召唤砖仍有上限，经验奖励受限；无账号、广告和多 Boss 机制扩张。

### 5. 维持性能优化

继承 v0.20 的120Hz固定物理更新、与浏览器刷新率匹配的rAF绘制、每秒约10次非关键HUD更新、碰撞AABB快速排除、死砖周期清理、低帧率阴影降级。本次只增加最多8处Boss召唤特效；真机60/120FPS仍需用户检验。
