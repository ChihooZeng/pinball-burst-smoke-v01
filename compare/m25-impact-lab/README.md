# 《弹珠超载》M2.5 派生打击感实验（独立，不并入主线）

线上试玩：https://chihoozeng.github.io/pinball-burst-smoke-v01/compare/m25-impact-lab/

本测试按用户反馈“900球、超大HP反而无聊”的事实制作：**只适当增加真实球量，测试每一次撞击的声画反馈是否带来更强爽感**。

## 相比M2.5的唯一变动
- 同屏真实球上限从32→48（+50%，并非数百上千球）；裂变R1/R2/R3每次分裂数从1/2/2变为2/3/3，星海风暴分支由3/4改为4/5，追猎裂变由2改为3；每颗原生球仅一次裂变，子弹不递归爆炸，减少卡顿风险。
- 重击反馈：**所有高HP砖每次受击**在局部出现明亮中心闪光、扩散小冲击圈、白亮火花与砖块压缩弹性，画面小幅震动；真正击碎及三连碎有更强的震动和金属色碎块、短闪白；保留性能预算：光圈最多40、碎片最多120、粒子最多90，符合减少动态效果设置自动关闭。
- 更有厚度的命中声音：高HP撞击增加低频与短促高频敲击，击碎声再增加低频鼓点；保留原音量控制、Web Audio动态压缩和密集连续撞击降频。
- 实验设置新增手机振动开关（默认开）：支持`navigator.vibrate()`的安卓浏览器按约8–24ms发出有限触觉脉冲并节流；**iPhone Safari 网页通常无法直接控制振动马达**，仍能感受到画面震动与音效。关闭反馈或系统偏好减少动态效果时保留相应限制。

## 没改的主线规则
仍是M2.5的20关、3流派、Boss击杀即胜+向外连环爆炸、逐次电弧、自动超载、HP和下降曲线以及未升级基础球1点直接伤害/330初速。未改M2.5目录或默认入口，也不打算并入11月5日Demo。此版本只测“打击感”，不先扩展技能和砖块类型。

## 试玩测试顺序
1. 同机先玩原M2.5 3分钟，记住普通撞砖和连续击碎感觉。
2. 开本版本在同一关选择相同流派，比较50%更多球量、每次撞击的反馈、以及Boss击碎前后的打击感。
3. 设置中将“重击实验 · 强反馈”改为“常规反馈”，比较是否更舒服；可随时关闭设备振动。
4. 观察FPS尤其第10关Boss高砖数/大量弹球时是否不稳，用户的主观反馈比单看数字更重要。

## 2026-11-01 首轮线上实际运行与自动降载
- M2.5来源、48球上限、裂变+3、Boss10胜利、强反馈设置、安卓振动开关等均在真实浏览器页面确认；未验证手机真实马达振动，不能承诺iPhone Safari网页振动。
- 第一次自动网页测试观察到**27–39 FPS**（测试浏览器条件），说明强反馈与48球可能明显降低部分设备帧率，不能宣称性能Gate已通过。
- 已增加**FPS低于48时自动轻量特效**：保留真实48球碰撞、每次命中闪光、冲击环和画面震动，但粒子数量减至约42%及碎片60%、取消部分阴影/砖块残影；FPS恢复则回归完整特效。不减少真实球上限，也不修改伤害或物理。
