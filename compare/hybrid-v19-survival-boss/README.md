# 弹珠超载 v0.19 — 连续生存 + 召唤型 Boss 试玩

2026-10-29。独立试验版：从 `v0.17` 的物理、音效、六种技能与打击效果独立分支，**不替换 v0.17**，也不基于较弱的四职业实验作为核心玩法。

## 本轮范围

- 只有一种初始炮台；散射为局内升级，不做四职业切换。
- **不分关卡**：生存时间不断累积，砖阵持续向下移动，触碰警戒线失败。
- 正常补充砖阵 + 每约 70 秒一次持续 13 秒的砖潮；HP 在后期逐渐增加，保留一击即碎砖。低密度时有约 3 秒清理窗口，清屏后约 0.85 秒内补给。
- 击碎砖块取得经验（部分高耐久砖提供更多）。经验满足阈值自动暂停，三选一升级；升级速度会逐步减慢。**首轮可选择火力、散射、裂变**，后续扩展到 v0.17 六技能与射速强化。
- 清屏得到 **25% 下级经验**（最少三点），可领取奖励间隔至少 32 秒。刻意不做“每次清屏完整升级”，防止滚雪球。
- **召唤型核心 Boss**：约第 78 秒出现，随后根据存活时间出现新 Boss。核心具有独立 HP，按原有碰撞反弹；每 5 秒尝试在核心两侧、上方补出 3–4 块数字砖，最多同时 8 块。召唤砖仅前 10 块提供经验，防止重复刷经验；Boss 击破召唤砖联爆并奖励一次三选一。
- **开始游戏触控 / 点击触发 AudioContext**：遵守移动浏览器自动播放限制；首次真实手势之后同步播放启动提示音，可点右上角音符重新恢复或试听。
- **手机单屏**：顶部小型 HUD、经验条、按可用高度等比缩放的 Canvas、底部超载/Build/音量设置；禁止网页纵向滚动；升级弹层置于画布内部，战斗暂停。
- **直达 Boss** 按钮只供本次试玩，开局给一次预设分裂+电弧+散射+震荡构筑，Boss HP 48（正常生存第一 Boss HP 75）。让用户无需耗时等候就能试召唤砖循环玩法。

- 上述模拟是自动化检验，不是人类玩家的真实生存时长与手感评价。

## 待验证与注意

1. **真人在 5–8 分钟内是否出现 2 次压力—突破—主宰循环**。自动瞄准的 250 秒运行击碎约 376 块、达到 9 级并击败 3 次 Boss，仍在生存，**没有清屏**，说明清屏奖励虽可触发，但实际清屏频率仍需真人试玩观察。
2. Boss 周边普通矩形砖是否能够真正制造重复反弹，而不是纯遮挡；必要时测试反弹砖，但不要提前增加。
3. 首轮平衡仍是原型，正常 Boss HP、补砖与下降速度、升级卡选择分布都需要反馈。
4. Mac/iPhone Safari 的音频、地址栏收缩、设备安全区域还需真机验证；Edge 手机视口验证不能代替真机。
5. 无账号、金币、签到、广告、长期存档、关卡/100关、独立激光炮台、商店。
