# 弹球暴走 v0.6 — iPhone 网页视觉打击感实验

试玩：https://chihoozeng.github.io/pinball-burst-smoke-v01/compare/hybrid-v06-juice/
对照 v0.5：https://chihoozeng.github.io/pinball-burst-smoke-v01/compare/hybrid-v05/

## 目标与边界
根据 iPhone Safari 不提供可靠标准马达震动接口的实际反馈，**彻底停止网页物理振动方案**。
本次只针对画面视觉冲击反馈（game juice），继续使用已经偏好的 B 版和 v0.5 密集砖块：
7 列，三波 35 / 42 / 49，装甲 HP 分别 2 / 3 / 4，射速 1.00 → 0.90 → 0.82 秒，原有升级/射击/巨型球伤害完全不变。

## 新增视觉模块
- 独立 `juice-fx.js` Canvas 2D 实现，游戏碰撞事件只触发非阻塞反馈。
- 装甲命中：在旧版的数值减 1、压缩和粒子基础上增加局部亮斑与短促冲击线；不摇屏。
- 砖块破碎：碎片具有旋转、不同方向速度和轻微下坠，有局部闪光；不会延迟原来的碰撞计算。
- 连击（每三次连碎等价值时刻）：较明显碎裂与微弱镜头冲击，不在每次普通击碎时持续摇屏。
- 手动巨型球：发射产生扩散金色圆环，贯穿时只按频率限制触发短暂冲击。
- 显示强度可临时选择：关闭新增效果 / 标准（默认） / 增强。关闭后保留旧 v0.5 基础粒子与声音，方便自行比较。
- 用户系统选择 `prefers-reduced-motion` 时新增动态效果自动关闭且控制不可用。
- 相机震动仅是 canvas 内画面偏移，幅度小于 4 px、单次约 95–140 ms；**不移动真实按钮和操作区域**。
- 限制最大队列：碎片 120、闪光线 90、光斑 24、扩散环 5；生命周期短。
- 无设备 `navigator.vibrate`、无 iOS WebKit 隐藏开关、不请求额外权限、不存储任何开关状态。
- 没有增加新音效、技能、炮台、砖块或数值。

## 验证
- `node --check game.js`
- `node --check juice-fx.js`
- `node visual-test.js`：同时覆盖三波 126 砖、装甲耐久、射速/瞄准/升级/巨型球、动效模式切换、无障碍减少动画、效果队列上限、效果过期和 Canvas 绘制。
- 测试脚本在与 v0.5 相同的自动瞄准条件下仍然约 113 秒清完三波；仅是自动验证，不代表玩家真实手感。
- 已通过 Microsoft Edge 在 390×844、320×640 尺寸上渲染页面。尚未执行真实 iPhone Safari 手感/流畅度测试。

## 需要收集的反馈
- 对比关闭、标准和增强：哪个在 iPhone 上最明显但不晃眼？
- 装甲未碎时有没有命中感？
- 3 连碎与 5 连碎的节奏是否明显？
- 巨型球是否有值得期待的爆发瞬间？
- 连续撞击密集时是否出现掉帧或眼花？
