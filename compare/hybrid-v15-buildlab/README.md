# 弹球暴走 v0.15 — 破坏构筑实验（独立对照版）

日期：2026-10-28。此目录从已核对一致的 v0.14 源码复制而来，未覆盖 v0.14 / v0.13。

## 本轮设计假设

原 v0.14 普通球对中高耐久数字砖伤害不足，且数字砖降至 0 HP 后还要求一次额外撞击，导致玩家只想等巨型球清场。本版验证：加强基础球 + 两条真实联动的 Build + 为巨型球设置明确上限，能否提高玩家主动瞄准与持续升级的意愿。

## 已实现（代码与自动化测试）

1. 普通球对装甲砖每次命中造成 **2 HP**（原 1 HP）；碎甲强化弹造成 **3 HP**（原 2 HP）。闪电等辅助来源仍可造成 1 HP。
2. 装甲砖 HP 归零立即破碎；HP 剩余 <=2 时显示破裂纹理与仍有的 HP 数字，不再存在「0 HP 装甲还要多一次命中」。
3. **雷链风暴**：选择「分裂齐射＋电弧扩散」后，侧向分裂球能在电流被动未觉醒时提前触发闪电，每颗侧向球独立冷却，无无限递归。
4. **爆破连锁**：选择「连锁爆破＋折射强化」后，每第 3 次由普通球击碎砖块会对邻近砖块（包括装甲）触发小范围震荡。震荡造成的击碎不会再触发同类连锁。
5. 巨型球仍为 **5 秒**，当前 HP<=5 可贯穿，HP>5 减 3 HP 反弹；新增单次最多 **10 块**贯穿预算，避免巨型球完全取代普通攻击。
6. 关卡数、砖阵分布、输入方式、六种升级、九次选择保持不变；UI 添加两条组合提示，避免玩家不知道融合条件。

## 自动化验收

```bash
cd compare
node --check hybrid-v15-buildlab/game.js
node --check hybrid-v15-buildlab/juice-fx.js
node v15-build-test.js
node v14-tenwave-test.js
```

v0.15 两条自动模拟（程序可通关验证，不代表真人时长）：
- 路线 A：212.4 秒、900/900、最高连击 156、闪电 238 次。
- 路线 B：230.1 秒、900/900、最高连击 97、闪电 119 次。

与交接文档中 v0.14 自动模拟约 425 秒、440.1 秒相比，当前自动模型明显提速。不能据此推断玩家一定更快乐、更愿意重玩。
