## 已编码的三项确定规则

1. **第10/20关打死Boss即胜**：Boss HP归零立即锁定该波胜利，停发射、停掉落/触线判负、停召唤；约1.7秒播放从Boss中心往外围的连续环形爆炸、周围砖块按距离逐个炸开；剩余砖不是在死亡帧突然消失，更不能把胜利特效清除算作普通击碎/经验。动画结束走原来的`screenClears`奖励/升级/20关最终结算，不绕过20关完成流程。20关原888HP三阶段Boss必须真正完成三个阶段并击败核心才能获胜。
2. **电弧改为逐目标真实延迟放电**：以前同一帧给所有目标扣血、线条只是事后画出来；现在电弧发起时只锁目标，不立刻扣血；第一个命中延迟25毫秒，每次约82毫秒沿上一目标延伸到下一真实砖块，画可见亮线并在每次跳转才真正产生对应HP损伤/击碎/后续传递。每条最多6个不同目标，最多7条排队链，无法无限递归，手机端渲染保留预算/低动效选项；`雷霆聚能`仍保持单体专精。
3. **默认自动超载**：普通炮台保持自动连续发射，不改射速系统；首次用户/没有设置记录时`autoSkill=true`。能量100%且技能未使用时自动按炮台当前方向释放；设置中关掉自动以后继续支持手动点击按钮，保留已有选择（用户明确选过手动的不强制覆盖）；自动模式隐藏多余的手动操作提示。
