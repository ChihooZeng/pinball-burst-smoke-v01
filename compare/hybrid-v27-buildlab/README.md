状态：实现与自动验收已完成；**手机真人手感 Gate 待验收**。参数均为实验值。仅前8波，不推进 v0.27b/c，不替换默认游戏。

## 试玩

在仓库根目录运行 `python3 -m http.server 8767 --bind 0.0.0.0`：
- 本机：http://localhost:8767/compare/hybrid-v27-buildlab/
- 同一 Wi-Fi 手机：将 localhost 换成本机局域网 IP（本次为 192.168.1.76）。
- 旧版对照：[v0.26](../hybrid-v26-wave-level/) · [v0.25](../hybrid-v25-wave-rush/)。欢迎页也保留两入口。

开局点开始并选裂变／电弧／机枪；左右拖动瞄准，炮台自动开火，充能满后可点超载冲锋。每波全清仅升级一次；升级时停表，旧球清零；选完后预告下一波。第8波完成并选择升级后结束原型。

开局是能力起点，尚未锁职业。前期可获得其他核心的基础能力；核心 Rank≥2 且清完第4波后，出现两条互斥分支，选择时才确认主核心。非主核心按 Rank1弱辅助生效且不可继续升阶。候选提供当前等级、效果、核心／辅助与互斥标记。

| 核心 | Rank 1 / 2 / 3 | 分支 |
|---|---|---|
| 裂变 | 2撞1球 / 2撞2球 / 1撞2球 | 星海风暴3子球／猎星裂变2子球+有限墙反追踪 |
| 电弧 | 3撞1目标 / 2撞2目标 / 2撞3目标 | 雷网跨目标3跳／聚能单体放电 |
| 机枪 | 0.35 / 0.27 / 0.20秒逐发，初始TTL2.4秒 | 直线0.17秒／扇扫0.18秒、±0.28弧度 |

## 参数与边界

全部集中在 `builds.js` 的 CONFIG 和 DEFS。相对任务书待定数值，本次实验采用：
- 电弧每目标伤害按Rank为1/2/3；全局释放间隔仍≥0.45秒；孤立目标放电2点，聚能分支3点。传播和震荡只扣血，不再次触发核心或充能。
- 整波下落速度为v26的80%，只影响本目录，便于前8波成长验证。并非最终难度。
- 主机枪通用射速每级减0.012秒、总下限0.12秒。辅助机枪0.70秒起、每级减0.012秒，下限0.55秒，确保射速卡持续有效。
- 32球预算。主机枪满球时优先回收最老子球，再回收最老普通球；记录并显示“供弹优先”反馈。裂变不足预算时抑制多余子球并计数。
- 史诗、传说、终极、融合、神器、额外Boss奖励、特殊砖计时Buff均未开启。flags是下一阶段占位；不要将设为true误认为功能已实现。
- 特殊砖沿用直接击破提供主动能量；不提供永久成长。未来Buff按战斗时间计时、可跨波，留待v0.27c。

## 结构与验证

`builds.js`：数据模型、资格、互斥、候选随机与方向保底、参数计算。
`game.js`：保留v26固定120Hz物理、波次、音效与绘制；接入新战斗事件和UI。
`juice-fx.js`：v26原样保留。

从仓库根目录：
```sh
node compare/v27-build-model-test.js
node compare/v27-buildlab-test.js
V27_REQUIRE_CLEAR=1 node compare/v27-replay.js
node compare/v27-scenarios.js
V27_QA_DIR=/tmp/pinball-v27-qa node compare/v27-mobile-cdp-qa.js
V27_QA_DIR=/tmp/pinball-v27-qa node compare/v27-baseline-mobile-cdp-qa.js
```
后两项需要正在运行的本地8767服务（新版本）及Chrome。可设置CHROME_BIN；Node24自带WebSocket，无npm依赖。

固定重放通过测试宿主在加载前设置 `__PINBALL_TEST__=true` 和 `__PINBALL_SEED__=2701`；普通UI无调试入口。生产只有只读 `__pinballState()`。测试模式提供配置夹具、实际碰撞、选择、结构化日志导出；明确区分“夹具清屏生命周期测试”和“真实物理8波重放”。生产每次重开获得新随机种子。
