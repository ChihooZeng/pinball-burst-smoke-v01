## 用户试验目标
- **超大耐久数字**：下拉选择9,999/49,999 或 99,999/499,999，不是只能显示数字，撞击后真正逐次扣血。
- **静止砖阵**：9列×8行中留弹射入口，永不下降、无警戒线、无失败计时；打完一组自动重铺，持续破坏没有关卡切换。
- **球海分裂**：炮台只控制方向、自动连续射击，前18颗快速热启动。撞砖发生真实碰撞和3层裂变，分别可生12/5/3颗，子弹与多层子弹均有真实坐标、真实生命时长与实际扣血。
- **去除旧主线32球限制**，但现实浏览器不能承诺数学意义上无限球：提供350、900（默认）、2200颗**真实球安全上限**三档；达到当前档位暂停新球生成，已有球自然过期后继续增长，避免手机内存与帧率彻底冻结。
- **实时反馈**：上方显示真实球量、累计撞击、实际击碎砖块、FPS；独立“再加200颗球”“重新铺满砖阵”“重新设置”按钮。
- **性能**：对静态砖块建空间网格索引，碰撞只查邻近砖，限制单帧裂变注入数量，球数较大或FPS下降时自动关闭大部分轨迹特效，不改物理球的实际碰撞与HP。

## 不是主线规则
不要将此处99999HP、静止砖、无失败或数千球等参数合并入M2.5、正式20关Demo，也不要把这个小游戏结果当成三大流派最终平衡结论。纯粹检验“数量爆发→持续撞击→数字快速下降→持续爽感”的感受。

## 人工 Gate
1. 先用900球/9999HP，观察30秒，确认能够持续明显上涨的真实球量、砖块HP下降和局部爆炸、手机能操作。
2. 再切到2200档/99999HP，观察极限数量时FPS、触控延迟和主观爽感。如果FPS严重下降，降低到350或900档。
3. 告诉我们哪个时刻最好玩：第一轮球潮、连续二次裂变、逼近上限，还是砖块成片击碎。后续仅据此讨论主线可借鉴的少量特效节奏，不整合这套极限数值。
