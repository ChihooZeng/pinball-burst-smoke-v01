# 弹球暴走（Pinball Burst）v0.17：持续爆破耐久实验

日期：2026-10-28
版本目录：`compare/hybrid-v17-sustain/`，从 v0.16 独立复制并且**只调整 HP 曲线、部分高耐久可视化和文案**。保留全部 v0.16 技能、音效、主动技能、砖块数量、物理碰撞、最终八块软化规则。

## 设计假设

反馈：v0.16 变爽了，但 10 关 900 砖被强力 Build 迅速清完；高耐久数字不足以让成型后的连锁持续发挥。

方案：保持每一关 HP=1 的占比与随机位置完全相同，第 1 关所有数据完全一样，第 2–3 关轻度增加，4–6 关中度增加，7–10 关放大中/高耐久段。**绝不平均给所有砖加血。**

- 配置层理论最高 HP：36（十关确定性砖阵中最高实际 HP：32）。
- 第 10 关总初始 HP：330 → 977，砖块仍 99 块，HP=1 的砖仍 37 块。
- 对 HP≥15 的砖增加细边框；HP=1 不显示数字的规则不变。
- 最后 8 块砖的 HP 上限仍会收敛到 3，减少残留磨血。
- 音效、强度滑块、6 种新技能、升级次数、巨型球/超载冲锋都保持 v0.16 不变。

## 自动化验收（不是玩家时长）

```bash
cd compare
node --check hybrid-v17-sustain/game.js
node --check hybrid-v17-sustain/juice-fx.js
node v17-sustain-test.js
node v16-sound-build-test.js
```

v0.17 三条模拟升级路线，使用真正的弹球推进 900 块/10 关：
- 路线 A（裂变/电弧/震荡）：131.0 秒；v0.16 同一自动线路 115.1 秒。
- 路线 B（钻头/震荡/追猎）：189.3 秒；v0.16 同一自动线路 151.9 秒。
- 路线 C（追猎/蓄能优先，弱爆炸 Build）：187.6 秒。

这说明大幅增加耐久仍无法线性延长高速连锁流派的清场时间，尤其是路线 A；不能仅凭这些数值断定持续爽感已解决。

## 下一步真人验证

- 是否在 4–10 关感到更持久的连锁破坏，还是只是多磨几下 HP。
- 观察第 7–10 关是否有一个孤立高耐久砖强制玩家空转。
- 对比 v0.16 的爽感密度：爆炸、击碎频率与主动瞄准的价值。
- 再根据玩家反馈考虑延长关卡/新增可选挑战，而不是继续暴力抬 HP。
