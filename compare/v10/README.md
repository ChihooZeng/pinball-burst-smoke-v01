# 弹球暴走 · v0.10 FINAL RUSH A/B 实验

试玩入口：https://chihoozeng.github.io/pinball-burst-smoke-v01/compare/v10/
A 追猎弹射：https://chihoozeng.github.io/pinball-burst-smoke-v01/compare/hybrid-v10a-hunt/
B 多球连锁闪电：https://chihoozeng.github.io/pinball-burst-smoke-v01/compare/hybrid-v10b-lightning/
原始基线 v0.9B：https://chihoozeng.github.io/pinball-burst-smoke-v01/compare/hybrid-v09b-armor/

## 问题与目标
玩家在 B 版中段获得了「破甲→反射→连续击碎」的爽感，但进入只剩几块的尾局后，反弹支点消失，玩法退化为逐个瞄准清理。目标是把最后 ≤8 块变成每波的终结高潮，不扩大砖阵，不再增加成长系统。

## A：追猎弹射
- 每波剩余 ≤8 块时显示 FINAL RUSH，但必须发生真实弹球撞砖才能触发。
- 撞击后的**同一颗弹球**接管追猎，按当前砖块位置向最近存活目标移动；每次抵达都是一次真实的 `hitBrick(normal)`，保持两阶段破甲、连锁爆破、充能和分数规则。
- 一个目标未死不会被自动秒杀，追猎会间隔约 200ms 再次追击；相同装甲砖会出现小幅回弹路线，直到本波清空。
- 引导弹球仅在当前波存活，其他小弹球继续正常碰撞。没有自动触发前的免费伤害，避免玩家只需等倒计时。
- 引导速度 310 画布单位/秒；连线寿命短、最多 25 段且尊重减少动态效果。

## B：连锁闪电
- 同样在每波 ≤8 块时显示 FINAL RUSH。每颗普通/分裂球仍严格遵守 v0.9B 的碰撞法线与反射，不增加自动追踪。
- 每次真实撞击可释放自己的闪电链。**同一时刻多颗球可以分别触发**，没有全局闪电 CD；每个球仅对自身做 160ms 冷却，避免贴住同一块装甲时无限触发。
- 每链最多 3 次**额外**一点击打，优先选择存活的数字装甲砖；每个目标一轮最多一次；闪电伤害通过原有 `hitBrick(lightning)`，即 HP–1、HP1→破甲、最终击碎的原规则。
- 数字装甲已经全部破光时，每次真实撞击最多顺带清理 1 个普通目标，不让 2 颗球立即清完整个残局。
- 闪电间只有最短的闪光连接，单一闪电动画约 300ms，42 段队列上限；闪电伤害**不会递归再触发闪电**。巨型球在残局的真实撞击也可成为独立起点，但遵守自身冷却。
- 所有旧有四项成长、原有普通球/巨型球反射、真实碰撞判定、342 块砖、四波、三次升级机会完全保留。

## 快速残局测试与最后一块装甲
两版均提供「快速体验最后 8 块」按钮，将当前波设置为分散的 3 块数字装甲和 5 块普通砖；按钮不会自动造成任何命中，玩家仍须自己打中第一块。B 版最后一块若仍带数字装甲，真实碰撞还会触发一次仅造成额外 1 点装甲伤害的电流回响，不会自行消灭最终普通砖。

## 实测
`node v10-final-rush-test.js`，在 `compare/` 目录执行。覆盖：两版基线一致；统一门槛8；从不无条件自动触发；A 真正命中后自动清到最后；B 两个不同弹球在同一时刻分别触发闪电并保留撞甲反射；没有递归清屏；减少动态效果、四波完整通关、旧升级逻辑。

模拟结果：A 8砖残局追猎 3.6秒（约9次额外追击），B 两球同时碰撞产生2次独立闪电起点、2次额外一点击打、未直接清屏。四波自动瞄准 A约90.6秒，B约94.2秒，342砖均正常清完。这些是程序测试而非真人数据或真机帧率。
