# 《弹珠超载》M1.3 — 新手循序渐进与单手技能操作

完整产品仍以50波连续Build为目标，当前M1.3是独立10波候选；旧版未改动。

## 核心变化
- 第1波**不弹出技能选择**，直接使用普通炮台；首波调整为35块低耐久砖（首轮教学配置，需真人反馈）。
- 第1波真正清屏后，第一次三选一选择裂变、电弧、机枪。之后照旧每波一次三选一、永久Build不断累积；不提前增发永久强化奖励。
- 超载主动在第一次升级后解锁；首次能量满时出现一次非阻塞的“松开瞄准后点按钮”说明。首次成功释放记入浏览器LocalStorage，后续新局不再提示；设备或浏览器数据清空后会再次提示。
- 主动按钮扩大，支持右下或左下选择、保存用户偏好。松手后瞄准角度锁定，不需要两个手指同时按住。另提供可选“能量满时自动释放”（默认关闭，按当前瞄准方向），减少单手腾指。
- 原M1.2基础伤害1、球速330、Boss与压力修复、简明技能卡、真实清屏、限时Buff不变。第一波新计数`shotsByBuild.base`避免无流派时产生NaN统计。
