## 关卡结构
- 1–4：基础弹射和第一项技能选择；第1关仍使用普通炮台，首轮清屏才选裂变/电弧/机枪。
- **第5关精英**：带独立HP的宽体橙色精英砖（32HP测试），周围低中耐久砖供反弹。没有额外升级奖励，不是Boss。
- 6–9：中等HP与低HP交错，持续构筑。
- **第10关Boss**：128HP测试Boss，顶部/左右22–39HP护甲砖，下方3–7HP低数字砖引导；中下部中心3列保持开放，尝试从底部进入后在Boss/护甲之间反复弹反。Boss有限召唤保留，且不应封闭中心入口。
- 11–15：专精第2级在清除11波后可选，裂变+1子球/追猎+1、电弧+1传播/单体+3、机枪直线/扇面射速增长，数值待平衡。
- 16–20：后期砖块HP重新分布，降低超高数字砖比例，增加2–6HP低数字砖与12–38HP中高耐久目标相邻，突出成型Build多次反弹、连击和大面积破坏，不再靠持续增加HP拖慢。
- 全部20关真正清空后结算；清1–19波共19次永久升级；不在第10或第15波重置。

## 直达Boss调试入口
起始界面选择裂变/电弧/机枪Build，点击“直达第10关 Boss”；自动构筑9次有效技能升级，跳转Boss关并充满超载。此行为是调试捷径，**不是正常通关**，不会声称玩家已完成前9波。原始炮台仍可从第1波正常挑战。
