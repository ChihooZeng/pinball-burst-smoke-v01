# 弹珠超载 v0.24 — 桥接弹球连击 + 真实清屏窗口

2026-10-29。基于玩家已认可的 v0.23 **独立对照实验版**，保留 v0.23 的规范砖块、无重叠物理、成长阶段、数字循环色盘、召唤 Boss、手机单屏和音频启动。

## 本轮反馈 / 对应设计

1. **只剩上层砖，弹珠向下空跑**：把场地按砖块 y 位置分为上（<175）、中（175–274）、下（≥275）三层；非前期且场上超过6块砖时，若下层少于3块或中+下少于6块持续约0.8秒，尝试触发中下层桥接召唤。砖位以第 2、5、8 列及中间等独立标准格子为主，y≈230、279–333，最大底边在警戒线之上至少约100px。保持不重叠；同列下降队列也进行间隔约束。
2. **下层召唤砖需要适合局面的 HP**：普通桥接以 HP=1–3 为主（容易清理）；“只剩明显上层砖阵”时改用阶段性中耐久（前期约 HP 3–6，之后随存活时间提高），延长弹球在上下之间往返的机会。
3. **虚线预告太突兀**：普通召唤、桥接召唤、Boss 召唤统一 1.0 秒预告。清屏大潮专用 0.85 秒预告。
4. **给玩家真正清屏的机会**：剩余1–6块、没有存活 Boss 时暂停补砖并取消未完成的普通预告，开启约2.1秒清理窗口。真的全部击碎后才计入清屏次数与奖励，非剧情强制清场。清屏后先保留 0.6 秒真正空场，再显示 0.85 秒不参与碰撞的整片虚线，最后实体化。仍有少量残砖时才在宽限后考虑最多3块的轻量恢复砖。
5. **清屏后不要只补顶部一大片**：新的清屏砖阵包含9行标准砖（后期10行），分别落在上、中、下区，底部两行留下三处通道，首波约78块、后期约87块。下层 HP 低，中层混合，上层按当前耐久梯度。不是整屏突然出现。

## 安全 / 性能取舍

- 桥接砖比普通砖慢速下降（约38%），目的在于制造反弹承接，而不是生成10秒就压线的不可避免失败。相邻列内进行垂直间距约束，不容许普通砖穿过桥接砖造成重叠。
- 前 26 秒不自动触发桥接，避免入门阶段主动给玩家制造贴近警戒线的危险砖。
- v0.23 的旧版召唤、彩色 HP、非自动四职业、音效、物理固定120Hz、按 rAF 60/120Hz 实际渲染全部保留。浏览器不能被代码强制提供 120 FPS，真机稳定帧率仍需真人验证。

## 试玩观察重点

- 60–120秒是否避免出现“只有上半场砖、下半场全空”的断链情形；
- 桥接砖是否足够耐打且能反弹，但不因为靠近危险线而造成失控；
- 清屏宽限与0.6+0.85秒节奏是否恰好，让玩家真的感到自己完成清屏；
- 后期清屏过频是否削弱了“难得一见的成就感”；
- iPhone Safari 真机 FPS 与碰撞视觉清晰度。
