# 弹球暴走 v0.10B：多球连锁闪电

试玩：https://chihoozeng.github.io/pinball-burst-smoke-v01/compare/hybrid-v10b-lightning/

基于与 A 完全相同的四波、342 块、两阶段破甲与升级。每波剩余 ≤8 块后，每颗普通、分裂或巨型球在真实撞砖时可独立产生闪电链，向其他最多 3 块数字装甲分别施加 1 点伤害，依然执行正常扣血及破甲转换；电流绝不递归触发新的电流。原球保持自然反射，单球触发间隔 ≥160ms；多球同时命中则可分别触发。

数字甲全部消失时，每次命中最多补刀 1 块普通砖；如果最后只剩 1 块数字甲，实际命中可触发额外 1 点的电流回响，但不会自动销毁最后的普通砖。可在页面点「快速体验最后 8 块」，直接模拟散布的 3 块数字甲和 5 块普通砖，不产生免费伤害。

软件模拟：两球同帧命中产生两次独立电链、未直接清屏；四波约 94.2 秒完成。运行回归：node v10-final-rush-test.js（compare 目录）。未测试真实 iPhone Safari 帧率。
