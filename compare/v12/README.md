# 弹球暴走 v0.12 — 雷链炮台职业与加长局实验

试玩入口：https://chihoozeng.github.io/pinball-burst-smoke-v01/compare/v12/
新版本：https://chihoozeng.github.io/pinball-burst-smoke-v01/compare/hybrid-v12-storm/
旧渐进闪电对照：https://chihoozeng.github.io/pinball-burst-smoke-v01/compare/hybrid-v11b-progressive/

## 核心决策
- 渐进式闪电不再是所有未来炮台无条件自带的公共能力，而是「雷链炮台 Storm Cannon」的被动能力。当前只实现一种可玩的炮台；不得误称已有多职业切换。
- 巨型球作为「主动技能槽」里目前装备的 giant 技能。充能、触发和当前巨型球行为全部沿用；通过技能注册表及派发函数预留以后替换技能的接口。**尚未加入第二种可装备主动技能**。
- 以后计划的速度球、追踪球、激光球保持独立方向，没有在本版本加入。

## 砖块数值（对照试验）
- 四波生成：72 / 81 / 90 / 99，总计 342，九列网格与砖间隙不变。
- 数字装甲初始 HP：2 / 3 / 4 / 5 → **4 / 7 / 10 / 13**；装甲数量依波次 11 / 12 / 13 / 15 不变（合计 51）。
- 非装甲砖仍一击击碎并允许穿透；装甲每击扣 1 并按照物理法线反弹，HP 归零后先破甲成普通砖，下一次才消除。
- 渐进电流仍按剩余砖块比率分级（30%、15%、≤8）；每个真实撞击下分别三撞单链/双撞双链/每撞三链，闪电伤害为 1，不递归，不瞬间全屏清除。
- 目标是增加反弹支点使用时间而非静态拖长时间。旧 3 个成长选择和基础自动射速均未改变。

## 回归与对照（模拟数据）
运行：`cd compare && node v12-storm-test.js`。
同样的自动瞄准及升级路线，旧 v0.11B **74.9 秒**，新 v0.12 **166.5 秒**完成全部 342 块。最高连击旧 76 / 新 67；新版本 453 次装甲扣血/破甲击打，51 次破甲。
四波最后 8 块的模拟耗时依次 **5.05 / 2.13 / 6.50 / 7.92 秒**，未出现新耐久让尾局无限卡住的现象。
上述是 Node 模拟脚本，不是玩家用时或真实 iPhone FPS；手感仍以真人试玩为准。

## 需要真人验证

3. 三次升级与巨型球主动槽是否让玩家觉得真正搭建了自己的攻击构筑？
4. 高 HP 在 29px 宽的装甲砖上是否仍能清晰看清？
