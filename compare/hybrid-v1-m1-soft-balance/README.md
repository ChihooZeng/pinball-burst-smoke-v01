# 《弹珠超载》M1｜伤害与球速调弱实验版

> 2026-10-30。用户反馈原M1过强：HP3砖可能一次被打碎、弹球飞行过快。此版为**独立对照**；没有改动旧M1、B版、默认入口。
> 50波是完整游戏目标，本候选只测试前10波。

| 项目 | 原M1 | 此实验版 |
| --- | ---: | ---: |
| 普通弹球基础直接伤害 | 2 | **1** |
| 普通弹球基础飞行速度 | 365 | **330**（降低约9.6%） |
| 普通炮台发射间隔 | 0.86秒 | 保持0.86秒 |
| 机枪基础发射间隔 | 0.35秒 | 保持0.35秒 |

**为什么一击打碎HP3？** 原M1未强化普通球一击伤害2，HP3正常应余1；临时15秒「强击」Buff使直接伤害+1，以及已获得的火力强化、侧墙蓄势、穿透球强化，可能把直接伤害增至3或更高。电弧也可在直接命中后补刀。**不是所有HP3砖都自然一击消失。**

新版本在没有Buff/强化时，对HP3普通砖的一次真实直接碰撞造成1点伤害，应该剩2；取得强化后仍可一击消除，属于成长收益。保留技能卡、暂停Build、15/30秒跨波Buff、32球预算、Boss、升级规则、所有技能逻辑和50波产品方向。
