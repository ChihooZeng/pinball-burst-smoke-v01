# 弹珠超载 v0.23 — 规范化砖阵

基于 v0.22 的独立试玩对照版。**只解决重叠砖块带来的杂乱与清理困难**，保留 v0.22 的连续生存、常驻召唤、清屏大砖潮、Boss 召唤、经验三选一和循环色盘。v0.22 未覆盖。

## 变化

- **统一尺寸**：所有普通数字砖及 Boss 辅助砖均为 29×22（Boss 核心本身继续使用大尺寸）；移除所有 22×16 的重叠小砖、局部叠层描边和重叠式成形。
- **禁止覆盖**：普通落砖、常驻中场召唤、Boss 召唤均在正式生成前检查目标位置是否与已有砖块或待生成提示区域相交。已有的普通砖可以转化为 Boss 辅助砖，不需要堆一个新碰撞盒。
- **保留中场密度**：清屏约 0.42 秒后，直接在危险线之上的中场生成 9×9=81 块标准砖；第四次清屏后最多 10×9=90 块。保留原有高低耐久砖混合和入场特效。
- **不会失去召唤机制**：平时的常驻召唤、场面过疏时的增援及 Boss 的动态召唤数量仍然存在，只调整成有空位才生效。
- **UI**：标题改为 CLEAN GRID · v0.23。

## 已验证

- `cd compare && node --check hybrid-v23-clean-grid/game.js` PASS。
- `cd compare && node v23-clean-grid-test.js` PASS：初始 60/120Hz 时间一致、升级暂停、伤害和 Boss 击杀、循环色盘、清屏完整 81 块、普通召唤及增援实际生效、长局与爆发构筑中每约 1.5 秒检查重叠数为零。
- `cd compare && node v23-mobile-cdp-qa.js` PASS：390×844、375×667、320×568 无滚动或控件裁切；真实点击激活音效；在线等效本地环境正常召唤；清屏 81 块；浏览器 JS 无异常。
- 人工体验仍需实测：移除部分易碎小砖后，自动瞄准的弱构筑在约 90 秒结束，强力构筑仍能生存约 300 秒并清屏多次。这是自动模拟数据，不是玩家生存时间保证，也不是已经完成的平衡定论。
- FPS 由硬件与浏览器实际刷新率决定，不能宣称在手机上稳定 120 FPS。
