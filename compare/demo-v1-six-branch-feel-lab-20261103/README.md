- 测试场景下拉选：第6波密集砖阵，或第10波Boss+护甲。
- 选择一个分支即可直达同一测试场景；各分支同场景使用同一块砖阵、相同升级次数。
- 本局禁用巨型球，避免它掩盖分支本身的差异。
- 暂停和结束页面返回六分支速测菜单；亦可从第一波正常闯关。
- 对照顺序建议：裂变 A/B → 电弧 A/B → 机枪 A/B，每组在两个场景至少各玩一次。
