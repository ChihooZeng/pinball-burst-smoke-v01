# 《弹球暴走》v0.7 — 细弹珠 + 更多砖块 + 强视觉冲击实验

试玩：https://chihoozeng.github.io/pinball-burst-smoke-v01/compare/hybrid-v07-density/
上一版 v0.6.1：https://chihoozeng.github.io/pinball-burst-smoke-v01/compare/hybrid-v061-hitfeel/

## 变更范围
在玩家确认偏好的 B 版 v0.6.1 基础上做独立分支，不覆盖上一版。仅调整砖块几何、普通弹珠尺寸/飞行速度与视觉冲击级别。
保留固定三波、手指水平瞄准、自动发射、巨型球、充能、升级二选一、正常砖一击消除、数字装甲砖多次命中、原始射速节奏。
不调用 iOS/Android 物理振动或第三方 haptics。

## 视觉冲击
- 原先「增强」成为默认「标准」，避免原本的默认档反馈偏弱。
- 新增可切换「更强冲击」，提升受击回弹、微震、碎片密度、残影亮度，不改物理/伤害计算。
- 镜头微震上限严格限制（最多 4.7 画布坐标单位）；单独次命中有频控，密集攻击不会强制停顿。
- 用户开启系统“减少动态效果”时自动关闭新增高强度动态特效。
- 小尺寸弹珠略增加轨迹可视度，不将其碰撞体放大回原来的尺寸。

## 验证
- `node --check game.js`
- `node --check juice-fx.js`
- `node density-test.js`
- 自动检查已覆盖 54/63/72 块、8/9/11 块数字装甲、HP 2/3/4、发射间隔、炮台瞄准、碰撞闪光、受击回弹、巨型球、升级、对照强度切换、 reduced-motion、实际砖缝通过、视觉效果上限和完整通关。
- 同一智能瞄准脚本约 122 秒通关 189 块，比 v0.6.1 约 113 秒通关 126 块略长。仅为程序模拟，不是真人试玩时长。
- Edge 本地 390×844 和 320×640 尺寸打开并截图通过；真实 iPhone Safari 触感、FPS 和小砖可读性仍需人工验证。

## 验证目标
1. 是否更容易打出弹珠沿砖缝穿梭、从侧面破坏的精彩路径？
2. 砖块增密后是否带来更长但不过度拖沓的一局？
3. 新标准动效与更强动效哪个更舒服？是否存在晃动疲劳？
