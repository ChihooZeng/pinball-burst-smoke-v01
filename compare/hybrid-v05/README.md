# 弹球暴走 B v0.5 — 密集破坏与连击动效实验

线上试玩： https://chihoozeng.github.io/pinball-burst-smoke-v01/compare/hybrid-v05/

## 改动范围
基于已验证的 B 版复制新分支，不修改原来的 A/B 对照，也不改生存版。

- 砖块由 5 列改成 7 列，尺寸 57×32 → 38×27（原尺寸缩减，仍保留点击目标和装甲数字可读性）
- 砖块从 15 / 20 / 25 块每波变成 35 / 42 / 49，每局总数从 60 增加到 126，数量约为原来 2.1 倍
- 每波约 14% 为数字装甲砖（5 / 6 / 7 块），HP 依次为 2、3、4；其余普通砖仍是一击即碎
- 保留原来的 1.00 → 0.90 → 0.82 秒射速、两次波次强化、反弹溅射、能量巨型贯穿球与结束结算
- 增加视觉反馈：装甲受击压缩回弹与 HP -1 浮字，击碎短促光环和碎片，连续击碎 Combo 提示与递增音调，巨型球击碎引起极轻的画面震动
- 不使用每次命中都晃屏；不暂停物理帧；粒子≤220、环≤28、浮字≤36，尊重 prefers-reduced-motion

## 为什么这么做
用户反馈 B 版更有参与感，但目标数量太少，清空三波过快。
增加可破坏目标，而不是提高所有砖块 HP；用轻、重不同的反馈让普通击中、装甲伤害、砖块破碎和连锁清除产生层次。
先不加更多炮台、闪电、金币和长期养成。

## 验收
`node --check game.js`
`node v05-test.js`
Microsoft Edge 390×844 网页渲染截图已验证页面加载。
自动测试覆盖三波数量、各波装甲 HP、射速、瞄准、碰撞浮字、冲击波、减弱动态效果、波次选择、巨型球、重开，单个智能瞄准脚本 113 秒打通三波。这是模拟参考值，不是 iPhone 实际体验成绩。
