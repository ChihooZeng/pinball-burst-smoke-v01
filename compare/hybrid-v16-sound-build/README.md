# 《弹球暴走》v0.16 — 音效与技能全面重做

日期：2026-10-28；从 v0.15 原版复制为独立对照目录 `compare/hybrid-v16-sound-build/`。
保留 v0.14 与 v0.15，不覆盖其源码和测试。

## 核心变动

### 重新设计 6 个升级（每个最高 2 级，9 次关间选择）
- **钻头穿阵**：每 4 发产生 1 颗钻头，装甲碰撞不反弹，最多贯穿 3 块；Lv2 每 3 发贯穿 5 块且装甲伤害更高。
- **碎星裂变**：主球首次击砖，裂变 2 颗侧向小球；Lv2 裂变 4 颗。子球只分裂一次，不无限递归。
- **追猎弯弹**：侧墙反弹后追踪高耐久砖一次；Lv2 最多两次，改变真实速度方向与弹道。
- **震荡核心**：普通球每累计 4 次直接击碎释放范围冲击（可击装甲）；Lv2 每 3 次释放更强冲击；钻头击碎可更快充能。震荡击碎不二次递归。
- **蓄能弹跳**：侧墙碰撞积累下一次直接命中的额外装甲伤害，Lv2 上限提升。
- **电弧印记**：每 3 次直接碰撞释放 1 道电弧，Lv2 每 2 次释放 2 道。分裂小球可频繁触发，但单球限频，不无限递归。

### 可辨识的 Build
- 钻头 + 震荡 = 爆破钻头（贯穿造成的直接击碎更频繁释放冲击）
- 裂变 + 电弧 = 电弧弹幕（小球本身也触发电弧）
- 蓄能 + 追猎 = 追猎回旋（撞墙蓄能并转向剩余装甲）

原有快速装填、折射强化、分裂齐射、连锁爆破、碎甲强化、电弧扩散六张旧卡全部移除，旧「雷链炮台」随残局分段触发的免费被动雷链关闭。基础球的 2 HP 装甲伤害与立即击碎保留。

### 主动技能与音效
- 「巨型球」改名为「超载冲锋」：仍然有 5 秒、最高贯穿 10 块限制，结束时留下三颗小弹球，让主动技能自然衔接普通球。
- Web Audio 全新混音：多振荡器层次、低频打击/碎裂高频、电击、追踪、升级、超载等不同声音；动态压缩限幅防止大量连锁削波。
- 音量条 0–100%，默认 78%，按键试听；浏览器需用户第一次手势才能启动音频。
- 不下载外部音效文件、不请求额外音频权限。
