# 《弹球暴走》v0.9 持续爽感 A/B 试验

入口：https://chihoozeng.github.io/pinball-burst-smoke-v01/compare/v09/
A：https://chihoozeng.github.io/pinball-burst-smoke-v01/compare/hybrid-v09a-longrun/
B：https://chihoozeng.github.io/pinball-burst-smoke-v01/compare/hybrid-v09b-armor/
基线 v0.8：https://chihoozeng.github.io/pinball-burst-smoke-v01/compare/hybrid-v08-ricochet/

唯一要回答的问题：玩家是否能在一次游戏内持续体验有成长、有预期的连锁破坏，而不会「刚爽起来就通关」。

## 已实现的共同规则
- 固定 4 波、每波 72 / 81 / 90 / 99（累计 342）块，9 列，每波 8 / 9 / 10 / 11 行；块尺寸 29×22，不为了增量继续缩小。
- 甲砖数为 11 / 12 / 13 / 15，占约 15%，沿用 v0.8 布局计算；其余仍为一击可碎的普通砖，保证清除反馈主导。
- 甲砖初始 HP 随波次为 2 / 3 / 4 / 5；不是无限增加难度。
- 连击破坏、可穿缝小球、真实碰撞法线反射、巨型弹球多次贯穿与反弹、自动射击和瞄准不变。
- 原四选一升级（快速装填、折射强化、分裂齐射、连锁爆破）不变；新增第 4 波使局内成长机会从 2 次增加到 3 次。
- 默认最大视觉冲击，保留减少动态效果支持；不调用手机马达。

## A/B 严格控制
- A：装甲 HP 到 0 时直接消失，保留原 v0.8 数字装甲行为。
- B：装甲 HP 最后一点被普通球打掉时，仅外壳碎裂并保留一块一击普通砖，**该次命中依然按接触面反弹**；下一次普通球命中后才会击碎并继续穿透。音画含明确「破甲！」提示。
- B 保留巨型球特殊能力：它仍可立即摧毁装甲；普通球与折射溅射按两阶段破甲规则运作。
- 除上述破甲变化外，A/B 完全使用同一砖阵、布局、射速、升级、随机性/数值、物理求解器与巨型球逻辑。**没有同步提高 B 的装甲比例**，因为那样无法单独判断两阶段规则的作用。

## 已完成验证
- `node --check` for both game.js 和 juice-fx.js，PASS。
- `node v09-comparison-test.js` 在 compare 目录执行，PASS，覆盖四波砖数与甲砖数、HP、3 次升级、自动射击、重开、减少动态效果、破甲真实反弹与最终穿透、巨型球破甲例外以及两版完整通关。
- 同样自动瞄准脚本选「分裂→连爆→折射」：A 342 块约 79.4s、最高连击 82；B 342 块约 107s、最高连击 63。仅为逻辑模拟，不是真实玩家用时、留存、帧率指标。
- Edge 本地 390×844 与 320×640 截图验证，无 iPhone Safari 真机经验数据。

## 未来想法，本轮明确不实现
- **速度球：** 命中后增速，考虑速度上限、碰撞连续性与技能手感。
- **激光球：** 反弹光束持续破坏，避免单点秒杀全屏；需要独立的激光伤害频率、甲砖减伤和能量预算。
这两种强功能必须等当前「持续连击与破甲」确认有趣后再测，避免系统过多造成归因困难。

## 真人最重要的 3 个反馈
1. 哪版更想再玩？哪版能更长地保持连击期待？
2. B 的破甲是否会产生「就差一下、再打一发」的期待，还是增加负担？
3. 四波是否合适，还是应该把成长与连击阶段延后到第五波？
