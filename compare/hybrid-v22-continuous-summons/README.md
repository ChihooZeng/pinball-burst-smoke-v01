# 弹珠超载 v0.22 — 常驻召唤、清屏大潮与可控叠层

**2026-10-29，独立实验版。** 以正式认可的 v0.21 为基准，保留成长曲线、循环色盘、固定 120Hz 物理、移动端布局与 Boss 预警，不覆盖 v0.21。核心方向是把“砖块持续碰撞 + 构筑连锁 + 清屏成就”变成连续循环。

## 本轮设计

### 1. 常驻中场召唤

- 除了原有每约3.5秒生成的普通落砖外，新增常驻召唤。开局约8.4秒触发首波；常态间隔随清屏次数下降，砖潮期间进一步缩短，最快约5.2秒。
- 普通召唤从约2块起步，生存时间和清屏次数提高后逐步增长，最多6块/波；初期砖块软上限之外只允许少量召唤增量，避免玩家尚未建立 Build 就被淹没。
- 召唤位置围绕现有砖块形成不规则簇，限制在 y=48 至 y=315 的安全区域，不会直接刷在警戒线旁；无合适锚点时，在中场随机落位。
- 召唤先显示青绿色轮廓约0.34秒，再缩放成形；新砖最初约0.2秒不参与碰撞。实体化后短暂出现青绿色扩散描边，让玩家更容易感知召唤。

### 2. 清屏后是大规模召唤，而不是顶部小砖阵

- 清屏奖励间隔从约0.55秒缩短为0.42秒。
- 第一轮清屏直接在中场生成 **7×9=63块基础砖 + 14块小型叠层砖 = 77块**，后续可增加至96块。基础砖采用轻微错位与抖动，避免完全机械的网格，同时保留连续弹球轨迹。
- 第四次清屏起基础砖增加至8行，叠层砖数量随清屏次数提高，最高约 **8×9 + 24 = 96块**。
- 新砖 HP 混合：保留较多 HP=1、2–3 和4–7的砖，配合高耐久砖，让电弧、震荡、裂变既能连续触发，也有持续目标。
- 只剩4块以内且2.3秒没有清掉时，常驻召唤会变成一波18–30块的中场增援；若真正清屏，则优先走更大的清屏奖励，不会每帧重复触发。

### 3. 有控制的砖块叠层

- 不再把“砖块发生任何重叠”视为错误。召唤砖会以更小的尺寸偏移叠在既有砖块右下角，形成局部错落和层次；基础数字中心尽量保持可读。
- 清屏大潮包含14–24块小型叠层砖。常驻召唤也会少量叠层。
- Boss 召唤保留“把已有砖转成 Boss 辅助砖”的原有做法，同时在部分重叠位置生成真正的小型叠层砖。
- 不允许完全相同坐标的砖无限叠放；叠层砖使用亮边框和较小数字，减少遮挡。物理仍使用每块砖自己的碰撞盒，需在真人试玩中观察密集重叠时是否出现不自然的卡球。

### 4. Boss 召唤随成长升级

Boss 不再永远固定召唤相同数量：
- 每次召唤数量随玩家等级与 Boss 击败次数提高，约3–6块/次。
- 活跃辅助砖上限随等级增加，最多14块。
- 召唤间隔随等级缩短，最低约3.2秒。
- 预警→实体化效果保留，Boss 核心本身不会被小砖遮盖。

### 5. 性能约束

- 保留 v0.21 的固定物理更新、刷新率驱动绘制、碰撞 AABB 预筛、死砖清理与低帧率降级。
- 普通召唤只增加有限的轮廓绘制，不给每块砖增加昂贵的独立发光粒子。
- 真实手机帧率与密集叠层碰撞仍需设备实测；Headless Edge 的约30 FPS不代表真实设备。

## 真人试玩重点

1. 普通战斗时，中场召唤是否让砖块持续进入弹球轨迹，而不是只增加屏幕负担？
2. 清屏后77–96块的中场大潮，是否比顶部补砖更有“清空→爆发”的成就感？
3. 叠层砖是否增加战场的自然感，还是遮住数字、造成球体卡顿？
4. 常驻召唤的节奏是否紧张但仍可控，尤其在高级技能尚未解锁的前90秒？
5. Boss 召唤规模随等级增长是否太快？若过强，优先调低数量/频率，而不是去掉叠层机制。
