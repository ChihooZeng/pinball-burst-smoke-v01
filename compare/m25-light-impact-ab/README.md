## B版轻快分层规则
- 普通撞高HP砖：**不再全屏震动、不再马达振动**；只保留约55ms浅色局部闪光、约95ms小幅光圈、2颗基准火花和更短的砖块压缩形变。声音变为约820Hz、38ms轻脆正弦音，不再每击打235Hz锯齿波；同一类音效至少95ms间隔。
- 真实击碎一砖：4基准碎片（随品质/性能档适度缩放）、约85ms浅色闪光、约65ms轻微屏幕震动，清脆的580Hz+1160Hz双音且无持续低沉重锤；同类破碎音至少75ms节流。
- **每5次连碎**才强调：更多碎片和波纹、较强但短促的屏幕震动，加入一声短暂中频强化音；仅该类连击里程碑可触发安卓短振动，普通单次不振。
- 巨型球/超载/Boss击杀保留有限重击、外爆与低频（Android振动20ms、180ms最小间隔）。尊重减少动态效果及设置关闭，iPhone Safari网页不承诺实体马达震动。
- 48球上限和低FPS视觉自动降载（FPS<48转lite）维持，性能仍需实测。所有粒子/光圈均有上限，无停帧、无影响物理的缩放。
- 正常入口不会展示Boss快捷测试；`?qa=1`用于开发内部比较相同Build和Boss场景。
