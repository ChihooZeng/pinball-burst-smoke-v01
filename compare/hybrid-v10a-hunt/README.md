# 弹球暴走 v0.10A：追猎弹射

试玩：https://chihoozeng.github.io/pinball-burst-smoke-v01/compare/hybrid-v10a-hunt/

基于 v0.9B，四波 342 块，保留两阶段破甲、四项成长与所有弹球物理机制。每波剩余 ≤8 块时玩家真实命中第一块，命中的弹球进入追猎模式，按目标位置逐个接近，每次抵达都进行真实的一点伤害与破甲；直到清掉本波最后一块。自动追猎速度约 310 画布单位/秒，有明显行程与撞击间隔；其他弹球保持正常运动。

游戏内提供「快速体验最后 8 块」实验入口，当前波会留下 3 块数字甲和 5 块普通砖，但需玩家自己命中才开始追击。

软件模拟：8 块残局约 3.6 秒完成（9 次追加追击）；四波约 90.6 秒结束。运行回归：node v10-final-rush-test.js（compare 目录）。未测试真实 iPhone Safari 帧率。
