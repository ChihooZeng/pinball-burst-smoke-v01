来自 `codex/v027a-buildlab` 的 v0.27a，只在新目录比较“老版为什么更爽”。**不是 v0.27b**，不改变正式成长规则与特殊砖原则。

## 试玩参数（URL 可直接切换）
- A `?feel=v27` — 与原 v0.27a 相同的物理与技能参数，只有界面及观测标签差异。
- B `?feel=tempo` — 在 A 基础上：普通球速 280→365；普通发射间隔 1.14→0.86 秒；基础命中伤害 1→2；机枪球 TTL 2.4→4.1 秒；开局前 0.12 秒就发射第一球。
- C `?feel=chain` — 在 B 基础上：裂变 R1/R2/R3 首次命中分别生 2/3/4 球；星海风暴每次多 1 子球（最多5）；子球真实撞击可按 0.5 电荷累计电弧。全局 0.45 秒最短电弧间隔及所有 32 球、递归防护仍保留。
- D `?feel=chain&pressure=off` — 与 C 相同但砖阵下降速度为 0，仅测试下降压力本身。Boss和全部清屏升级保留。

## 不变的东西
- 每波完全清空→一次三选一；开局 3 种 seed、Rank 与互斥分支、8 波上限、Boss机制、巨型球、现有砖阵与 HP、所有UI/视觉特效基线。
- 特殊砖当前仍为原版即时主动充能；未实现的15/30秒临时 Buff仍不提供永久升级，未来跨波且暂停停表；**没有为实验新增永久成长来源**。
- v0.17 / v0.25 / v0.26 / v0.27a 都不修改；本目录独立投放，不替代主页默认入口。

## 真人试玩顺序
同一手机、每种参数优先用同一个起始流派，至少体验前两波：
1. A→B：只比较球速、破甲、基础连射与机枪留场；
2. B→C：判断更早的裂变、子球电弧是否明显增加有意义的破坏；
3. C→D：判断去掉下降压力是否更轻松、更愿意瞄准。
重复三种起始流派，记录：每波耗时、砖块破碎/秒、空转等待、最后三块收尾耗时、每次升级后是否有明显变化、愿不愿重开。A/B/C/D是逐层改变参数而不是严格单因素因果实验，不应只靠通关秒数判好玩。
