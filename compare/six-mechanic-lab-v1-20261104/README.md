# 六机制实验 V1 · 独立实验室

> 状态：**可试玩机制原型，不是正式技能/平衡定稿。**
> 基于 2026-11-03 冻结版 `96f5d84` 的 `compare/core-foundation-baseline-20261103/` 复制演进。
> 冻结目录、`demo/v1/`、旧 45 关产品线均未修改。

## 1. 怎么运行

```sh
cd compare/six-mechanic-lab-v1-20261104
python3 -m http.server 4184
```

打开 <http://127.0.0.1:4184/>。无需安装依赖、无需构建。

QA / 截图直达（不经过菜单）：

```text
http://127.0.0.1:4184/?mode=S2&scenario=dense
http://127.0.0.1:4184/?test=1&mode=C2&scenario=pressure
```

- `mode`：`none`、`S1`…`S6`、`C1`…`C3`
- `scenario`：`dense`、`sparse`、`pressure`
- `test=1` 才暴露只读/调试用的 `window.__pinballLabTest`；正常入口不暴露可改游戏状态的接口。

## 2. 实验选择

开始页有 **10 个机制入口 + 3 个固定场景**：

| 入口 | 内容 |
|---|---|
| 无技能对照 | 只保留冻结版基础炮台、自动射击、真实 HP、巨型球 |
| S1 砖块开花 | 主炮击碎砖块 → 短寿命子球 |
| S2 弹珠合体 | 真实命中积攒 → 下一发普通弹变冲锋球 |
| S3 引雷针 | 命中布电极 → 电极连线周期伤害 |
| S4 过载短路 | 命中蓄能 → 局部环形冲击 |
| S5 双炮交火 | 左右炮口交替、角度偏移 |
| S6 弹幕倾泻 | 命中蓄势 → 短时快速连射 |
| C1 雷花风暴 | S1+S3：开花子球首次命中布微电极 |
| C2 超载雷核 | S2+S4：冲锋球首次命中释放一次雷核 |
| C3 交错火线 | S5+S6：倾泻时左右错峰交叉 |

场景：

1. **密集低HP**：9×7 低 HP 砖阵，静态；验证成片破坏与触发频率。
2. **稀疏高HP**：3 个 40/64/40 HP 目标 + 少量低 HP 引导砖，静态；验证单体压制。
3. **增援+下落**：初始 6 排砖阵持续下落，每 2.8 秒补充 2 排；触警戒线失败。

暂停面板显示：当前实验组/场景、真实伤害来源计数、峰值球数、电极/过载/倾泻/雷核计数、FPS 与参数版本。

## 3. 保留的底线

- 普通球基础伤害固定 **1**；没有 `bonus`、暗削 HP、自动清屏。
- 所有新增子球、合体分解球、双炮弹流都计入 **48 球硬上限**。
- 伤害来源区分 `cannon`、`bloom`、`merge`、`mergeShard`、`labArea`、`labElectric`、`core`；二次/面积/电流伤害不会推进同类充能或再次生成同类派生物。
- S1 子球不会再开花；C1 微电极只来自开花子球首次命中；电流不会再生成微电极。
- S4 的冲击波不会为过载充能；C2 的雷核不返还过载、不在同一冲锋球重复触发。
- 巨型球独立保留：满能自动释放、5 秒、10 次贯穿预算，不与合体共享能量。
- 冻结版命中反馈、粒子/震屏预算、低帧率 `lite` 降级保留。
- 实验页允许的显式覆盖只有：基础射速 `0.55s`（冻结版 `0.86s`）、场景砖阵、技能参数；均在 `lab-config.js` 中集中标注。

## 4. 参数（全部可调，不是正式平衡）

见 [`lab-config.js`](./lab-config.js)。首轮关键值：

| 机制 | 触发/预算 | 首轮值 |
|---|---|---|
| S1 | 主炮击碎 → 子球 | 2 颗；寿命 1.25s；最多 14 颗活跃；伤害 1 |
| S2 | 真实命中积攒 | 8 次；冲锋 1.35s；6 次贯穿；结束 3 颗子球；出生 ±0.20 rad 轻微校正 |
| S3 | 命中布电极 | 最多 3 枚；寿命 3s；每 0.36s 脉冲；线段半径 14；单脉冲最多 3 目标；伤害 1 |
| S4 | 真实命中蓄能 | 7 次；半径 62；伤害 1；0.08s 重入锁 |
| S5 | 左右交替 | 角度 ±0.055 rad；炮口 ±11；射速间隔 ×0.78 |
| S6 | 真实命中蓄势 | 6 次；持续 1.25s；间隔 ×0.32；冷却 3s |
| C1 | 子球首次命中 | 微电极最多 2；寿命 2.2s；连线规则同 S3 |
| C2 | 冲锋球带核 | 过载 ≥1 时携带 1 个核；首次命中释放半径 58、伤害 1 的脉冲 |
| C3 | S5+S6 | 倾泻时角度偏移 ±0.08；统一射弹预算/冷却 |

### 与冻结版默认值的差异

| 项目 | 冻结版 | 本实验 |
|---|---|---|
| 普通球基础伤害 | 1 | 1（未改） |
| 基础发射间隔 | 0.86s | **0.55s（实验覆盖，便于 10 秒内看到机制）** |
| 同屏物理球上限 | 48 | 48（未改） |
| 巨型球 | 610 速度 / 5s / 10 次贯穿 | 未改，满能自动释放 |
| 关卡 | 20 波、第 5 精英、第 10/20 Boss | 3 个固定场景，无 Boss/升级树 |
| 技能系统 | 六条候选分支 | 本轮 6 单机制 + 3 联动，不写入正式 Build |

除上表明确覆盖外，物理、碰撞、警戒线、暂停、打击反馈、低帧率降级均复用冻结版。**0.55s 不是正式平衡值。**

## 8. 已知问题 / 遗留

1. **S3/C1 电流视觉偏弱**：电极寿命短、线段伤害目标少；10 秒样本 C1 已有 9 点电流伤害，但仍低于 S3 单独使用；下一轮应优先看连线可见度/电极寿命，而不是直接加伤害。
2. **S2/C2 的冲锋球**在玩家瞄准通道已被清空时会空放；当前用 ±0.20 rad 的出生校正缓解，仍应真人验证“是否像自动瞄准”。
3. **基础射速 0.55s 是实验覆盖**，比冻结版 0.86s 快；它让 10 秒内能看到机制，但不能作为正式平衡结论。
4. **dense/sparse 静态**；固定瞄准只清一条通道时会留下另一侧砖，这是玩家瞄准问题，不是自动清屏。没有失败计时。
5. **pressure 的失败已能复现**（无技能约 50 秒触线），但增援节奏/HP 仍需真人调。
6. **没有 Boss、没有正式成长树、没有存档**；这些不在本轮范围。
7. **没有真机 60/120FPS、iPhone 音频、安卓振动证据**；headless 的 0 error 不等于真机 0 问题。
8. **S5 不是纯 DPS 翻倍**：交替单发 + 间隔 ×0.78，理论总 DPS 约 1.28×；是否“像双炮”仍需真人判断。
9. 暂停面板的“炮台总属性/当前能力”是实验信息，不是正式 Build。
