# 弹球暴走 v0.6.1 — 细腻碰撞反馈实验

**体验地址：** https://chihoozeng.github.io/pinball-burst-smoke-v01/compare/hybrid-v061-hitfeel/
**旧 v0.6 对照：** https://chihoozeng.github.io/pinball-burst-smoke-v01/compare/hybrid-v06-juice/

## 只改视觉受力反馈，保留主线
游戏仍是 B 版：三波 35 / 42 / 49 块、装甲 HP 2/3/4、同样的弹球速度、射速上限与升级选项、巨型贯穿球及触摸瞄准。**没有调用手机物理振动 API**，也不做网页隐藏开关尝试。

## 增量视觉反馈
- 一击即碎的普通砖：被击碎时生成不阻塞碰撞判定的压缩亮色残影（约 105ms），常规命中同时给予最高约 0.8px 的短微震（标准档）；碎裂与闪光沿用 v0.6 效果，强化「接触瞬间」。
- 有数字 HP 的装甲砖：每次扣血生成 **180ms** 的局部受力视觉状态，带轻微位移、偏转、短暂压缩与阻尼回弹，原有数字浮字照常保留。受力动画由撞球方向决定，但**仅变换 Canvas 绘制，真实碰撞矩形和 HP 完全不变**。
- 连击微震略强于普通砖；巨型球仍最强。110ms 的画面震动最短间隔防止密集命中变成持续晃屏。
- 旧的「关闭／标准／增强」切换保留：关闭新增视觉模块时，恢复 v0.5 的基础破碎效果。用户启用系统减少动态效果时，新模块停用。
- 新增残影队列 ≤32，旧有碎片 ≤120、火花 ≤90、光斑 ≤24、冲击波 ≤5；状态按生命周期自动清理。
- 不增加屏幕震动音效、受力停顿或主线程等待。

- `node --check juice-fx.js`
