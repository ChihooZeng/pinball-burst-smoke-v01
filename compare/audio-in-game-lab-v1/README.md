# 《弹珠超载》游戏内音效实验室 · Audio Lab V1

**定位**：在真实R1极速补砖战斗过程中，实时试听与切换各游戏事件的音效，不再单独盲听素材。**独立实验，不是正式Demo，也不代表音效已最终定稿。**

## 入口

`compare/audio-in-game-lab-v1/index.html`（GitHub Pages发布后访问）

本页使用V6 R1作为**已获玩家认可的爽感对照底盘**，不采用高HP的R2作为默认：
- 引用V6原始 `style.css`、`juice-fx.js`、`builds.js`，避免重新造游戏；
- 此目录有一份**拷贝并加音效事件钩子的** `game.js` 和 `lab-config.js`，原V6源码和正式 `demo/v1/` 都不改；
- 玩法保持V6实验机制、48球物理上限和真实HP，不加隐藏伤害；
- 默认按固定 seed `20261105` 开始R1；每次点击技能按钮，会**重开**对应技能的完整R1战场，音效选择不会清空。

## 功能

1. **20×10=200备选**：音效事件包含机枪、普通命中、击碎、装甲命中、砖块开花、植雷、爆雷、清屏、失败、升级。各10个来自V4原选型目录，另10个来自同索引的新增CC0真实文件。每组的20个`url`互不重复（可追溯到 `extra-catalog.js`）。
2. **实际事件驱动**：V6游戏中的`playSfx(armor/break/upgrade)`，普通砖直接命中，S1开花，S8植雷与真实爆雷队列、M1/M2发射、真实清屏和失败被接至音效控制台；音量、静音和声音换档立即作用于后续事件。
3. **技能单独测试**：无技能/S1/M1/S8沿用V6；另仅在此目录新增M2扇形和C1联动两个**音效实验模式**。切技能会重开场景，不支持不中断当前游戏原地改技能。
4. **原版A/B**：A保留V6现有M2.5合成音（部分新事件在A本来就是无声）；B使用自选声音。由于新旧声音素材和链路不同，音量不保证严格一致；可用总音量、分组音量校准。
5. **控制**：每组独立选音、3秒连发、单次试听、单组静音/音量；自动保存在本机LocalStorage，可导出JSON。移动端为按钮呼出的全屏滚动面板，关闭后继续操作游戏。
6. **音频QA**：只按需加载和解码正在试听/选中的音效，不把200段全部预加载；系统限制密集撞击的触发间隔和并发声部，总线使用压缩器，防止极端瞬间大声量；播放器会在手机首次用户手势后恢复AudioContext。音量仅供当前实验参考。

## 验收与局限

手动验收顺序：
1. 开始无技能、R1，切到B组，打砖感受`hit`和`break`，再切A对照；
2. 切M1，检验真实12.5发/s连射，循环替换mg-01/02/03，注意是否压成嗡嗡声；
3. 切S1，确认开花成功时播放选中的`bloom`；切S8，确认植雷与爆雷分别触发；
4. 单独调`boom`、`break`、`hit`的音量，检查大范围连锁是否太重；
5. 将`clear`和`upgrade`切成不同音效，检查是否表达不同语义；
6. 手机端打开/关闭面板，确认瞄准与触摸行为不被遮挡，设置刷新后仍保留；
7. 导出JSON确认10类音效和技能/音量配置被保存。

已知风险：
- 此页基于**V6原型R1**，不是最新版正式15关/20关Boss完整Demo。M2、C1只是临时实验模式。
- 不保证第三方音源在所有地区都可访问；加载失败会提示。已选V4音效优先从本仓库加载。
- 外部素材未逐条由人耳验收；20项/类只是听感候选的覆盖范围，不是20套正式游戏音频成品。
- 客观声学校准仅用于降低音量差异，不能替代真实手机扬声器的测试。
- 游戏内测试需要进一步用移动设备、多人听测与长期连续触发来确认听觉疲劳、性能/断音与混音。
