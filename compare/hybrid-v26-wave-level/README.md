# 弹珠超载 v0.26 — 逐波升级（Wave Level）

基于已认可的 **v0.25 整波召唤**，独立创建 v0.26，不覆盖 v0.25。保留一局到底、每波整阵清屏后下一波、手机单屏、色盘、单炮台、现有技能和有限 Boss 召唤。

## 这版已实现（2026-10-29）

1. **每清完一波，升 1 级且仅获得 1 次三选一技能选择。** 波次中途击砖只获得分数/超载能量，不再触发经验升级；击败 Boss 也不额外给升级，必须清完本波其余砖块。初始 LV.1，完成波 1 → LV.2，以此类推；技能和 Build 跨波次保留。
2. **关卡转换严格清场。** 真正清空整波时立即移除所有留存弹球、裂变弹以及正在持续的巨型弹（清空普通球数组和巨型技能实体），清除上一波电弧，停止新弹发射。随后暂停于升级面板，选完后才走约 0.6s 清屏庆祝和 0.9s 虚线预告，进入下一波；没有旧球直接打穿新波。
3. **砖块下落加快到介于两版之间。** v0.25 起始 5.0 px/s，v0.24 起始 11.2 px/s；v0.26 起始 **6.8 px/s**，每波 +0.09，正常最高 8.4。Boss 波为普通波速度的 90%，避免更少的升级机会让首次 Boss 无法突破。
4. **升级节奏适配。** 开局前两次强化以射速/弹速/续航为主，LV3–5 加入火力、追猎、钻头等，中后期 LV6+ 进入散射、裂变、电弧、震荡。未增加天赋或新的职业/技能。Boss 血量按每波升级的新成长节奏重新标定，第 4 波约 52HP，之后随波次提高；不改变 Boss 核心与有限辅助召唤结构。
5. **HUD 清晰区分波次与升级。** 原 XP 进度条调整为“第 N 波 · 已清理 X/本波目标 · 清屏升级”；LV 数字仅通过波次完成变化。顶部第 N 波仍保留。

## 明确保留到后续规划

- Boss 最后独自存活时，如何增加持续打击感：多形态、大型 Boss 特殊破坏武器、辅助机制与技能联动；
- “只剩最后一块自动降至 1HP”作为**技能/天赋候选**，当前版本没有做成免费全局功能；
- 3 选 1 的流派、技能互斥/加成、天赋与中后期重玩成长曲线；
- 更精细的 Boss 单体强度、低血量回合、长期平衡，等待这一版真人体验。
