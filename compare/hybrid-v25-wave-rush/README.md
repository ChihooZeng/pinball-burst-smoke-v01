# 弹珠超载 v0.25 — 整波召唤 / Wave Rush

独立对照试玩版，以 v0.24 为起点。**v0.24 原版不修改**。核心循环：一整波密集砖阵缓慢下降 → 玩家用现有 Build 逐块破坏 → **真实清屏** → 0.6 秒庆祝空场 → 0.9 秒整片虚线预告 → 下一整波正式生成。

## 本轮确认范围

- 不再按时间补充普通新砖；移除正常战斗的顶端补行、常驻中场召唤、桥接召唤、零星援军、周期性砖潮。普通波次必须清理所有砖后才前往下一波，整个生存 run 的玩家等级和技能不重置。
- 每波开始在 y=36 至 y=282 的高密度安全区域布下 9 行标准砖（默认 78 块）。最下层砖底距离 y=455 警戒线 **173px**，没有贴近警戒线的突然召唤。下层 3 处空位保留部分球路；整波同时开始缓慢下降。
- 下降速度起始约 **5.0px/s**，每波略微增加，上限 6.1px/s；v0.24 起始速度 11.2px/s。本版本的压力来自整个砖阵逐步靠近危险线，而非在靠近危险线的位置突然生成目标。
- 数字耐久每 2 波提升一级，并保留约四分之一至三分之一的低数字砖，用于保持碎裂和连击。底部两行以 HP1–3 为主，少量略高 HP 充当反弹目标。最后剩余≤3块且局内战斗超过12秒时可温和削弱为3HP，仍须由弹球真正击碎。
- **每4波出现 Boss**（4、8、12……）；Boss 在整波砖阵中间出现，附近留出核心位置，不与普通砖重叠。只有 Boss 可在该波中途召唤辅助砖；有限的最大召唤预算为12块、间隔约7秒。击败 Boss 后不会再召唤，须清掉其余残砖才进入下一波。
- 玩家选择的基础训练、火力、散射、裂变、闪电、电弧、震荡等技能及经验持续累积，不做职业选择、单波结算商城或 Build 重置。
- 顶部 HUD 新增第 N 波标识，同时保留生存时间与击碎统计。高帧率物理基线延续 v0.24（120Hz 固定模拟 / 屏幕 rAF 绘制 / 10Hz UI），不承诺任何手机强制120FPS。

## 验证与阶段结论

- `cd compare && node --check hybrid-v25-wave-rush/game.js` — PASS。
- `cd compare && node v25-wave-rush-test.js` — PASS。验证开局78块、初始危险线距离173px、前10秒不补砖、0.6秒空场+0.9秒虚线预警、清屏进入下一波、Boss 第4波和有限召唤、危险线失败、60/120Hz时间一致；两条模拟路线不产生普通召唤。
- 自动瞄准模拟（不代表真人表现）：普通成长路线约258秒推进至第7波、清屏6次；爆发型路线约299秒到第20波、清屏19次。后者清屏频率偏高，需真人体验评估是否使成就感降低。
- `cd compare && node v25-mobile-cdp-qa.js` — PASS。390×844、375×667、320×568 无纵向溢出或控件遮挡，开局音效手势、Boss 演示、完整虚线预告、下一波实体化、JS 无异常。
- Edge Headless 在静止和战斗时约30 FPS 是测试环境现象，无法代表手机屏幕真实性能；实际 Safari iPhone 60/120 FPS 待真机确认。

## 核心人工 Gate

1. 真人第一波是否来得及打完，而不是每次都在接近警戒线时输掉；
2. 整波密集阵列是否解决等待零星砖的空窗，破坏感是否延长；
3. 爆发型 Build 是否太快连续清屏，应按体验调整波次 HP 而不是无意义增加砖数；
4. Boss 波次是否依然形成重复反弹、有限召唤不拖死整波；
5. 手机音效、帧率和长局功耗。
