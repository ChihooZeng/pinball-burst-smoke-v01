## 2. 核心结论（45 秒 · 自动转火）

| 对比 | A | B | C |
|---|---|---|---|
| 最长破坏空档（M1） | 10.46s | 4.03s | **2.07s** |
| 最长破坏空档（S1） | 17.17s | 2.21s | 2.52s |
| 等待补砖（M1） | 0 | 6.68s | **1.60s** |
| 清屏时间（S8） | 33.1s | 9.4s | 25.9s |

- C 在"破坏连续性"和"减少等待"两项上明确优于 A/B。
- B 供砖最猛，但会把 S8 的高潮压缩到 9 秒；C 把同一段高潮拉到 26 秒。
- A 的 10–17 秒空档复现了原始问题。

## 4. 已知问题（必须先看）

1. C 的触发阈值从建议的 48/20 调到 62/10，否则首批要等 25 秒。
2. C 会在 10–20 秒内打光 3 批预算，之后仍会转稀。
3. S8 太强，B/C 都提前清屏，掩盖补阵差异；需削弱爆雷后复测。
4. 未做真机、未做真人；"爽感"全部来自模拟。
5. 自动转火是启发式（找砖最密处），不是真人操作。
6. A 初始 108 块，与 B/C 的 72 不同，只作历史对照。
7. 三场统一落速 4.4（A 原 5.4）以消除混杂变量。
