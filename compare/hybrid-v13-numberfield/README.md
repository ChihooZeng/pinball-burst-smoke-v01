# 《弹球暴走》v0.13 全砖块独立数字实验

正式试玩入口：https://chihoozeng.github.io/pinball-burst-smoke-v01/compare/v13/

上一版 v0.12：https://chihoozeng.github.io/pinball-burst-smoke-v01/compare/hybrid-v12-storm/

## 本版目标
更正先前的误解：用户想要的是**全砖块各自有数字**，不是只把少数数字装甲 HP 提高。
同一行不同砖独立分配 HP，允许不同砖恰好出现相同数字（不是要求 342 个全不重复的数字）。全部砖第一次绘制都展示数字；特殊 ENERGY 砖 HP1 右上角显示小星。

## 生成与分布
总计四波：72 / 81 / 90 / 99，共 342 块。位置和间距保持不变。HP 是通过每波编号、行列位置做确定性哈希生成的稳定数值，避免每刷新都随机变化导致对比无意义。

数值区间与分层偏好（不是每波必须达到固定百分比）：
- 第 1 波：HP1 38%，HP2–3 32%，HP4–5 22%，HP6–7 8%。
- 第 2 波：HP1 33%，HP2–4 31%，HP5–6 27%，HP7–9 9%。
- 第 3 波：HP1 30%，HP2–4 31%，HP5–7 28%，HP8–10 11%。
- 第 4 波：HP1 27%，HP2–5 29%，HP6–8 30%，HP9–12 14%。

## 撞击规则
- **HP1 砖一击爆碎且弹球可继续穿透**：避免全图数字化以后失去原有最爽的连续粉碎。
- **HP≥2 砖每命中一次减少 1**，仍作为弹球反射支点。数值归零时变为有裂痕、无数字的普通砖，下一次击中才真正消失并允许穿透。
- 全砖在健康阶段均显示当前 HP，按 1 / 2–3 / 4–6 / 7+ 进行颜色分层；破甲后颜色变蓝并显示裂纹。
- 圆形与矩形的真实碰撞法线仍作为反射基础。增加同一弹珠在同一砖块物理重叠期间短暂的重复命中防护，防止高密度数值时出现额外扣血。
- 雷链炮台渐进闪电仍优先削数字装甲，早期每3次、阶段2每2次、末期每次碰撞可触发，单段伤害 1 且不会无限递归。
- 巨型球仍可作为主动技能贯穿砖阵，保留其特殊快速粉碎能力；原有升级及四波结构未修改。

## 已运行的回归
`cd compare && node v13-numberfield-test.js`
- 四波所有砖均初始带数值，HP 范围与低中高分布合法；
- 刷新后数字分布稳定；HP1 立即清除，其他数字扣血，归零破甲，下一击消除；
- 真正运动中的弹球扣血与自然反弹；渐进闪电削多个独立数字；
- 雷链炮台与巨型球槽、减少动态效果、四波完整通关保留；
- 同一自动瞄准/成长脚本：旧 v0.12 166.5s，新 v0.13 174.9s；旧 maxCombo 67，新 58；新版装甲命中 1161 次、破甲 223 次。
- 四波最后 8 块分别耗时 3.37 / 6.90 / 4.03 / 4.80 秒（逻辑模拟）。

以上不代表真人游玩时间，实际 iPhone Safari 性能与手感待真机验证。

## 本轮明确未实现
没有新增其他职业、其他主动技能、速度球、激光球、追踪球。需先明确数字砖让玩家「连续扣血与碎裂」更爽，还是使普通穿透变少。
