# 弹球暴走 v0.8：连续击碎与真实法线反弹（实验版）

线上链接：https://chihoozeng.github.io/pinball-burst-smoke-v01/compare/hybrid-v08-ricochet/

旧版 v0.7：https://chihoozeng.github.io/pinball-burst-smoke-v01/compare/hybrid-v07-density/

## 产品唯一目标
爽：更长的单球连击、进入砖阵后的连锁破坏、可读的碰撞角度、巨型球多次反弹和具备明显体感收益的成长选择。**不是**增加压力、故意拖长战局或堆满特效。

## 本次更新
- 默认打开原 v0.7 的「更强冲击」选项，保留「较柔和」「关闭」用于个人比较；仍然没有手机马达 API。
- 普通球速度从 405 降到 365（约 -9.9%），半径 3.45、9 列密集砖和砖块数量保持 54 / 63 / 72。
- **基础物理调整**：改为圆形与矩形的最近点接触法线计算（侧边 / 上下边 / 角落对角线），反射遵守 v' = v - 2(v·n)n；把球从接触面正确推出，防止反复陷入砖体。保留更精细的分段迭代检测。
- **最重要的连续破坏基础规则**：普通一击即碎砖块被撞碎后，其碰撞体已经不存在，弹珠保留当前方向继续前进，而不再被已消失的砖块反弹出去。打在还有剩余 HP 的装甲砖时，才产生符合碰撞法线的弹开。弹球如果已经穿过砖缝，便有更多机会从砖阵内部制造连续破坏。这可能会明显加快清关，需真人验证。
- **巨型球弹射**：先连续贯穿 2 块砖，在第 3 次撞砖时根据碰撞面反弹并重新获得两次贯穿能力；可撞左右墙、顶部、下方的限定能量屏障。最多存在 3.3 秒或 12 次反弹，以避免单次技能无限挂机。保留对数字装甲的瞬间击碎。
- **新增两项局内成长选择**（连同旧「射速」「折射」合计 4 个选项，每波结束选 1 个，一局最多选 2 次）：
  - 分裂齐射：每第 3 次发射会在当前瞄准角度左右 ±0.17 弧度同时补发 2 颗较小弹球；弹球总数上限 24。
  - 连锁爆破：当正常球引起第 5、10、15… 次连续破坏时，直接击碎最近的最多 2 块、半径 65 内的非装甲砖。升级第二级可击碎最多 3 块；连爆引起的击碎不再递归触发新的连爆。
- 巨型球墙面与砖块反弹附带轻量碎片、折射光效和有节流的声音，不增加游戏逻辑停帧。
- 4 选 1 卡片仍放在原波次升级弹层，在 320/390 手机宽度上渲染。
- 原其他功能保留：手指拖动瞄准、自动发射、短暂停顿升级、3 波固定砖块、绿色 ENERGY 充能、既有视觉冲击分级和 reduced-motion。

## 验证结果
- `node --check game.js` PASS
- `node --check juice-fx.js` PASS
- `node gameplay-test.js` PASS
  - 默认更强冲击、普通子弹速度 365、物理法线与角落对角反射、普通砖贯穿、装甲扣血、巨型球撞砖/撞墙反弹、两项新技能真实 UI 点击、分裂上限、连爆触发、重开、reduced-motion。
  - 确定性追踪瞄准脚本，不使用必杀技能：原有射速/折射成长路线约 **68.6s** 击碎全部 **189** 块，累计自然碰撞 **244** 次，单球最多 **32** 次自然碰撞。

- 本地 Edge 的 390×844、320×640 手机视口截图检查已执行；Safari 真机仍需人工验证。

## 目前最重要的验证点
1. 普通球在砖阵内部连续穿行，会不会由「爽」变成无脑穿透（缺少瞄准价值）？
2. 相比上版 122s，本版平均 59–69s 的三波时长是否过短？
3. 巨型球真实反弹角度是否直观？是否想攒能量再使用？
4. 4 选 1 中「分裂齐射」或「连锁爆破」哪个更容易产生重玩动机？
5. 密集碎片 + 增强档是否出现掉帧或视觉噪声？
