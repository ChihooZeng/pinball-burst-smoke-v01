# 《弹球暴走》A/B 对照实验

## 入口
- A： https://chihoozeng.github.io/pinball-burst-smoke-v01/compare/traditional/
- B： https://chihoozeng.github.io/pinball-burst-smoke-v01/compare/hybrid/
- 统一选择页： https://chihoozeng.github.io/pinball-burst-smoke-v01/compare/

## 目的
验证“少量数字装甲砖是否增加有趣的策略选择，而不会显著降低一击破坏和连锁爽感”。

## 严格控制的维度
基于此前 v0.3 源码的同一固定三波：自动发射、手指水平瞄准、发射间隔 1.00 → 0.90 → 0.82 秒、
每波清空后同样的「射速 vs 折射」二选一、绿砖充能、手动巨型球、粒子特效和球速。
两版为了可玩性，都把巨型球按钮移到战斗画面右下角。
不存在持续下落、局外养成、随机选卡、第二炮台。

## 唯一实验差异
- A：普通非能源砖 HP 1，击中一次即碎。
- B：普通非能源砖中部分橙色装甲砖拥有数字 HP；第一波为 2 点、第二波 3 点、第三波 4 点。
  每波各 2 / 3 / 4 块（分别占 13.3% / 15% / 16%）。
  普通球和折射溅射每次命中装甲砖减 1；巨型贯穿球仍然直接击碎。
  其余砖块照常一击碎，避免整场数字挤压爽感。
- B 的装甲砖没有额外得分或充能，以免引入其他影响变量。

## 测试
- `node --check traditional/game.js`
- `node --check hybrid/game.js`
- `node ab-test.js`
- 已做 390×844 Edge 移动端页面截图检查（不代表 iPhone 真机测试）。
- 模拟相同固定瞄准脚本：A 约 52 秒、B 约 61 秒完成三波，仅作程序运行与机制对照，不是玩家成绩。
