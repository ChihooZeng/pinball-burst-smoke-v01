## 实施
1. **视效与物理碰撞分离**：普通球视觉半径3.45、真实物理碰撞半径2.7；视觉直径6.9、实际碰撞直径5.4。物理反射、侧墙和砖块命中使用碰撞半径；粒子球、拖影用视觉半径。裂变小球同比例缩小，钻头球两个半径同步按1.35倍放大；巨型超载球不改，避免伪造巨型球物理直穿。不能扩大视觉与物理半径差到出现明显穿模。
2. **砖缝稍微缩小但仍可真实穿行**：砖高22、纵向行距33→31，净上下缝11→9，仍大于普通球实际碰撞直径5.4（且大于视觉直径6.9）；水平空隙9.5维持。原长屏到警戒线的距离补偿逻辑自动按行距重新计算，不在所有波增加突兀压力。
3. **Boss10召唤真正的新砖**：原每7秒尝试（总量最多12块、部分只把已有砖转成辅助）→ 每4.6秒尝试一批4块实际实体砖，上限23块新砖、同时存活最多16块；优先顶部和两翼的安全空位，不在Boss下方中央开口新填砖；每块8–20HP、提前1秒虚线预告，保持可撞击的真实数字HP和场上MAX_BRICKS/空位检测。Boss死亡后仍依照原规则处理其有限辅助砖。
4. **Boss10下落更有压迫感**：相对M2.1的Boss专用下降倍率0.9→1.04（其它初期普通关不变）；同时横向通道要保持可攻入，避免只有提高失败率。
5. **Boss20有限三阶段也更紧张**：阶段下降倍率0.24/0.32/0.40→0.29/0.38/0.47；两个阶段新增上限从各15→各18块真实砖，遵守原1.35秒警告、撞击检测、中央入口、阶段HP锁定与真正清屏规则。**不可无穷补砖**。
6. 其它：未选伤害升级前普通球每次直接命中仍1HP、球速330、11–19砖数与阵型/电弧有限击碎续传、第10关25高HP环形护甲、20关清屏结算及50关长期目标均不改变。
