## 实际修改

1. **真实穿缝空间**：普通砖高22，原上下行距28（缝6，小于普通弹球直径6.9）→ 行距33（缝11，能通过）；列距38.5（左右缝9.5）保持。额外的40个逻辑高度通过坠落倍率的基准距离补偿，避免同一手机突然更早触线。
2. **后期阵型密度**：11–19关仍有双翼、漏斗、斜走廊、低位门、双通道的不同结构，新候选每关73–77块，大多数关增加2–8块，但保留真实弹反通道、不强制填满9×9。
3. **第10关Boss高HP护甲环**：25块26–45HP高数字护甲围绕Boss，上层/左右/下侧角形成近环形反弹边界；另有10块4–9HP导向砖；底部中央3列开放。Boss本身128HP、第5关精英、第20关888HP三阶段终局逻辑保持。
4. **后期渐进下降**：11–19关原额外+2.8%每关调为+2.2%每关；同时自动校准增加的纵向高度。短屏/长屏在静态计算中无伤直降危险时间接近前版；注意真实弹球破坏会动态改变危险砖位置，不代表实战难度完全相等。
5. **电弧路线加强**：R1/R2/R3的普通跳电目标从1/2/3提升到2/3/4，半径124/138/150；电弧实际击碎目标时可以沿附近的真实砖块继续跳电，最多6个不同目标、不允许电弧命中递归放电。雷网蔓延R1/R2至少保持原核心目标数，分别可传播4/5目标；雷霆聚能仍是单体专精，不无条件获得群体连锁。记录实际追加跳电数。
6. **保留**：未选伤害强化时每颗普通球直接撞击1伤害、球速330、20波清1–19波升级、真清屏、有限特殊砖Buff、Boss20三阶段、手机全屏与右上设置、直达Boss10/20测试入口。

## 回归与待验收
- 已验证代码语法、关卡生成1–20波三种手机顶部偏移下无砖-砖与Boss-砖碰撞重叠；Boss10护甲环25高HP+10导向；晚期关卡73–77普通砖；上下砖缝11大于普通球直径6.9；电弧R1/2/3对弱HP实测mock命中3/5/6块，对厚HP实测mock只命中2/3/4块，雷霆聚能仍只打单体；三流派技能卡池基础不变。
- **未完成**：真实浏览器20波三流派全程物理回放、iOS/Android发热和音效、弱电弧/弱裂变可玩性、实际弹球在Boss10护甲环中反弹次数。参数为实验候选，不能把模型PASS当作真人试玩合格或宣布对外正式公测完成。
