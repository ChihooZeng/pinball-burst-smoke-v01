# v0.9B — 破甲→普通砖→击碎穿透
基础砖阵、升级、发射、巨型球数值全部与 A 版相同，唯一增加的规则：普通球扣掉装甲最后 1 HP 时外壳碎裂，留下 cracked 普通砖。该次命中反射球，下一次命中才真正击碎并穿透。
装甲裂开时显示「破甲！」和亮色裂纹，破甲不增加分数；最后消失才计 1 分。巨型球特殊能力仍可直接毁掉装甲。
