## 设计与修改
- **第11–19关**不再是同一块砖墙：不同波使用双翼、漏斗通道、斜向走廊、低位压力门、双通道。低HP砖与高HP锚点相邻，使弹球破坏低砖之后继续在高砖间弹反。
- 数字随波次逐步提高。第11关大致3–45HP，第19关大致7–92HP（普通砖）；特殊Buff砖仍可低HP。高砖数量/耐久与下降压力同时增加，下降速度在第11波开始乘`1+(wave-10)*0.028`，第19波约+25.2%（*相对现有下落参数*）。并非仅翻倍全部数字。
- **第20关**全新独立终局：大体型**888HP** Boss，顶部与两翼大数字护甲砖，底部中央真实入口。
- **3段有限砖阵**：初始1/3，Boss HP降至约70%或战斗达到24秒时进入第2阵；HP降至约35%或达到46秒时进入第3阵。每次最多15块，提前至少1.35秒虚线预警，不重叠Boss、已有砖或危险线，且在Boss两翼保留弹射通道。不无限生成。
- 第20关Boss自带召唤改为上述阶段增援，其他普通波仍不在战斗中填补砖块。Boss击破不会偷偷把新召唤的阶段砖判定为已清理；必须真实击碎才能通关。
- 第一关普通炮台、首次清屏后核心三选一、特殊砖只有限时Buff、基础伤害1/球速330/50关正式目标等均继承旧版。
- 首界面支持`直达第10关 Boss`和`直达第20关 最终Boss`；可选择裂变、电弧或机枪，调试跳关自动生成前9或19次合法成长记录。**跳关只供测试，不能当作正常通关或正式战绩。**
