## 2. 菜单

**14 个入口**：无技能对照、S1、C1、M1、M2、D1-L1/L2/L3、D2-L1/L2/L3、C4、C5、C6。

- 战场沿用 V2 的 **A/B/C**，默认 **C 中部召唤**。
- 砖块生成、下落、HP、召唤规则**未改**。

- M1/M2 射速保持 V2：0.08s / 0.15s×3，不加速。

## 3. D1 破阵钻头

- 每 **8 发普通弹**后，下一发替换为贯穿钻头弹（D1-L2 为 7 发、L3 为 6 发；可调）。
- 沿瞄准方向高速直线前进，不反弹；真实命中每块砖一次（`Set` 去重），单颗最多贯穿 4/5/7 块。
- 真实伤害：L1 = 1；L2/L3 = 2；只有 HP 归零才播放击碎，不额外削血。
- 发射前炮口有金蓝蓄能环；弹体为细长菱形钻头 + 旋转螺旋 + 长尾迹；命中产生穿孔亮线和沿路径依次出现的贯穿火花。
- 三种等级：L1 基础；L2 旋转钻头（更大、更快、2 伤害、5 贯穿）；L3 宽体钻机（外圈宽体、7 贯穿、更大碰撞半径）。

## 4. D2 横扫刀弧

- 真实主炮/机枪命中积累切割能量；达到 8/7/6 次后，在命中点先出现 **0.12s 横向预警亮线**，随后释放刀弧。
- 刀弧是薄月牙/弧线，沿水平方向实际移动；路径上的砖块按经过顺序依次结算，每块一次；有距离上限、冷却和垂直带宽限制，不是全屏默认扣血。
- L1 单向短距；L2 从命中点向左右两道交叉刀弧；L3 三道错位、带延迟的千刃风暴。
- 视觉：预警亮线、横向移动光刃、砖块切割线、定向碎屑；不覆盖真实 HP。

## 8. 已知问题

1. 无真机 iPhone/Android 证据：实际刘海、地址栏、手势、FPS、音频、振动未测。
2. 刀弧速度较快（约 0.35–0.5s 扫过），真人是否看得清需试玩；D2-L3 三道弧可能偏密。
3. D1-L3 宽体碰撞半径更大，可能偏强；D1-L1 单发伤害 1，打高 HP 砖仍依赖多次。
4. C6 子钻视觉较小，手机上有辨识度风险；已限制每朵花最多 1 颗、生命周期 0.85s。
5. 默认关闭巨型球；勾选后仅验证兼容性，不评价联动平衡。
6. 未做 45 关、正式成长树、存档、Boss。
7. 浏览器部分长序列样本被 Chrome 后台节流到 30FPS；不代表真机。
