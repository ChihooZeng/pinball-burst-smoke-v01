## 实际变化
1. **第10关Boss真正召唤波次：** 以前只沿顶部、每4.6秒最多4块、总≤23块。现在每**3.8秒**尝试一轮，单轮**最多14块**，全场总上限**70块**，同时存活辅助砖上限**48块**，每块7–21HP；部分两翼锚点砖22–38HP。每轮按当前空位在上层、中层、下层分配实体砖，真实撞击/清除，保留Boss下方3列中央射入通道；不能重复或叠砖，提前1秒虚线显示。因为安全空位受实体占位、手机屏幕和真实破坏量限制，**每次实际数量可能少于14、总数也可能少于70，不承诺固定生成70块。** Boss不死不会无穷补砖，普通关没有战中反复补砖。
2. **Boss下降压迫：** 第10关独立下落倍率1.04→**1.20**；第20关按阶段的倍率0.29/0.38/0.47→**0.34/0.45/0.56**。当前是更强的实验候选值，首次公开测试仍须平衡。
3. **电弧路线明显增强且不暗改普通球伤害**：R1/R2/R3基础电弧每次传播2/3/4目标，目标伤害1/2/3→**2/4/6**；电弧触发冷却0.45→0.34秒；一级放电需求3次击砖→2次；半径提高到145/165/180。击中Boss、高HP环形护甲、精英或Boss召唤砖时，电弧额外+2/+3/+4伤害（按电弧等级）。当普通球直接打到高HP Boss/护甲且触发电弧时，电弧必须包含该实体，不再只跳周围其他砖；原有击碎后续传、单次最多6个不同目标仍保持。「雷霆聚能」仍属于可选单体专精并不自动开放全屏闪电。
4. **技能卡/暂停说明与真实数据对齐**：电弧升级卡显示具体目标、伤害和导电增益，满级卡显示“已满级”，不出现NaN。
5. **继承不变**：初始普通球直接碰撞伤害1、球速330、普通球视觉/碰撞大小分离、上下砖缝9、Boss10环形高血砖、Boss20的888HP与三阶段实际清屏、每清屏后正常三选一、20关Demo/50关正式目标。

## 已执行定向检查
- V8游戏和模型JS语法通过；3路线×30固定随机种子=**90条完整19次升级路径**均三选一、卡文案非NaN。
- 第10关实际Boss召唤函数在三种顶部偏移×两种画面高度的**6个模拟场景**，无实体重叠。每3.8秒尝试最多14块，持续6批后实际新增约54–70块；所有场景均在上、中、下不同高度生成过砖。模拟不等于真实手机实战，也不代表一定能撑过6轮。
- 真正从游戏源码提取的电弧函数，用Mock的物理伤害调用检验：R1/2/3面对高耐久密集阵单次总伤害分别8/18/30点；Boss被包含在闪电优先目标里；聚能专精只打一个目标，不产生无限链式递归。
- 仍待**浏览器实际启动**、三路线第10关清屏率、完整20关物理回放、iOS/Android真机发热/音效/触线时间。绝不能把模拟通过标成真人手感已通过。

## 测试焦点
先选择“电弧Build”并直达第10关Boss：观察第1–3批召唤砖是否大范围落在上、中、下，闪电是否能帮助处理外围高数字护甲，警戒线是否变得合理紧迫；再与旧M2.2同机对照。若出现明显无解触线，先调Boss波次节奏、召唤砖HP/边界与电弧成长，不恢复普通球基础伤害2。
