## 已改
- **真实缺陷**：旧`defeatBoss()`在Boss10死亡时把全部存活`bossSupport`砖直接标记`alive=false`并虚增击碎数，造成召唤砖瞬间消失。现Boss10/Boss20都不删除任何活体增援砖，只解除Boss归属、停止该Boss后续召唤，并记录剩余砖数；砖必须经真实伤害击碎。
- **胜利规则暂未修改**：Boss10当前仍是“Boss死亡后，清掉所有剩余砖才过关”，这是此前产品既有规则，不代表最终建议。用户明确提出讨论“击败Boss即胜利”与“全部清屏”两方案，需用户决策。未经确认，不将Boss击破自动视为完成，也不暗中清砖。
- **电弧强度**：一级2次有效撞砖放电，二级和三级每次有效撞砖即可尝试放电（冷却0.34→0.30秒，最多每0.3秒一次），延续M2.3电弧伤害2/4/6、Boss与护甲额外导电2/3/4、六目标上限，技能卡“每次撞砖就放电”与实际一致。普通球基础直击仍为1HP，球速330。
- **Boss10下降压迫**：原固定1.20倍→开场1.22倍，战斗8秒后每秒多0.014倍，最高1.49倍；同时将第10关最下方引导砖上移一行，降低开局触线过早的概率。此改动是实验，真实压力有待手机和物理回放。
- **触线追踪**：失败界面与事件日志会显示到底是初始砖、Boss新生砖、Boss本体还是终局增援触线，附该砖剩余HP，后续可据此调整，而不是盲目叠加召唤及伤害。
- 不改第10关Boss128HP、第20关888HP三阶段、20关demo目标、正式50关连续Build、真实物理弹反、召唤总上限70及每3.8秒尝试最多14砖、受占位控制的真正新砖机制、旧版基础伤害等。
