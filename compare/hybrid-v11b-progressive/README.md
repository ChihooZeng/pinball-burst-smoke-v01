# v0.11B 渐进式电流超载

新版本地址：https://chihoozeng.github.io/pinball-burst-smoke-v01/compare/hybrid-v11b-progressive/

继承 v0.10B 的全部自然碰撞、四波、装甲破甲与升级；只调整闪电触发成长曲线：剩余≤30% 首次单链（每3次自然碰撞放电1次）、≤15% 双链（每2次放电1次）、≤8块终局三链（每次有效命中都可以放电，保留每球冷却）。前两个阶段只削数字砖的1点HP，不额外清除普通砖。所有阶段均由真实弹球撞击激活，多球独立。

下方提供三阶段快速体验选择器。运行 `node v11-electric-test.js` 验证完整四波及对照数据。
