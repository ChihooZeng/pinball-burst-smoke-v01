# 特殊砖美术预览 V1.0

《弹珠超载》砖块美术体系的特殊砖扩展。**只做视觉预览，不接入正式游戏。**

- 基线：`deepseek/brick-art-v1` @ `89c9074`
- 正式游戏代码：`demo/v1/game.js`（本目录不修改它）
- 打开方式：双击 `index.html`，零依赖、零构建

---

## 一、设计原则

三种特殊砖复用普通砖的全部结构，只换三样东西：

| 维度 | 普通砖 | 特殊砖 |
|---|---|---|
| 形状 | 29×22 圆角 4 | 完全相同 |
| 渲染管线 | 渐变填充 + 霓虹描边 + 外发光 + 顶部高光 | 完全相同 |
| 数字 | 居中白色 + 柔和投影 | 与图标作为整体居中 |
| 差异点 | — | 颜色 + 一个图标 + 轻微动效 |

不新增材质层、不加装甲板、不做传送门。

## 三、图标几何

图标统一画在 7×7 逻辑单位的方框内（占砖宽 24%），与数字间隔 2 单位，整组水平居中。

| 图标 | 构成 | 颜色 |
|---|---|---|
| 闪电 | 6 点折线闭合多边形，上宽下尖 | `#EAFFF6` |
| 菱形 | 实心菱形 + 中心 `destination-out` 镂空小菱形 | `#F4EBFF` |
| 双层环 | 外环 r=.92 / 线宽 .26，内环 r=.46 / 线宽 .19 | `#E8FBFF` |

**降级规则**：若「图标 + 间隔 + 数字」超出砖内容宽（29−4=25），图标降到 6 单位、数字降到 10px。不放大砖块。

用到的实际 HP：能量砖 1（不显示数字）、精英砖 32（固定）、召唤砖 7–21 普通 / 22–38 重型。

## 五、已知取舍

1. **能量砖不显示数字** —— 沿用正式游戏逻辑（HP 恒为 1，一次击破）。若希望显示，需要额外占位。
2. **召唤砖的青色与普通砖 HP6–10（`#3FDBFF`）接近** —— 同属青蓝家族，主要靠双环图标区分。实际游戏中召唤砖只出现在 Boss 关，那时普通砖 HP 已进入紫蓝/粉紫区间，撞色概率低。
3. **动效幅度刻意压小** —— 呼吸/脉冲只改变 alpha 或 1–2% 的缩放，不改变砖块外轮廓，避免在密集砖阵中产生闪烁干扰。
4. **手机模拟是静态构图** —— 砖阵、危险线、炮塔位置按游戏真实常量摆放（9 列 / stepX 38.5 / 危险线 H−105 / 炮塔 H−37），但不是真实运行画面。
