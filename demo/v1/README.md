## 已采纳的主线基准
用户实测“900球×超高数字×不下落”只有无聊，没有爽感，因此不移植球海实验；明确选择M2.5打击强化版作为新版主线基础。

1. 同屏物理弹球上限48（原M2.5为32；不能无限增加）。裂变增量：基础等级R1/R2/R3=2/3/3；星海风暴专精4/5颗；每颗主弹球最多触发一次、子弹不再递归分裂。
2. 砖块真实受击反馈：中心明亮闪光、局部扩散冲击圈、震荡/挤压形变、分层飞屑，连续击碎更强；音效加入低频撞击；被攻击的物理坐标、HP、砖块下落不随纯视觉变更。
3. 48球×高特效时，自动浏览器曾观察到27–39FPS；FPS低于48会保留小冲击圈/画面震动、减少飞屑与阴影开销。**性能仍未通过目标真机60FPS验收**。
4. 支持Vibration API的安卓浏览器可以开关短振动并限频。iPhone Safari网页通常无可用原生马达振动，本版用画面震动和音效实现等效反馈；不能宣传真机有物理振动。
5. 普通炮台连续自动射击，玩家拖动瞄准；超载能量满默认自动释放（已有手动设置会保留）。第一关清屏后3选1确定裂变/电弧/机枪核心，之后升级3选1，不重置Build。
6. 普通关真实清屏过关，Boss10和Boss20击败核心即锁胜、从中心向外1.7秒连爆残砖后领取奖励/结算；最终Boss888HP三阶段保持。基础普通弹球直击1、初速330、20关Demo、长期50关目标不变。

## 玩法范围冻结（11月5日版）
- 核心流派：裂变、电弧、机枪，各有两个互斥专精（星海风暴/猎星裂变、雷网蔓延/雷霆聚能、直线压制/扇形扫射）。
- 基础技能：射速、火力、弹速、续航；辅助技能：追猎、钻头、震荡、撞墙蓄势。**不再新增职业和全新技能子系统。**
- 砖块：数字HP砖、较高HP/护甲砖、能量增益砖、第5关精英、第10/20关Boss、Boss真实生成的辅助砖，保持物理碰撞；可在不新增系统的前提下调颜色/HP/阵型。
- 玩家正常入口不显示Boss调试直达，内部可在URL加`?qa=1`测试。原全部`compare/*`实验均不覆盖。
