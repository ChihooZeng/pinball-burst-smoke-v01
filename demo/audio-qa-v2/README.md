# 《弹珠超载》音效重新选型 / 第10关诊断测试 V2

独立验收路径：`/demo/audio-qa-v2/`。原正式游戏 `demo/v1/`、初版音效验收 `demo/audio-qa/` **完全不改**。

## 本轮用户两项问题

1. **已选音效不满意，需要重新选择**：在同一个真实20波战斗中切换每类声音，而非单独网页盲听。每种声音有「★原本地已选」基准及从V4/V5 20–30个不同来源文件得到的备选，支持单次、连播3秒、本地音频上传、实时音量、A/B、JSON导出。本地上传只在当前页面保留，JSON不包含音频二进制，正式发布要另外上传确认文件。
2. **第10关进入后卡住**：先用QA直达第10关复现、检查代码。裂变与电弧均能击败Boss并出现「升级选择」——原逻辑是**清屏后暂停，必须选择卡片才推进下一关**，并非每次进入第10关都产生死循环。但尚不能排除用户设备真实卡死，尤其普通1–10连续流程。
   - **已发现的可实证问题**：旧代码 `window.addEventListener("resize",()=>{pause();...})` 任何窗口尺寸变化都会把正在玩的游戏切成暂停状态，包括移动浏览器工具栏/窗口缩放。V2改为更新帧计时但**不自动暂停**。
   - 第10关清屏后的卡片标题改成「第10关Boss已击败 · 选择强化后进入第11关」。
   - 新增右栏运行阶段检测：`playing/choosing/paused/lost/complete`、波次、Boss HP、帧异常、音频加载、进度停滞提示。
   - 当游戏处于 `choosing` 时右栏显示「应用第一张升级卡，继续下一关」，等同于用户确认有效卡片（没有跳过升级、没有改强度）；处于 `paused` 时显示「恢复暂停的游戏」。
   - 新增动画帧 try/catch/finally：如果一次动画脚本异常，不会让 `requestAnimationFrame` 永久停止；自动进入可见的暂停错误状态，并可导出 `pinball-wave10-diagnostic.json`（含最后120条游戏事件），避免无日志卡死。
   - 300条连续构筑升级模拟（裂变、电弧、机枪各100组随机seed，前10关每波升级）未找到“第10关固定选卡失败”。
   - 其他Boss/伤害/下落/球数/20波机制**不改**，不假装已经通过所有真实设备测试。

## 新版音效调试台

- 真实游戏左侧；电脑右侧固定音效操作区。每个分类有下拉选音、单次试听、3秒连播、本地上传、单独音量。
- 9种类别：机枪、普通命中、击碎、装甲命中、爆雷、技能选择、清屏过关、触线失败、升级提示。普通发射/电弧/裂变/超载等已有合成音继续保留，不硬增独立音效类别。
- 原始候选由 `assets/sfx/v4/catalog.js`、`compare/audio-in-game-lab-v1/extra-catalog.js`、`assets/sfx/v5/more-catalog.js` 组成，属于**多样化公开CC0试听素材**，部分来自同一系列不同录音；并非所有候选已通过听感审核。
- 默认★内置已选（Mixkit三项与V5五项）全部保留并自托管，不依赖外部URL。尝试其他外部音源时按需下载解码，失败则回退内置基准，避免整局静音；部分国家/网络会阻断 `raw.githubusercontent.com`。
- 正式游戏音效部分尚未定稿；用户选出最终候选后需要将被选中的文件另行归档、本地托管、核实许可证并做手机真机响度测试。

## 建议验收流程

1. 电脑Chrome/Edge宽度至少1200px，打开 `/demo/audio-qa-v2/?qa=1`；
2. 点击「直达第10关 Boss」，分别选裂变/电弧/机枪，击败Boss后观察右侧阶段变为 `choosing`（等待升级），点击卡片或「应用第一张升级卡」应进入第11关；
3. 游戏进行时拖动浏览器窗口改变大小，应该**不会自动暂停**；若画面停止，右侧导出游戏卡住诊断；
4. 调整音效分类的下拉备选，实时听砖击、过关、技能选择等。可从电脑上传自己的音频做临时替换；
5. 右侧导出选音JSON，先决定哪些声音合适，再决定是否进入正式版；
6. 浏览器及安卓、iPhone的真实连续1–10关、Boss10/20和高频混音必须额外进行验收，不能因一次跳关成功而宣称全部修复。
