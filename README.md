# 弹球暴走 v0.4 — 实时生存式数字打砖块

试玩：https://chihoozeng.github.io/pinball-burst-smoke-v01/?v=4

## 游戏循环
- 炮台每 1 秒自动发射一颗；手指水平拖动改变方向，不需要松手发射或等待弹球回收。
- 砖块从顶部定时生成，带数字 HP、持续缓慢下降；每次普通命中扣除伤害值，数字归零才消失。
- 砖块触及红色底线立即失败。越往后下降速度、生成频率和砖块 HP 逐步增加。
- 击碎砖块获得 EXP，升一级时战斗暂停，随机二选一：伤害 +1、有限提速、侧墙反弹后溅射、巨型球威力强化。
- 击砖积蓄必杀能量，绿色 ENERGY 砖额外充能。**巨型球按钮固定在游戏画面右下角**，充满后点击沿当前炮台方向贯穿；巨型球伤害不会再次增加其自身能量。
- 死亡显示时间、击碎数、等级、必杀使用次数，可立即重新挑战；每局属性重置。

## 试验参数
- 普通弹球初伤 1，上限 7；同屏最多 20 颗物理球。
- 发射间隔 1.00 → 0.90 → 0.82 秒，上限 2 次射速强化。
- 生存初期砖块每约 7.5 秒生成一排，随时间最低到 4.8 秒一排。
- 下落速度从约 8.7px/s 逐渐提高，上限 16.5px/s。砖块 HP 随时间分段增长（上限 60）。
- 巨型贯穿球初始对单砖伤害 15，巨型强化每级 +6，至多 3 次。
- 普通球伤害与折射等级有上限，满级后升级选项会提供一次性额外发射或能量补给，避免无选项崩溃。

## 验证说明
- `node --check game.js`
- `node smoke-test.js`：覆盖数字扣血、经验选卡暂停、连续发射、瞄准、巨型球、触底失败和重开。
- 采用脚本自动改变瞄准方向（不主动放大招）实测约 402 秒触底；不改变瞄准方向约 43 秒触底。此处为模拟环境数值，不代表真实玩家成绩。
- Windows Microsoft Edge 已成功生成 390×844 移动端布局截图；仍需 iPhone Safari 真机触控测试和数值调优。

## MVP 限制
只做一台炮台。没有局外科技树、第二炮台、诅咒、商店、广告、云存档、复杂敌方 AI。
