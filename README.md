## 本次只调整砖块供给和下落节奏

| 参数 | v0.4 | v0.4.1 |
| --- | --- | --- |
| 初始砖块 | 1 排 | 2 排（顶部 Y=6 与 Y=45） |
| 刷新基本间隔 | 7.5s | 4.2s |
| 刷新最短间隔 | 4.8s | 3.4s |
| 初始下落速度 | 8.7 px/s | 11.5 px/s |
| 下落最大速度 | 16.5 px/s | 15.5 px/s |
| 新砖位置 | Y=-42（屏外） | Y=12（屏内可见） |
| 场上剩余目标少 | 等待正常刷新 | 剩 ≤2 个且顶部安全，最多约 1.25 秒后补充 |
| 场上没有砖 | 等待正常刷新 | 最多约 0.42 秒后补充 |

保留数字 HP、自动发射、射速升级、经验二选一、巨型球、触底失败、重开，以及现有唯一反弹炮台。
这是局内实测候选数值，不是行业标准。

## 原因与参考
Ballz 使用每轮生成/移动砖块；Idle Brick Smasher 每隔几秒生成整排；实时自动射击版还应按战场剩余目标数动态补充。
