# 弹球暴走 · 连续发射手感实验 v0.2

手机网页：GitHub Pages `https://chihoozeng.github.io/pinball-burst-smoke-v01/`

## 变更
- 无需松手：炮台自动连续发射，每秒 1 颗。
- 触摸/拖动只改变发射角度，抬手不发射，也不停止自动发射。
- 多颗弹珠并行碰撞与反弹，不必等上一颗掉落；弹珠在底部或约 7 秒后自然回收。
- 击碎绿色 SPEED 砖提升射速：1.00 → .84 → .68 → .52 → .36 秒/颗（最小 .36 秒）。
- 两个模式可通过按钮切换（重开后生效）：直接升级 / 掉落道具自动拾取。
- 三波砖块后结算，每局可以直接重来。
- 限制同屏最多 28 颗真实弹珠，控制性能和后期自动化风险。

## 目标
比较两种射速成长反馈对节奏的影响；暂不新增诅咒、巨型球或商业系统。

## 手工测试
手机 Safari：确认无需触屏自动发射；拖动时方向变化；同屏多球；绿色砖触发射速提升；切换模式后道具掉落并自动领取；三波结算。
