# 弹球暴走 · 手机试玩烟雾测试 v0.1

独立静态网页原型，仅验证远程开发→公网部署→iPhone Safari 试玩的闭环。

## 玩法
- 在画布中触摸并拖动，松开即发射一颗球；也可以点击“发射弹珠”。
- 弹球自动反弹，碰到砖块即击碎；回到底部后可再发射。
- 击碎全部 15 块砖后获胜，点击“再来一局”重玩。

## 范围
没有增量、诅咒、强化、主动巨型球、广告或数据收集。
纯静态文件，无外部依赖和后端；游戏逻辑在 game.js。

## 验证
node --check game.js
移动端触控、不同屏幕尺寸、HTTPS 域名以及 Safari 实机体验待用户验证。

## 部署
直接把 index.html、style.css、game.js 部署到任何静态托管即可。
