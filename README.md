# 弹球暴走 v0.3 — Quality-growth test
试玩页面：https://chihoozeng.github.io/pinball-burst-smoke-v01/?v=3

## 已确定的边界
- 竖屏 2D、炮台自动发射、单指水平滑动瞄准；无需等待旧弹球回收。
- 三波砖块，每波结束暂停战斗，二选一：快速装填或折射强化。
- 发射间隔只允许 1.00 → 0.90 → 0.82 秒，不再通过战场掉落无限提速。
- 折射 Lv.1：撞侧墙后的首个有效击砖，会额外击碎附近 1 块。Lv.2：溅射范围更大，最多 3 块；每颗弹珠只触发一次。
- 击砖为巨型贯穿球蓄能；绿色 ENERGY 砖即时增加能量。满 100% 后玩家按按钮主动释放，沿当前瞄准方向直线贯穿；巨型球攻击不为自身充能。
- 三波结束结算，可随时重开；不做金币、诅咒、闪电、局外成长和广告。
- 真实球数上限 20，同屏约 7 秒自动清理，避免无限挂机/移动端开销。
